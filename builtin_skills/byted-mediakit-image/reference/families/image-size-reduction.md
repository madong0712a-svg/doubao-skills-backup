# 图片体积治理选择指南

## 适用目标

用户强调尽量不掉画质、质量优先或高质量缩小图片体积时，选择[slim-image](../slim-image.md)。输出格式默认保持原格式；用户明确指定输出格式时，按该工具reference的支持范围填写。

## 能力边界

当前工具不支持指定精确文件大小上限或quality数值。不能把“压缩到某个大小”或“设置某个质量值”的要求改写成没有这些保证的瘦身任务。先说明可用能力，再按用户明确的目标决定是否继续。

输入和输出均为JPEG时，体积可能无明显下降，少数情况下可能略微增大；不得承诺固定压缩率或必然变小。

## 澄清边界

用户只说“压缩”或“变小”，无法判断是质量优先还是需要精确体积、质量或格式控制时，先澄清。可选输出格式按用户真实意图填写，不推断额外参数。
