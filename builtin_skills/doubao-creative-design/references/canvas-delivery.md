# 可编辑设计的预览与交付

**读取方式**：按主入口的任务与阶段指引直接读取本文件；已有内容沿用，仅补读当前任务需要的关联规范。纯图阶段不执行 HTML 专属条款，模板资产仅在实际选中后读取完整正文及必要依赖。

**结果处理（所有场景）**：所有产物返回即按[主入口](../SKILL.md#交付规范)用 RichMediaCard + 真实短链交付；HTML 仅交付 `creative_design_preview` 的设计预览／编辑入口短链，不交付源文件。非 HTML 产物一律不做产物校验，包括混合素材和拼接结果。HTML 可检查，但检查不延后交付；只有符合 [quality 单轮溢出例外](quality.md#内容溢出允许增长长度的有限例外)的 HTML 可自主增长长度，同一任务最多一轮。该例外优先于本文件中只记录、不自主改高或重排的一般限制；除此之外，必须用户明确说改才改。不得因效果不好自主重生、修图、替换或重排。继续完成原定未完成产物和首次预览，不擅自增加优化轮次。

**HTML 规则**：仅在用户明确要求或同意可自由编辑时，才生成或修改 HTML 及相关产物，已有明确意愿直接沿用。预览必须调用 `creative_design_preview`，仅使用该工具返回的设计预览／编辑入口真实短链，通过 RichMediaCard 交付。HTML 只作为内部实现文件，禁止交付 HTML 文件、源码附件、打包源文件或下载链接。字体使用 head 内声明的豆包 CDN 远端首选字体及对应字重、样式，系统字体仅作备用，禁止检查字体可用性、字形覆盖或加载命中。 HTML 复刻以用户选中的图片为准，尽量保持风格、排版、布局和字体，题材默认样式不覆盖原图；艺术字按[混合制作](produce-hybrid.md#独立艺术标题的使用条件)复用或参考生成透明素材后排版。

## 为什么交付设计入口

用户选择可编辑设计，是希望拿到作品后能方便地继续改字、换图、调布局。只收到 HTML 文件，还需要自己下载、打开或寻找编辑环境，会把使用作品的负担留给用户。HTML 是实现和保存设计的文件格式，最终服务的是可编辑设计；交付应让用户拿到对应设计入口，而不是停在“文件已经生成”。

因此，完整 HTML 仅在内部保存，用于预览和后续修改。所有 HTML 产物一律通过 `creative_design_preview` 生成设计入口短链，再用 RichMediaCard 展示给用户。交付的是可访问的设计结果，不是 HTML 文件。

## 生产范围

仅用户明确要求或同意可自由编辑时，才生成、重建或修改 HTML 及其预览。已明确的意愿继续有效，不重复询问；未答复、仅指定导出格式或仅提供已有源，不自动启动 HTML 制作。具体承接见 [editable-upgrade](editable-upgrade.md)。

## 生成预览

- 保存本次完整 HTML，包含准确文案、实际素材与指定尺寸；字体按 [fonts](fonts.md) 在 head 内声明豆包 CDN HTTPS 远端首选字体，系统字体仅作备用；不检查可用性、字形覆盖或加载命中。
- **必须调用 `creative_design_preview`。** 按工具实际协议传入当前完整 HTML 及所需信息，不猜参数，不用本地截图、浏览器截图或画布回读替代预览。
- 多页、双面或分屏分别提交对应完整版本，标明阅读顺序。用户明确要求修改，或符合 [quality 单轮溢出例外](quality.md#内容溢出允许增长长度的有限例外)并完成必要增长后，对新版本调用该工具；其余检查结果不触发改稿或重复预览。

## 直接交付

- **仅交付设计入口短链。** 必须调用 `creative_design_preview`，将其实际返回、对应本次设计预览／编辑入口的真实短链原样填入 RichMediaCard 的 `refs`。返回即交付，多页逐项展示，不等待整套完成。
- **禁止交付 HTML 文件。** 不发送 `.html` 附件，不粘贴完整 HTML 源码，不打包源文件交付，也不提供 HTML 文件下载链接。即使预览工具同时返回源文件地址，也不把它填入 RichMediaCard 或作为补充交付。
- **保留内部源，直接展示设计。** HTML 源仅用于内部保存、版本维护和后续修改；交付时不重新上传、不二次转短链、不自行拼接地址，不用 Workspace／Item ID、其他工具链接、Markdown 图片或普通附件替代设计入口。

```text
<RichMediaCard>{"refs":["creative_design_preview 返回的设计预览／编辑入口真实短链"]}</RichMediaCard>
```

RichMediaCard 是展示格式，不是工具。`refs` 填真实返回值，不保留示例占位，也不嵌套 Markdown 链接。

## 版本与异常

- 记录短链对应的文件、页序与版本；已有本次版本的有效工具结果直接复用，不为交付重复制作。
- 工具不可用、失败或未返回设计入口短链时，在内部保留完整源并如实说明交付未完成；不能退回发送 HTML 文件、源码或文件下载链接，也不改用其他工具链接冒充完成。
- 工具已返回的有效设计入口短链立即交付；用户明确提出修改，或执行获准的单轮溢出增长时，才另存新版本并调用 `creative_design_preview`，不覆盖历史结果。异常不触发自主改稿或自动重试。
