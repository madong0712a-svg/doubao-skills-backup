# 单张商品主图

适用单张商品主图、白底图或商品棚拍。当前图片阶段的必要规则在本文件内；不补读成组电商、A+、长图或复杂复刻规范。多张主副图、独立副图及 A+ 模块使用 [ecommerce](ecommerce.md)，连续详情页使用 [ecommerce-detail](ecommerce-detail.md)。

## 内容与规格

- 默认生成 1 张完整图片；未指定平台或尺寸时通常为 1:1，服饰可按展示需要采用 3:4。用户明确的数量、尺寸、平台要求和锁定项优先，不为缺少平台名称增加确认。
- 商品完整清晰，作为视觉中心；保留真实外形、配色、材质表现、标识、包装文字及售卖组合。根据用户要求调整背景、光影、机位和摆放，不把手、杂物或场外包装误当作商品配件。资料足够直接创作，不猜型号、功效、参数或营销事实。
- 国内主图保持低密度：有营销文案时最多 1 个标题及 1–2 个极短标签；用户只要商品摄影时不强加标题。不放具体价格，利益或服务标签须有真实依据；准确文案在提示词中逐条用中文双引号标明。
- Amazon 主图沿用纯白底、通常 1:1、商品居中且约占画面 85% 的要求；保留商品与真实包装自带标识，不附加文字、Logo、水印、徽章、营销角标、道具或装饰背景。套装仅呈现实际售卖内容及真实比例。

## 使用原图并生成

- 已能看到商品图时直接理解，禁止再次调用读图工具。仅有路径或链接、当前看不到图片时才读取；不可替代的原图缺失时请用户补充。
- 仅保留商品身份时，将外观、标识、包装和获准改动写入提示词，不做整页版式拆解、不建复杂 Brief。使用 `image_edit` 实际传入原图；多图按“图1、图2”说明用途。仅有商品参考图不增加整页拆解；明确要求复刻版式或风格时才读取 [reference](reference.md)。
- 一次写清主体与保留项、背景与摆放、光影、文案及修改范围，尺寸按工具协议传入。直接生成最终主图，不先生成白底母版或内部候选；仅需抠图时按主入口使用专用去背景工具。

## 返回与承接

- 工具返回产物即用 RichMediaCard + 真实短链交付。图片不做生成后校验，不因效果自行重生或修改；只有用户说改，才改指定范围。
- 纯白底图、商品摄影及包装自带文字不追加可编辑追问。含独立营销文案或版式设计时，交付后可问：“需要可自由编辑的设计吗？”同一任务只问一次，已有明确意愿直接沿用。
- 用户明确要求或同意自由编辑后，才切换到 editable 阶段，按选中图片复刻。必须调用 `creative_design_preview`，直接用返回的设计预览／编辑入口短链 + RichMediaCard 交付，禁止交付 HTML 文件。
