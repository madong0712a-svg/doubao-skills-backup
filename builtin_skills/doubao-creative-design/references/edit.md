# 既有设计与模板编辑

**读取方式**：按主入口的任务与阶段指引直接读取本文件；已有内容沿用，仅补读当前任务需要的关联规范。纯图阶段不执行 HTML 专属条款，模板资产仅在实际选中后读取完整正文及必要依赖。

**结果处理（所有场景）**：所有产物返回即按[主入口](../SKILL.md#交付规范)用 RichMediaCard + 真实短链交付；HTML 仅交付 `creative_design_preview` 的设计预览／编辑入口短链，不交付源文件。非 HTML 产物一律不做产物校验，包括混合素材和拼接结果。HTML 可检查，但检查不延后交付；只有符合 [quality 单轮溢出例外](quality.md#内容溢出允许增长长度的有限例外)的 HTML 可自主增长长度，同一任务最多一轮。该例外优先于本文件中只记录、不自主改高或重排的一般限制；除此之外，必须用户明确说改才改。不得因效果不好自主重生、修图、替换或重排。继续完成原定未完成产物和首次预览，不擅自增加优化轮次。

**HTML 规则**：仅在用户明确要求或同意可自由编辑时，才生成或修改 HTML 及相关产物，已有明确意愿直接沿用。预览必须调用 `creative_design_preview`，仅使用该工具返回的设计预览／编辑入口真实短链，通过 RichMediaCard 交付。HTML 只作为内部实现文件，禁止交付 HTML 文件、源码附件、打包源文件或下载链接。字体使用 head 内声明的豆包 CDN 远端首选字体及对应字重、样式，系统字体仅作备用，禁止检查字体可用性、字形覆盖或加载命中。 HTML 复刻以用户选中的图片为准，尽量保持风格、排版、布局和字体，题材默认样式不覆盖原图；艺术字按[混合制作](produce-hybrid.md#独立艺术标题的使用条件)复用或参考生成透明素材后排版。

## 1. 概述

- 承接既有图片和模板修改；生成或修改 HTML 必须已有用户明确的自由编辑意愿。保护完整基线、修改范围与源版本。
- 需求路由、制作方式、澄清与交付统一见 [SKILL.md](../SKILL.md)；本文件不另设规则或放宽授权。

## 2. 使用场景

| 来源／类型 | 执行边界 |
|---|---|
| 目标与修改明确 | 直接执行；授权不明、目标不唯一或需扩围时才确认 |
| 完整 HTML | 始终以完整源为基线，整体重做也保留原文档 |
| 只有最终图，用户要求恢复可编辑能力 | 按 [editable-upgrade](editable-upgrade.md) 以该图和原文重建；范围已明确直接执行，不重复询问意愿、不冒称原位编辑 |
| 明确另做纯图版本 | 可用 HTML 正式导出图建立衍生任务，不改变原 HTML |
| 普通纯图局改 | 不因 Logo、VI、详情页、长图或套图题材禁入，不擅增张数或重做全套 |

- 原文件、原图及既有版本均不覆盖。HTML 内容变化须保存完整新版本，不用截图、补丁、压平图片或 Frame 代替。
- 按主入口区分接续编辑与重新生成；不因编辑题材增加 KV、封面批准或整套重做。

## 3. 核心流程

### 先核对项目与完整基线

- 代码修改前实际查看技术栈、目录、组件、设计变量、依赖及版本；使用版本控制时检查未提交改动。沿用项目约定与可复用实现，不覆盖或回退用户改动。仅编辑最终图时不做代码项目检查。
- 读取用户要求、完整源、已有 Brief 与可用资产，结合已可见的同版本渲染；图片已可见时禁止再次调用读图工具，此限制不影响读取 HTML 源文件。按实际存储及回读能力核对对象身份、类型、位置、标题、尺寸和真实资源地址，不假定操作已完成。

| 基线 | 必查内容 |
|---|---|
| HTML | 完整 `.html`、稳定节点标识、真实文本、CSS、素材 URL；与同版本 Brief、文档及资产清单对齐。作品根与画布实现见 [produce-code.md](produce-code.md) |
| 最终图片 | 当前成品、已有 Prompt／Brief；核心商品、人物、品牌或 Logo 的权威母版、稳定资产标识、身份约束、文字、尺寸及保留区域 |

- 选中图或截图只作定位线索，不代替完整回写源。结合节点标识、素材地址及语义职责锁定唯一目标；不唯一时暂停该部分并确认，不凭相似度猜测。
- 当前成品是编辑目标，母版是身份参考；仅修改母版本身时二者重合。截图、低清预览不冒充母版。工具无法同时接收必要输入时说明限制并暂停依赖部分，不以母版替换成品而丢失布局。

### 再分析获准变化

- 局部文字、素材、间距或样式修改沿用有效分析，只建立目标、容器及受影响邻居的基线。新增参考只分析获准继承维度，身份参考不用于推演整页版式。
- 从可见设计恢复整体布局／风格，或获准整体重做且需恢复整体视觉时，按 [reference.md](reference.md) 完成适用分析；简单纯图将结果用于编辑提示词，复杂任务更新同一 Brief；过滤非设计性水印、截图 UI 等干扰，不删除锁定原文或真实身份资产，不扩大权限。

### 明确编辑范围

- 明确编辑目标、依据、可替换内容、锁定尺寸／身份／文案及受影响区域。简单纯图直接写入编辑提示词；复杂任务及代码作品更新同一 Brief 的编辑范围，不另建文档。
- 未授权 DOM、文案、身份资产、画布尺寸、交互及层级不变。只改目标与获准局部关系；需改变未授权邻居时先说明影响并确认。仅整体版式、背景或多数元素获准变化时整页重建，不静默另起设计。
- 电商局部改字只动点名文字及最小容纳范围，优先换行、文本框与局部间距，不重做商品、背景、其他卖点或全局风格。
- 替换优先落入原文本框、数据位及图片位。空间不足时，仅在获准范围内凝练未锁定文案、调整容器或复用同类组件；仍放不下则报告冲突，不静默扩围。
- 事实核验、缺失处理与设计扩写统一按 [common.md](common.md)，不补造事实或承诺，保留锁定原文。
- 用户锁定的尺寸、坐标、色值及其他原始约束原样保留；已有 Brief 时同步目标，新增节点、几何、CSS／SVG、素材版本、消费者及用户要求归最终 HTML 或资产清单，不在 Brief 重复维护实现字段。实现修正不改目标，规划说明不进入可见内容。

## 4. 不同产物/策略展开

### HTML 局部修改与资产接入

- 无需图像处理时只改真实文本、HTML、CSS 或内嵌 SVG，沿用未变实现。组件机制变化时按 [templates.md](templates.md) 用发布 manifest 的稳定键读取正文及依赖，只更新受影响引用，不按名称盲抄。
- 准确文字保持真实 DOM；价格、SKU、规格、日期、单位及促销／服务条件保持原生可编辑。Logo、二维码、CTA 独立可替换，不擅改内容、含义或功能，不烘焙进商品、背景或壳体；Logo、二维码不为可编辑而重绘。
- 如实说明扁平图限制，按最终图编辑或经确认重建，不暗中转换任务。
- 字体沿用符合预览协议的远端首选字体声明及对应 `font-family`、字重和样式；用户要求换字体时替换声明。排版调整按实际文案与布局处理，不检查字体可用性、字形覆盖、加载命中或回退。
- 仅摆放或裁切优先复用原图；改场景、姿态、构图或身份内容时使用获准图像编辑输入，不靠文字重绘相似主体。按用途抠图，完整矩形背景不机械套艺术字规则。
- 素材清单记录输入来源、真实输出引用、版本、Prompt、原定处理范围、DOM 消费者及母版派生关系；尺寸、裁切与透明属性仅沿用已知输入或工具返回元数据，不检测生成产物。HTML 节点实现见 [produce-code.md](produce-code.md)。

### 独立艺术字替换

- 读取准确源文字、原位置、字形、颜色、材质和允许修改范围。需要重新制作过于艺术化的文字时，按 [produce-hybrid](produce-hybrid.md#独立艺术标题的使用条件) 复用或参考生成透明底字图，结果返回即交付，再按原位置排版；不改变未授权区域。

- 制作与接入方法统一按 [透明艺术字制作规则](produce-hybrid.md#独立艺术标题的使用条件) 选择，不因进入编辑流程而改变方法。仅改位置、尺寸且现有素材有效时直接复用；字图改为原生文字或改变可编辑范围须符合本次授权。
- 仅用对应工具实际返回的真实 HTTPS 地址替换完整 HTML 中唯一目标消费者；不按同 URL 批量替换，不用 Base64、本地路径、预览地址或路径不符文件。保留节点标识、容器、层级及未授权属性。
- 回贴后在完整实际背景上局部复查字色、融合或透明边缘、可读性、对比度及相邻图层。

### 最终图片局部编辑

- 调用前用自然语言明确本轮保留项、改动项、区域、融合约束及最终尺寸，与用户要求及已有方案一致；未点名内容默认保持，不另立权限合同。
- 按 [produce-image.md](produce-image.md) 编译真实输入，名称、编号及参数服从当前工具协议。局改不做全新设计推演，不改写为整图重生 Prompt。
- 直接编辑当前最终图，不拆层或转 Coding；核心身份受权威母版约束并记录派生标识，不以纯文本重绘。
- 生成前将身份、文字、边缘、遮挡、尺寸和未改区域写入编辑提示词；扩画幅须生成新区域，不拉伸原图。图片结果返回即交付，混合素材同样不校验、不设置采用门槛。
- 结果返回即按主入口交付；有依赖的后续编辑沿用真实结果，独立任务可继续。混合素材是否进入组装按 [quality.md](quality.md) 判断。

## 5. 输出形式

- HTML 局改保留未受影响的根节点、画布与样式，按 [produce-code.md](produce-code.md) 核对本次修改及关联影响，不因旧稿未采用当前结构而迁移整页。旧实现确实阻断本次编辑、渲染或宿主接入时，说明具体冲突和所需修改范围；未获授权不扩改，也不把未解决问题判为通过。完整新版本调用 `creative_design_preview`，直接使用返回短链 + RichMediaCard 交付，不以模板背景另起设计系统或用截图覆盖可编辑内容。
- 保留旧版本及可核验派生关系；元数据修改不能代替内容版本保存。完整源、同尺寸完整预览及正式导出须对应同一版本；预览不冒充另行要求的正式图片／视频导出。
- 存储、上传、展示、回读及交付按 [quality.md](quality.md)。能力缺失时说明实际未完成／未验证范围，继续独立可完成动作，不虚构对象、关联或闭环，不把本地文件称为公网资源。
- 所有返回版本均交付并保留，不覆盖或隐藏原图，不筛选素材，不虚报部署或生产验证。只有用户明确提出修改才继续改稿；HTML 检查发现其他问题只作记录。
