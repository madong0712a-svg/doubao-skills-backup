# 图片交付后的可编辑版本制作

**读取方式**：按主入口的任务与阶段指引直接读取本文件；已有内容沿用，仅补读当前任务需要的关联规范。纯图阶段不执行 HTML 专属条款，模板资产仅在实际选中后读取完整正文及必要依赖。

**结果处理（所有场景）**：所有产物返回即按[主入口](../SKILL.md#交付规范)用 RichMediaCard + 真实短链交付；HTML 仅交付 `creative_design_preview` 的设计预览／编辑入口短链，不交付源文件。非 HTML 产物一律不做产物校验，包括混合素材和拼接结果。HTML 可检查，但检查不延后交付；只有符合 [quality 单轮溢出例外](quality.md#内容溢出允许增长长度的有限例外)的 HTML 可自主增长长度，同一任务最多一轮。该例外优先于本文件中只记录、不自主改高或重排的一般限制；除此之外，必须用户明确说改才改。不得因效果不好自主重生、修图、替换或重排。继续完成原定未完成产物和首次预览，不擅自增加优化轮次。

**HTML 规则**：仅在用户明确要求或同意可自由编辑时，才生成或修改 HTML 及相关产物，已有明确意愿直接沿用。预览必须调用 `creative_design_preview`，仅使用该工具返回的设计预览／编辑入口真实短链，通过 RichMediaCard 交付。HTML 只作为内部实现文件，禁止交付 HTML 文件、源码附件、打包源文件或下载链接。字体使用 head 内声明的豆包 CDN 远端首选字体及对应字重、样式，系统字体仅作备用，禁止检查字体可用性、字形覆盖或加载命中。 HTML 复刻以用户选中的图片为准，尽量保持风格、排版、布局和字体，题材默认样式不覆盖原图；艺术字按[混合制作](produce-hybrid.md#独立艺术标题的使用条件)复用或参考生成透明素材后排版。

负责可编辑意愿承接、参考复刻与素材分工。授权和产物处理遵循[主入口](../SKILL.md#交付规范)：结果返回即交付；非 HTML 产物不验收，HTML 检查默认只记录；仅 [quality 的单轮溢出例外](quality.md#内容溢出允许增长长度的有限例外)可自主增长长度，其余须用户明确要求修改后才处理。字体声明豆包 CDN 远端首选字体，系统字体仅备用，不增加字体可用性检查。

执行顺序：确认参考与编辑范围 → 判断各类内容的复刻路径 → 确定实现方法并补齐同一 Brief → 处理素材与组装 HTML → 预览交付。以下方法用于生成前规划、首次实现或用户明确要求的修改。

图片阶段只加载下文“追问与承接”；用户同意自由编辑后，主入口一次加载完整复刻、模型、字体、生产及预览规范，已加载内容不逐链补读。

## 1. 判断复刻路径

### 追问与承接

- 用户已明确要求或同意可编辑时直接沿用，不重复询问；已有完整源按 [edit](edit.md) 修改，不重新生成一套图片。未同意时不启动 HTML，编辑选项也不作为图片制作前置。
- 仅当当前题材规范明确提供可编辑版本建议时，在本次图片全部交齐后按对应问句询问一次；不因借用其他题材规范而触发。明确拒绝、已问未答或仅要求修改位图时不再问。详情页确认版本超过 6 屏时，不主动询问是否需要可编辑版本；用户已明确要求或同意可编辑时仍直接执行。屏数按确认版本的内容屏计，不按素材、制作切片或拼接后的文件数计。
- 使用当前可用的交互工具提问，没有工具时在交付文字中询问。只澄清影响制作的缺口，不重新做需求问卷。
- 采用用户选中的图片及版本；仅有一套且范围明确时直接沿用，多个候选无法确定时只问采用哪版。记录其引用、准确原文、尺寸及页序，不把照片内部像素承诺为独立图层或矢量。

### 基线与已有 Brief

- **图片与记录分工。** 直接理解已可见的选中图片，禁止再次调用读图工具；读取对应已有 Brief：图片确定可见布局与效果，Brief 提供准确文案、规格、页序、来源、身份及锁定项。用户最新明确要求优先；旧方案不覆盖选中版本，图片错字不覆盖确认原文。无法确定的事实、版本或锁定项冲突只暂停相关部分并澄清。
- **交付单元一一对应。** HTML 复刻以用户确认版本的最终交付单元为准，保持产物数量、顺序及页／面／屏边界，每个单元分别制作一份完整 HTML，再按 [canvas-delivery](canvas-delivery.md) 逐份调用预览、逐项交付；不将多屏合成一个 HTML 提交，也不自行合并、拆分或增减确认单元。用户仅指定部分时只复刻该部分，明确要求调整时再变更。制作过程中的切片、素材和未选候选不计入最终交付数量。
- **沿用已选视觉。** 保留构图、字体气质、配色、图文比例、密度和阅读顺序；区分满幅、图窗、开放排版与容器，不套新模板将场景改成卡片，不另增 KV、封面批准或页数。

### 确定编辑范围与实现方式

已有完整可编辑源按 edit 修改；原生矢量、专业刀模或特定格式先确认真实能力，不以位图或 HTML 冒充。图片转为可编辑版本时，先确定实际编辑范围，再按原图结构选择以下路径。同一屏可以组合使用，同一对象不重复铺底与拆出。

| 原图结构 | 复刻路径 |
|---|---|
| 满幅场景、主体融入背景、完整产品组合或地图拼贴 | 主体与背景默认保留一层，局部去除需重建的页面文字，再按原文字区域渲染。已确认满幅详情页按下文“满幅详情页复刻”执行，不改成纯色底＋产品图窗 |
| 原设计已有明确照片窗、局部特写窗 | 复用原照片或沿原图窗边界裁取，保留环境、比例、取景与主体大小；窗外文字单独渲染，不将完整场景自行拆成多个图窗 |
| 表格、菜单列表、参数、基础线框与连线 | 原生重建文字和规则图形，保持原行列、分组、位置及内容对应；配图按前两条处理，不重新分类或统一套网格 |

**拆层仅按实际需要。** 用户明确要求独立移动、替换某对象，或确有跨层遮挡需要时，才分离必要部分。主体轮廓独立、背景简单、视觉分散或方便定位都不是拆层理由。需与背景融合的拆出对象使用透明素材，带底色、残字或邻近对象的矩形裁片不能直接贴回；已有独立照片则保留其原图窗，不先合后拆。

纸张、标签、印章等承载面的材质、边框和阴影随背景保留，文字按其局部坐标及角度渲染；普通文字用 DOM，艺术标题沿用下文透明字图规则。可编辑范围如实说明：整体保留的背景内部对象不承诺独立编辑，独立字图也不承诺逐字编辑。

- **图片不能降级为代码图标。** 有具体造型、笔触、描边、明暗或材质的图像元素，不能因简单、小巧而归为基础几何；不得用 SVG、CSS 拼形、Canvas、emoji 或通用图标仿画替代。基础几何指参考本就是规则色块、边框、分隔线和确定性图形；已有真实 SVG 资源可原用途复用。用户明确要求矢量／代码重绘时才调整实现，并说明能力边界。

## 2. 具体执行方法

### 依据选中图片进行 HTML 复刻

先落实原图的区域结构与内容对应，再按下列对象类型处理素材、组装文字和细节。复刻沿用原画幅、页／屏边界、栏目位置与顺序，保留并列、跨栏、嵌套及局部错落关系；不因内容属于同一类别而重新归并成列表或网格，不将各区统一成居中标题和等距卡片。题材默认排版、模板及内容整理规则不覆盖选中图片；用户明确要求的变化只作用于对应范围。

在结构内保持主要图文的相对大小、对齐、疏密和前后遮挡，不只保留模块数量与阅读顺序。先确定主要区域与可见主体占位，再按完整文案安排文字；原图中有意叠压的装饰可以保留，不能新增对文字或原本完整可见主体的遮挡。具体位置与尺寸按本章已有几何方法落实，选定路径写入同一 Brief，不增加逐元素标注或新的前置审批。

#### 简历、菜单与详情页的排版重点

- **简历：正文尺度与内容密度。** 以参考的正文可见大小、栏宽、行数及模块间距安排经历、教育和联系方式，不为塞入模板整体缩字，也不以均匀分配剩余高度扩大组间空白。参考已有的留白保留；确认文案减少时允许自然留白，不编造经历、重复内容或随意放大文字撑满页面。文案增加导致容量冲突时按“文字占位与避让”处理。
- **菜单：先容纳完整栏目。** 保持栏目所在区域及图文分组，先在该区域扣除标题、边距和图片占位，再按完整菜名、说明、价格与单位安排各行。换行计入行高，价格与对应菜名绑定，列宽合计不超出可用宽度；不靠连续空格或点号撑开对齐。保留参考引导线时用可伸缩线段承接剩余宽度。原图错落、跨栏关系不因统一行列而重排；完整内容确实放不下时记录具体冲突，不隐藏末项、把栏目移到页外或自行拉长画布。
- **详情页：按确认屏独立复刻。** 确认版为分屏时，每屏分别依据对应的可见参考，已可见图片禁止再次调用读图工具，以该屏左上角、宽高和区域关系确定局部布局，独立组装完整 HTML；不先制作整条长 HTML 再切屏，也不让上一屏的内容高度推移下一屏。各屏共用已确认的字体、颜色和必要背景连续关系，但分别保持主体占比、对齐轴与边界。只有拼接展示图时，沿用已有 Brief 的确认屏界；边界不明才澄清，不自行等高切分。确认版原本为单张长图时仍按一个单元处理，交付调用沿用第 1 章规则。

#### 满幅详情页复刻

用户已要求可编辑复刻，且确认版 Brief 将该屏标记为满幅时，以对应确认屏原图作为背景基线。保留整屏的产品、环境、装饰、纹理、光影及接触关系，禁止擅自改为纯色背景＋产品图窗，不默认抠出产品或重建场景。Brief 与选中版本冲突时先澄清受影响屏，不套用其他布局。

1. **在原图定位文字。** 去字前，以该屏左上角为原点、原屏宽高为基准，为每个需重建的页面文字块确定 bbox（x、y、宽、高），绑定准确文案、字级、对齐和断行。按标题、段落或标签成组定位，不逐字拆框；只记录文字区域，不扩为全元素标注。沿用已有 Brief，精确坐标落实到 HTML，不另建几何文件。
2. **局部去字保留满幅背景。** 已有同版本、同构图的无字原底图时直接复用；否则实际传入确认屏原图，使用 **5.5 局部编辑**，一次清除已确定要重建的页面文字。PE 只写“删除／去除＋具体文字及必要位置”；产品包装上的文字、标签、Logo 和必要证据保留，不把去字扩大为去除产品、容器表面或装饰。返回结果作为该屏满幅背景，不重新生成相似场景。
3. **按同一坐标渲染。** 背景保持原画幅和取景，文字 bbox 与背景使用同一缩放比例及原点；普通文字用 DOM 按原字级、行宽、对齐和断行呈现，bbox 是定位与排版依据，不用于拉伸字形。艺术标题按既有透明字图规则处理。只叠加已从背景清除的对应内容，避免重复文字；不得用色块遮字代替局部去字。
4. **按确认屏交付。** 每屏独立组装和预览，保持确认数量、屏序及内容归属。原图或局部编辑能力缺失时说明具体阻塞，不降级为纯色底或产品卡片。用户明确要求产品独立编辑时，仅调整必要图层并保留满幅构图，如实说明背景内部未拆出对象的可编辑范围。

#### 背景与连续场景

- 完整场景、产品与环境、连续光场优先整体复用，保留背景、装饰、纸纹、光影、反射和接触关系，非必要不拆图。确认原区域确为纯色、规则渐变、重复线纹或基础几何后才用 CSS；浅纸纹也属于需保留的材质，不能取平均色后当纯色底。复杂纹理与材质使用图片，不用代码简化原效果。
- **纯色背景取色。** 在选中输入原图的实际背景区域多点取样，避开文字、装饰、边框、阴影、高光和截图界面；以干净区域的代表色写入 CSS，不凭“米白／浅绿”等名称猜色。取样颜色有明显空间变化时先判断是否为渐变或纹理，不强行平均成纯色。
- **规则渐变还原。** 从原图对应区域提取起点、终点及必要中间色，记录渐变类型、方向、中心或范围及色标相对位置；结合原图过渡关系实现，不只取两色就套默认渐变。重复线纹分别确定底色、线色、间距和方向；透明叠层取到的是合成色，不能将该色再叠同样透明度造成二次变淡。
- **取色落实到实现。** Brief 简记取色区域、背景类型和保留关系，准确色值与渐变参数直接写入 HTML；同一连续背景共用参数。仅对输入参考取色，不追加生成素材检测；输入不足时注明估计，不称精确取色。纸纹、复杂光影及插画装饰随背景图片保留，不用取色或 CSS 噪点替代。
- 底图混入需编辑文字或容器时，优先找回无字原素材或独立层；否则以选中原图为输入，使用 **5.5 局部编辑**，只清除需原生重建的指定文字；容器表面只有在明确需要替换时才清除。纸纹、撕边、印章、装饰框及其阴影保留，再在原位置重建文字或必要的布局框。保留区域外的装饰、纹理、光影和构图，不重新参考生成整张背景；原图缺失或局部编辑能力不可用时说明具体缺口。跨屏背景按本章“图片框、可见主体与连续背景”共用坐标。

#### SVG、容器与规则图形

- 规则容器、基础几何、准确图表与连线用 DOM／CSS／适用 SVG；文字与容器分离，按职责设节点，不强拆每条边和阴影。复杂材质表面保留图片；透明 DOM 布局框可承载文字而不重复绘制已有表面。普通原生容器也须沿用参考的切角／圆角、边框层数与线宽、内边距、底色透明度和阴影，不能一律套圆角卡片。
- 已有 SVG 优先复用；需编辑节点时直接内嵌 `<svg>`，保留命名空间与 `viewBox` 并等比显示，`fill`／`stroke` 管样式，CSS 管位置和尺寸；同页 ID 唯一并保留对应内部引用，装饰节点加 `aria-hidden="true"`，确为对称的图形可镜像复用。仅作静态图片引用时使用真实 HTTPS 地址，不用 data URI；内部 `url(#id)`、`href="#id"` 保留，不当外链删除。

#### 普通文字 coding

- **先判字形类别，再判视觉字重。** 分别判断标题、正文、标签和数据在参考中属于粗体／中等体／细体，结合笔画粗细、字腔与整体黑度选择同类字体的真实字重，标题默认使用粗体；参考图明确呈现中等体或细体、或用户另有要求时按其执行，不把宋体一律当细体。CSS 数值以字体清单实际支持的字重或范围为准，不将不同家族的同一 weight 视为等粗；Brief 记录各文字角色的视觉字重与选定声明。
- **文字占位与避让。** 首次组装用准确文案、选定字号字重、行宽和行数安排完整文本高度；列表包含全部条目、换行及条目间距。有效期、电话、地址等相邻组按前一组实际排版占位及参考组间距定位，不按固定猜测的 top 覆到正文上。容器内保留文字与边框、装饰及相邻文字的净空，描边和阴影也计入可见边界；文字及末行须落在所属内容区和画布可见范围内；容器裁切仅用于参考原有的照片窗或装饰边界，不用 overflow 隐藏正文、数据或必要主体。字号依参考与所选字体确定，不为塞入固定框而单独缩字、压行距或删除内容。准确文案在原结构内确实无法容纳时记录容量冲突；仅当该冲突使首次实现无法继续时澄清允许调整的范围，不默改栏目位置、画幅或页数。预览发现的问题只记录，不据此自主修复。
- 普通标题、正文、标签与数据使用准确原文和 DOM；圆润字体配圆体、黑体配黑体、宋体配宋体。保留字重、宽窄、字号关系、行宽、行高、字距与语义断行，按内容组编辑，不逐字拆无关节点。先依据原图文字可见字高、整行宽度、行数和行间距确定排版；像素字高不是 CSS font-size 的直接等值，结合所选字体形态估算并注明不确定项，不统一套默认标题／正文档位。短标题、日期和标签保留原行数；按语义组织日期、括号内星期及数字单位，避免不必要的组内拆行，但不对整段文字强设 nowrap 而造成横向溢出。长段落在文案未变时沿用原行宽及断行位置；数字与单位保留各自大小和基线关系，普通文字的描边、阴影及轻量渐变用原生样式实现，不仅因有这些效果而转字图。
- **字体按三类实现。** 普通圆体、黑体、宋体等用原生 DOM；从现有字体清单选对应类别的真实资源，在 head 内声明豆包 CDN HTTPS `@font-face`，使用同名字体及对应字重、样式，系统字体只作同类备用，不猜造地址、不做字体探测。合规资源仍须匹配原字体类别与粗细、宽窄；缺少同类资源时记录具体缺口，不默换另一类别来通过预览。已有合规声明直接复用；特殊笔画、变形或复杂材质标题按“艺术标题”使用透明字图。普通文字不转图片或 SVG 路径来锁定字形。
- 沿用参考字号与阅读层级，不通过拉伸文本框替代字形排版，不启动字体可用性检查；回退可能改变字宽和断行。仅需新增字体选型、真实资源声明实例或阅读尺度细则时查 [fonts](fonts.md)，不因普通字体填写重复跳转。

#### 配图与独立主体

- **独立照片窗。** 优先复用原始照片；只有整图时可沿原照片窗边界裁出，保留照片本身的环境、餐具及取景，不带入窗外文字或装饰。保持照片框在页面／卡片中的宽高占比、可见主体大小和裁切方向，不改成统一小缩略图，不默认抠成透明底或生成相似替代图。这与开放背景上独立主体的带底裁片不同。
- **确需拆出的主体。** 主体融入背景且没有独立照片窗时，默认与背景整体保留。仅满足第 1 章拆层条件的对象进入透明素材处理：优先复用透明素材；有完整独立源且只需去底时使用专用抠图；只有整页参考、混有页面内容或缺少可用独立层时，实际传入对应参考，用 **5.5 生成或编辑透明底素材**。按工具真实协议选择模型及透明输出参数，不只在 PE 写“透明底”，不猜造参数；工具能力或明确返回不支持时说明缺口，不将带底图或棋盘格图当作透明成果，也不自动追加加工。完整场景及无需独立操作的装饰仍整体保留。
- **单品与组合一致性。** 单品锁定原轮廓、食材／部件层次、容器、视角和光影；套餐、分享桶等按完整组合传参考，明确可见成员及数量、前后遮挡和托盘／包装关系，不按品类名另造相似商品或重组套餐。确需补充独立透明素材时，PE 只包含本素材，排除页面文字和无关环境；要求完整主体、保持原宽高构图并只留必要边距，保留贴近主体的自然阴影，外围真正透明。

- **结构说明类主体插画。** 细胞、器官、设备剖面等具有具体轮廓、内部构造和材质的主体，默认随原背景整体保留；确需拆层时优先复用对应完整透明素材，缺少可用独立层时，传入原图对应参考，用 **5.5 生成透明底主体**，保持视角、比例、配色及内部结构关系，不用 SVG／CSS／Canvas 重绘，也不因属于信息图而归为基础几何。主体及其放大图按原布局分别组织，各自内部结构整体保留，不逐部件拆散。
- 拆出或补充的主体素材不烘焙页面标题、外部标签、公式或标注线；这些内容用原生文字和规则线条实现，连线锚点对应实际被标注结构。Brief 列明每个主体、参考区域、5.5 透明输出路径、保留结构、放置区域及标签／锚点归属；已有透明素材直接复用，不为模型分流重生。

#### 艺术标题

- 按 [produce-hybrid](produce-hybrid.md#独立艺术标题的使用条件) 结合原生图 PE 与看图判断，优先复用对应透明字图；需要补充时传入真实参考生成透明字图，保留准确文字、字形效果及原位置和比例。参考需覆盖完整标题，保持笔画端点、粗细变化、字间节奏、行数和金箔／印刷等材质；按可见字形范围确定放置比例，不能仅让带透明留白的文件框等宽。
- 字图作为可移动、缩放、替换的独立图片层，内部文字不承诺逐字编辑；不把普通圆体、黑体或宋体一律做成字图。

### 拆层与处理顺序

- **只分离所需内容。** 原生文字或容器接入后，底图不能仍烘焙同一内容；禁止整图铺底再覆字冒充完整可编辑。页面文案与场景内实物文字分开，包装字、标签、Logo 和必要证据继续保护，不因拆层替换指定身份。无法分离时如实说明编辑范围。
- **操作提前确定。** 必要处理及依赖顺序写入第 3 章的生产路径，可一次完成的已规划编辑合并执行；输入或能力缺失时说明受阻项，不临时改用带底裁片或代码仿画，也不在结果返回后自主追加修图。

### 承载面、共享几何与组装

以下计算用于首次组装或用户授权修改。只测量选中的输入参考；新返回素材使用已知规格及工具元数据，缺失部分记录假设，不额外检测图片。按实际出现的关系使用，不强制为每个元素填写全部参数。

#### 原图基准与比例换算

- **先确定作品区域。** 排除截图 UI、展示外框和非作品留白，以作品左上角为原点，X 向右、Y 向下。并排页、拼图和长图先确认真实页序与边界，不把展示间隔算入作品；低清、裁切或透视参考不冒称精确测量，隐藏区域保持未知。
- **位置与大小使用同一基准。** 原作品为 W×H，未旋转元素框为 (x,y,w,h)，相对值为 (x/W,y/H,w/W,h/H)。同长宽比目标为 W′×H′，统一倍率 s=W′/W=H′/H，得到 (sx,sy,sw,sh)；字号、固定行高、间距、边框和圆角按相同尺度转译，无单位行高不重复缩放。归一化值用于定位依据，不将旋转后的外接框误作原始尺寸。
- **变比例不是拉伸。** 目标长宽比改变时，不分别按横纵倍率拉伸主体和文字；按用户授权保留主次、对齐轴、图文关系与边距，明确采用留边、允许裁切或重新排布。锁定结构无法容纳时说明具体冲突，不默改画幅、删内容或增页。
- **先锁定主要布局锚点。** 在同一原图基准下确定标题外框、各栏边界、主要图片框、各模块起止位置及页底位置；保留外边距、栏间距、组间留白和图文面积比，不只复刻“左右两栏／上下几块”的结构。内容未变时不重新分类、去重、删小字或改变标签行数；名称、图片、数值和单位保持对应，不按常识自行纠正价格、热量或图文配对。确认文案以已有 Brief 为准，模糊或冲突内容记录待确认，不自行补造。
- **先确定对齐与间距关系。** 找出标题、正文、图像的左／中／右对齐轴、共用基线、栏宽、组内和组间距，再定位节点；按参考关系选择布局方式：规则行列可用固定轨道的 flex／grid，拼贴、叠压或旋转内容使用局部定位；两者均落实已测位置与尺寸，不让自动换行、space-between 或内容自然增高重新分配原图间距。普通文案按原字级、行宽、行高、字距和语义断行复刻，不用拉伸文本框代替字形排版。

#### 承载面与共同变换

- **文字属于具体容器或场景净空。** 扣除边框、内边距、折角、夹子、袋口及前景遮挡后确定内容区；记录对齐轴和局部位置。容器整体定位，内容相对其内表面排布，不能只因文字落在外接矩形内就认定可用。印章与章内文字、纸条与日期等明确为同一定位组；即使承载面保留在整张背景中，也建立对应局部框，避免文字脱离承载面。
- **旋转围绕同一轴心。** 先在未变换的局部坐标中排好容器、文字、图形和连接点，再统一应用缩放、旋转或必要的透视。二维旋转时，局部点 q、局部轴心 o、目标轴心 P、统一倍率 s、角度 θ 满足 `q_world = P + s·R(θ)·(q-o)`，其中 `R(θ)=[[cosθ,-sinθ],[sinθ,cosθ]]`；屏幕 Y 向下时正角与 CSS 顺时针一致。轴心由承载面决定，不机械取图片框中心。
- **共同变换只做一次。** DOM 父容器已有变换，子元素只填局部位置及自身相对角度 φ，不再写世界角 θ+φ；若直接计算世界坐标，则不再重复父变换。图片内承载面已有倾斜时，节点仅补目标与已有方向的差值。透视、偏斜不以角度相加代替，按同一平面映射组织内容。
- **只让实际成员跟随。** 独立贴纸、照片和阴影不自动归入邻近平面；原图正文水平时不因手绘装饰而倾斜正文。层叠必须保留文字、容器、主体的原有前后关系，不靠提高 z-index 绕过袋口、夹子或主体遮挡。
- **连线绑定锚点。** 标注、箭头和连接线的端点绑定所属对象的局部锚点，与对象使用相同变换；不绑定旋转后外接框的猜测位置。线经过的路径避开文字和关键主体，缩放或移动对象时同步必要端点。

#### 图片框、可见主体与连续背景

- **区分图片框与主体范围。** 按原图可见主体的外框记录其占所在栏／容器的宽高比例及中心或底部锚点；透明留白不计入商品大小，不以统一 img 尺寸替代不同主体的目标占比。已有素材记录或工具元数据给出内部主体框时，按主体框计算等比缩放和偏移；如内部主体宽 bw、目标可见宽 Tw，则倍率为 Tw/bw，整个文件与主体偏移使用同一倍率，再核对已知高度约束，不分别拉伸宽高。新素材无主体范围元数据时依已规划紧凑构图估计并注明假设，不启动 Alpha 或边缘检测；目标尺寸仍沿用原图，不为迁就文件留白缩小版面中的商品。
- **计算等比适配与偏移。** 已知素材尺寸 Iw×Ih、容器 Cw×Ch：contain 的倍率 k=min(Cw/Iw,Ch/Ih)，cover 为 max；显示尺寸为 Dw=kIw、Dh=kIh。以比例位置参数 ax、ay（0 为左／上，0.5 为居中，1 为右／下）计算偏移 `dx=(Cw-Dw)ax`、`dy=(Ch-Dh)ay`。素材点 (u,v) 在未旋转容器中的位置为 `(dx+ku,dy+kv)`，再按容器变换到作品坐标；cover 的负偏移表示裁切，不是额外留白。
- **取景保护已有关键内容。** 按输入参考和规划的保护区安排 contain／cover、object-position 或背景位置；人物面部、产品识别面、Logo 和必要证据不因套框被裁掉。不能为对齐主体而非等比拉伸整张图片，也不因局部定位方便而拆散完整场景。
- **背景保持同源坐标。** 连续场景、光场、纹理和渐变共用完整范围与参数；第 n 屏的全局起点为前面各屏高度之和，全局内容位置换算到该屏时减去起点，不在每屏顶部重启背景。仅在原图确有边界时分区，不按段落硬切或添加过渡色带；已有纹理、框线和阴影不重复绘制。

#### 记录与实现边界

同一素材复用一条真实来源记录，各放置节点分别保留稳定 ID、容器归属、位置、裁切和层级；改单个位置不自动换掉全部引用。背景、平面及图文关系写入已有 Brief，来源、版本和消费者沿用 asset-manifest；精确坐标、旋转轴、色值及 CSS 留在 HTML，不另建几何清单或平行 manifest。

按 [produce-code](produce-code.md) 组装完整固定画布。以上方法落实参考关系，不增加素材数量、不改变已确定的文字与容器拆解范围，也不替代既有预览及交付规则。

选中图片作为制作依据，已可见时禁止重复调用读图工具；不用于打分、筛选或自主返工；新返回素材按原定用途接入，不新增质量、透明度或尺寸准出检查。新增方向、扩大范围或不可替代的输入缺口按主入口处理。

## 3. 落实到 Brief

### Brief 中的生产路径

- **唯一 Brief 逐区落实。** 按 [reference](reference.md) 记录准确文案、页／区类型、具体布局、相对位置与尺度、对齐间距、字体层级与断行、色彩职责、光材装饰、图文归属与遮挡、背景连续范围及编辑边界。主要内容组沿用已有相对位置与大小依据（如 x/W、y/H、w/W、h/H），缺失时只补影响整体布局的区域；简记区域间的并列／嵌套关系、关键图文占比、文字行数及保留的素材表面，角度等仅在实际涉及时记录。同类重复项可共用尺寸并列出位置，不要求为背景装饰逐个标框。注明来源区域、保留项、获准变化与未知项，不以“同原图／其余同理”代替安排。已有内容复用，只补缺口；没有 Brief 时按 [common](common.md) 建立，不另建模拟 query 或平行几何文件。

每项素材或同类原生内容组写清：**对象与位置 → 来源／版本 → 制作方式及必要处理 → 输出形态 → HTML 用途与依赖**。生成项注明模型、实际工具能力及保留／排除项；必须写出本次具体内容及选定路径，不仅写“背景／配图／混合制作”，也不把“复用／抠图／生成”并列留待执行时选择；同路径内容可成组列明，不同处理分开记录。受阻项注明缺少的输入或能力。背景项列清删除对象及保护范围；DOM 项列准确文案、首选字体及清单资源；SVG 项写内嵌 DOM 或 HTTPS 图片引用；图片项写明照片窗／开放底／完整组合分类、来源、选定处理方式、透明输出参数（如需生成）、锁定成员与数量、可见主体占比及锚点；艺术标题列准确文字与参考。只记录本次涉及的内容，已有记录引用即可。模型统一按 [model-adapters](model-adapters.md#html-复刻补充素材的模型选择)：HTML 复刻新增透明素材、背景局部编辑用 **5.5**，非透明独立配图补充用 **5.0 Flash**；已有素材不为模型分流重生。

将第 1 章的路径判断和第 2 章选定的方法写入各页／屏对应内容组：背景覆盖范围、局部清除区域与保护内容、需拆出对象及拆分原因、文字与容器实现、图片复用或处理方式、SVG 接入方式、艺术标题来源及图文层级。各页／面／屏按第 1 章“交付单元一一对应”落实，Brief 与最终产物逐项对应。补齐这些决定后才开始素材处理与 HTML 组装，不等制作结束再补写。

### Brief → PE → HTML 的对应关系

- **PE 只承担当前素材。** 背景局部编辑的 PE 只写“删除／去除＋具体对象及必要位置”，如“去除中央标题和下方两个时间框”，不展开背景、风格或构图描述。其他新增生成／编辑的 Prompt 从 Brief 提取对象、身份、构图、视角、相对尺度、光材色彩、净空、遮挡及连续关系，转为可直接提交的自然语言。透明要求随素材路径传递；不整段复制页面 Brief，不把 DOM 文案、容器排版或代码参数烘焙进普通配图。艺术字只带对应准确文字与效果，场景实物文字按身份保护；指定数量沿用主入口 grounding。
- **参考实际传入。** 明确编辑目标、身份、构图或材质参考的用途，按稳定序号实传必要图片；只说“参考原图”不算工具输入。选择足以表达本素材的参考，不夹带无关页面内容，不因局部补图更换主体身份。描述以中文为主，准确原文和协议参数保留原值。
- **记录与实现对应。** 用现有 asset-manifest 关联“Brief 页／区 → 素材与实际完整 Prompt → 返回版本 → HTML 消费节点”，不以草稿冒充实际请求、不预填未来结果。复用项保留真实来源，代码项直接落实节点，均不虚构 PE；无新增图像操作不调用生图。模型适配仅改变表达，不丢失保留项或扩大范围。精确坐标、样式与变换留在 HTML，不另建记录。

## 4. 组装与交付

进入 HTML 制作后读取 [produce-code](produce-code.md)、[quality](quality.md) 和所需字体规范；混合素材按 [produce-hybrid](produce-hybrid.md) 执行。模板只辅助获准的局部实现，不为复刻重新选版。

各页／面／屏保存完整内部 HTML，调用 `creative_design_preview` 后立即以真实设计预览／编辑入口短链＋RichMediaCard 交付，具体按 [canvas-delivery](canvas-delivery.md)。不发送 HTML、源码包或下载地址；工具失败或缺少短链时说明未完成项，继续其他已确定工作。

原图片、完整源及历史版本内部保留。说明真实可编辑范围；HTML 检查只记录问题，不扣留结果、不自主返工，用户要求修改后才更新指定范围并生成新预览入口。
