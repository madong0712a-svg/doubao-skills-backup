# 字体与排版

**读取方式**：按主入口的任务与阶段指引直接读取本文件；已有内容沿用，仅补读当前任务需要的关联规范。纯图阶段不执行 HTML 专属条款，模板资产仅在实际选中后读取完整正文及必要依赖。

**结果处理（所有场景）**：所有产物返回即按[主入口](../SKILL.md#交付规范)用 RichMediaCard + 真实短链交付；HTML 仅交付 `creative_design_preview` 的设计预览／编辑入口短链，不交付源文件。非 HTML 产物一律不做产物校验，包括混合素材和拼接结果。HTML 可检查，但检查不延后交付；只有符合 [quality 单轮溢出例外](quality.md#内容溢出允许增长长度的有限例外)的 HTML 可自主增长长度，同一任务最多一轮。该例外优先于本文件中只记录、不自主改高或重排的一般限制；除此之外，必须用户明确说改才改。不得因效果不好自主重生、修图、替换或重排。继续完成原定未完成产物和首次预览，不擅自增加优化轮次。

本文件的构图、文字和素材安排用于生成前规划或用户明确要求的修改；读取参考用于理解输入，不用于重新验收本次返回的非 HTML 产物。

**HTML 规则**：仅在用户明确要求或同意可自由编辑时，才生成或修改 HTML 及相关产物，已有明确意愿直接沿用。预览必须调用 `creative_design_preview`，仅使用该工具返回的设计预览／编辑入口真实短链，通过 RichMediaCard 交付。HTML 只作为内部实现文件，禁止交付 HTML 文件、源码附件、打包源文件或下载链接。字体使用 head 内声明的豆包 CDN 远端首选字体及对应字重、样式，系统字体仅作备用，禁止检查字体可用性、字形覆盖或加载命中。 HTML 复刻以用户选中的图片为准，尽量保持风格、排版、布局和字体，题材默认样式不覆盖原图；艺术字按[混合制作](produce-hybrid.md#独立艺术标题的使用条件)复用或参考生成透明素材后排版。

## 1. 概述

统一字体选型、文字层级与阅读尺度。HTML 制作声明并使用豆包 CDN 远端首选字体，不检查字体是否安装、可用、覆盖全部字符或在目标环境命中，也不把这些检查作为预览或交付前置。

## 2. 使用场景

- **字体建议**：按语种、形态、角色和阅读状态选型。
- **图像内文字**：描述字形、重量与搭配意图，不承诺精确 family，不安装字体或另生成试排图。
- **HTML 排版**：用户明确同意自由编辑后，将所选字体、字重和样式直接写入 CSS；准确文字保持原生，完整实现见 [produce-code](produce-code.md)。
- **已有品牌或参考**：保留用户指定的字体及形态；未知字体只描述可见笔画，不冒充识别结果。

## 3. 核心流程

### 确定条件与候选

- 按准确文案、语言、品牌、角色、参考和阅读尺度选择字体；用户指定字体优先，已有方案直接沿用。
- 需要比较时通常保留 2–3 个视觉候选，明确命中时直接采用；不为凑候选数改变语种和风格。
- 默认使用一至两个协调家族，用字号、字重、行高和间距建立层级，不逐模块更换字体。

### 查询与分类

- 需要选型资料时使用 `scripts/select_fonts.py` 查询候选，也可直接读取 `assets/fonts/font-curated-pool.json`。先用 `--list-themes` 或 `--list-tags` 查看已有分类，再按实际主题、字形特征、语言与文字职责查询；例如 `--theme <已有主题键> --role body --language zh --limit 3`。`font_key` 是索引键，CSS 使用对应字体名称。
- 查询脚本只依赖 Python 标准库及包内字体候选池、字体目录 JSON 和 `web-font-manifest.json`。返回 `web_font_resources` 中的真实 family、URL、字重、样式与格式；`web_manifest_listed` 表示当前清单已登记，不代表实际加载成功。无明确映射时返回 `web_mapping_missing`，仅供风格参考，不直接用于 HTML 字体声明；`--available-only` 仅筛选已有 Web 映射的候选，不检测网络或本地字体。
- 默认按主题或字形特征查询。可选 `--combination` 使用模板索引与已有配方映射；绑定不可用时查看 `binding_diagnostics`，再按实际主题／字形查询，保留语言、文字职责和用户锁定条件，不自动放宽条件或伪造绑定。用户锁定字体缺少声明资源时说明具体缺口，不擅自替换。
- 查询用于字体选型及已有资源声明；不进行字体下载探测、字形覆盖、许可状态或目标环境加载检查来判断是否允许填写。

### HTML 字体填写

- 在 `head` 内用 `@font-face` 声明豆包 CDN HTTPS 字体，并在原生文字中作为首选 `font-family`；系统字体仅作同类备用。按 `assets/fonts/web-font-manifest.json` 读取真实 URL、family、格式、字重与样式，按 `assets/fonts/web-font-policy.json` 的 hostname 与目录前缀选择资源；不拼接猜造地址，不使用 local、本地、相对、data 或 blob 字体来源。保留字号、行高和字距。已有声明符合此要求时直接沿用。
- 禁止检查字体可用性、字符覆盖、真实 face 命中或回退结果；不运行 FontTools 检测、CDN 探测或 `document.fonts` 检查，不下载字体验证。
- 可直接设置正常 CSS 回退栈，不通过探测结果筛选字体、重试加载或阻断制作。排版完成后必须调用 `creative_design_preview`，直接使用该工具返回短链 + RichMediaCard 交付。


字体声明示例（地址来自包内字体清单，仅对应思源宋体 CN 600，不作为其他字体或字重的地址模板）：

```css
@font-face {
  font-family: "Source Han Serif CN";
  src: url("https://lf-flow-web-cdn.doubao.com/obj/flow-doubao/doubao/infinite-canvas/fonts/v1/source-han-serif-cn/source-han-serif-cn-semi-bold.otf") format("opentype");
  font-weight: 600;
  font-style: normal;
}
/* 使用该字重的原生文字 */
.serif-text {
  font-family: "Source Han Serif CN", "Songti SC", "SimSun", serif;
  font-weight: 600;
  font-style: normal;
}
```

示例回退栈按宋体类别整理，不代表已检查字体可用性或加载结果。

## 4. 不同产物/策略展开

### 角色、形态与效果

以下为新创作试排参考；复刻采用选中图片的现有层级，不强套倍率。

| 角色 | 职责 | 字重／相对正文大小试排起点 |
|---|---|---|
| hero | 唯一最高焦点、主标题、品牌名 | 600–900；3–6× |
| sub | 栏目、章节、卖点标题 | 500–700；1.5–2.5× |
| body | 连续说明、经历、规则、参数 | 400–500；1× |
| meta | 注释、编号、页码、辅助信息 | 400–600；0.75–0.95× |

- 范围不证明资源有对应实例。价格、核心日期、数据可升为 hero/sub，不因字段名固定小字，也不因重要而用难读展示体。body 禁用书法、像素、黑信体、强装饰字体；`dark_horror`、`street_y2k`、强手写限短标题，不进入简历正文、公告事实、参数、价格或 UI。
- HTML 复刻的普通字／艺术字判定按 [produce-hybrid](produce-hybrid.md#独立艺术标题的使用条件)：原 PE 与看图共同判断，圆体、黑体、宋体对应原生字体，其余标题优先判断是否需透明字图；保留原字重、宽窄、排版及真实编辑范围。
- 黑体不等于粗体，宋体不等于细体；自然手写与书法章法不同，圆角不自动童趣，窄字不自动速度。CSS weight 不跨家族等同视觉重量。按选定样式填写 italic、oblique 或 normal，不做字体实例检查，也不通过横向压缩改变字形。
- 书法、毛笔／软笔、手写、创意分别按 calligraphy、brush／soft-brush、handwritten、creative 判断；普通硬笔、墨感黑体不凭名称归毛笔。气质按需求取交集，“狂放且可爱”无交集时不静默删标签。
- 新创作标题采用一个主要强调机制，细体、细窄和高反差衬线以清晰实色为主，不堆描边、套边、投影或错位重影；粗体不侵蚀字腔或压下一行，正文和参数不继承展示效果。复刻保留参考现有效果，不能据通用配方擅自删减；效果与用户锁定阅读要求冲突时说明具体问题。用户授权调整后，优先减少干扰效果，再调字重、字形与字号，不继续叠加效果补救。

### 字体禁用与条件准入

- `胡敬礼毛笔行书`、`HuJingLi-Mao`、`胡敬礼毛笔行书简.TTF` 及别名禁止候选、精确解析和回退，仅用户明确解除才恢复；不据此删除或卸载系统字体。
- 沐瑶软笔默认不推荐。仅用户明确同时要求“可爱＋毛笔／软笔”的短标题才准入，排在其他合格候选后；国风、山野、非遗、童趣、手写、可爱单独出现均不足。明确点名时直接按对应字体填写；已有 Brief 时记录选型理由，不新增字段表。
- 沐瑶支持可爱、温暖手作，不按狂放或清新毛笔召回；流江草体支持狂放，马善政楷书支持端正传统，莫大毛笔的狂放／可爱／清新证据不足。缺正向标签非永久禁用，也不证明其他类别已审核。
- 得意黑仅在需要倾斜、窄长、尖锐笔势时考虑，不作为通用标题。资源400 Oblique与平台400 italic为不同证据；HTML 直接使用对应名称和样式；受约束 Item 按实际协议填写，不追加字体实例检查。
- 清松第7款不等于第8／9款，第3款繁体样字不证简体覆盖。齐伋各包、CN／SC／TW／VF、轻量版、点阵变体按对应名称区分，不合并实例；龙藏锁定具体版本。Zen Antique仅为日语标题候选，未证明等同“Zen 老式明朝”或覆盖中文。
- Oswald、Playfair Display 按选定名称与样式填写，不挪用另一字体或变体造型；阿里巴巴普惠体目录仅Regular，不推断粗体。寒蝉点阵体不用于正文、价格、事实；齐伋刻本、书法不进入密集正文。

### 主题与产物

- 烘焙／手作区分圆润产品形态与自然笔迹；茶饮／新中式先比宋、明、仿宋、楷与书写，不默认毛笔；时尚／杂志看反差、阅读距离、中英墨色；促销／运动用真实粗体，仅需动态才倾斜；旅行／自然生活不把整段改手写。新中式、杂志编辑、自然生活与原主题共存，不另建排名。
- 简历主题限 `business_pro`、`minimal_modern`、`luxury_elegant`、`retro_classic`、`literary_academic`、`japanese_fresh`。运营公告优先商务／极简，婚礼邀请优先典雅／东方，喜报优先商务／运动力量／东方，节庆按品牌选择。
- Logo字体仅是字标起点，不自动变成VI正文或UI字体；保留本次明确采用的母版。可编辑VI角色进入既定Token、组件与应用，规范样张须用真实字体、字重，图像不冒充精确样张。
- 三折页在既定六面、折法、尺寸内试排，超量先调内容分配、栏宽、行距，不改纸幅或无限缩字。

### 阅读尺度与换算

- 用户、品牌、渠道、制作要求在其范围内执行。屏幕值为最终阅读状态的CSS逻辑像素，纸张pt为最终物理字号，不直接套任意HTML母版。
- 设母版CSS宽W、整张画布在阅读端的实际显示宽V（扣除宿主外侧边距，不扣画布内部留白或正文栏边距）、源字号F、无单位行高L：`s=V/W`，`有效字号=F×s`，`F=目标有效字号×W/V`，`最终行高=F×L×s`。
- 同构图W1→W2时，字体、固定行高、框、间距、坐标、画布高度均乘 `W2/W1`，无单位行高不再乘。改长宽比、仅加高度、改多栏属于重排，不机械缩放。
- 例如360宽16px对应同构图1080宽48px；1080宽仍用16px，缩回360仅5.33px。360不是统一阅读宽度；电商详情页未指定手机阅读宽度时，生成前按390px规划，其他产物按各自阅读条件确定。
- 仅提高采样倍率／DPR不改CSS布局或字号。已知源且整图无额外裁切变形时：`有效字号=F×采样倍率×最终显示宽度/导出像素宽度`。预览缩放只计一次，局部transform另计；首次实现不做非等比字形拉伸，不以根transform掩盖溢出。只有位图时不猜源字号，也不测量或评价生成图片的阅读效果。
- 纸张成品宽M mm、字号P pt：`F=P×25.4/72×W/M`，`P=F×M/W×72/25.4`。M为对应整页宽，非正文栏宽，出血前后不混用。`1in=96px=72pt`；原生A4 CSS宽约793.70px，无额外缩放时12pt=16px。PDF／打印落实物理尺寸及打印缩放；A4比例或截图不能证明pt验收，也不能推断用户要印刷。

| 场景 | 生成前的字号规划 |
|---|---|
| 社媒长图、屏幕连续说明 | 正文16–19px、规划时避免低于16px；辅助14–16px、规划时避免低于14px。旧网页正文／行高16/24px及19/25px、小字14／16px不混为统一要求；标题无28/20px通用硬下限 |
| 简历 | 定尺寸文档10–12pt，中文可从11–12pt起排；必要日期、联系方式沿正文尺度，规划时重点留意低于10pt的情况，不统一放行9pt。姓名不强制24–32pt或最低22pt；A4仅默认文档选择，英文行高1.2仅试排 |
| 菜单 | 手机菜名、价格、关键条件16–19px，辅助14–16px，规划时避免低于16/14px；纸质近读12–14pt、规划时避免低于12pt，暗环境或大字需求再增大。无11/10/9pt角色底线；墙面按已有实体规格、观看距离、视角和亮度资料规划 |
| 电商详情页 | 按最终阅读宽度计算：正文默认16–19px，辅助说明默认14–16px，所有内容文字不得低于13px。手机阅读宽度未指定时按390px规划；13px是下限，不是正文默认值 |
| 三折页 | 按实际成品尺寸：正文默认12pt、不得低于11pt；图注及短辅助说明默认11pt、不得低于10pt；日期、地址、联系方式、价格及使用条件按正文下限执行。数字专用且无物理尺寸时，正文默认16–19px、不得低于16px，辅助默认14–16px、不得低于14px，按实际阅读宽度换算 |
| VI展示板 | 以1600px宽母版为基准：正文默认25–30px，正文、章节信息及主要说明不得低于20px；短辅助说明、图注及来源默认16–20px，不得低于16px。其他母版宽度按W/1600换算，并按目标阅读尺寸规划；效果图内文字不承担展示板说明 |
| 信息图、关系与流程图（数字阅读） | 按实际显示宽度换算：解释正文、节点文字、步骤、关键部件及关系标注默认16–20px，不得低于16px；短图注、图例及来源默认14–16px，不得低于14px。关键条件、单位和必要解释不降为辅助小字。先明确阅读端与显示宽度；无依据时记录阅读假设，不以导出像素代替目标阅读宽度。纸质版本按实际纸幅与阅读距离另定，不直接套屏幕px |
| 其他产物 | 画册定物理尺寸后可从12pt起排；名片、票券、包装无8/9pt统一底线，按各题材和制作要求执行 |

- 上述数值为生成前的设计规划依据，不冒称平台或印刷行业标准。纯图把阅读尺度写入提示词，返回后不校验；HTML 首次实现按这些数值安排，预览发现偏差时只记录，必须用户明确要求修改才调整字号或重排。用户锁定字号或外部规范优先，不检查字体可用性。

- 中文连续正文从行高1.5试排，可比1.5–2；行间空白0.5–1倍不等于CSS line-height，短题、单行金额另测。长说明默认左轴，书刊式中文可两端齐，首次实现遵守禁则并安排末行、中西间距，不拉满短末行或空格凑列。
- 不设统一每行14–24字、固定段距、菜单0.5–0.8／1–1.5倍间距门禁；按条目内、条目间、章节间递进分组。金额独立右轴对齐菜名首行，规格矩阵留列头；简历机构、正文、项目符号共左轴，日期统一右轴或邻接，长邮箱正常换行。
- 仅 HTML 网页可访问性按实际交付目标检查并记录问题，不自动修复；查看用户覆盖行高1.5、段后2、字距0.12、词距0.16倍及文字200%放大适配，非作者默认值；图片文字等有适用例外，WCAG无统一最小字号。静态截图合格不证明网页无障碍合格。

### CSS 回退声明

可在选定字体后填写适合语种和角色的常规 CSS 回退栈；只写声明，不检查实际回退、覆盖或命中，不启动字体失败排查流程。

## 5. 输出形式

远端字体声明、字体名称、字重、字号、行高和字距保留在完整 HTML 中；需要说明设计时简述选型意图，不生成字体可用性报告或字体契约。HTML 预览和交付统一按 [canvas-delivery](canvas-delivery.md) 使用 `creative_design_preview` 返回的短链 + RichMediaCard。
