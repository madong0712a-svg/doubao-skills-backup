# IP角色题材规范

**读取方式**：按主入口的任务与阶段指引直接读取本文件；已有内容沿用，仅补读当前任务需要的关联规范。纯图阶段不执行 HTML 专属条款，模板资产仅在实际选中后读取完整正文及必要依赖。

**结果处理（所有场景）**：所有产物返回即按[主入口](../SKILL.md#交付规范)用 RichMediaCard + 真实短链交付；HTML 仅交付 `creative_design_preview` 的设计预览／编辑入口短链，不交付源文件。非 HTML 产物一律不做产物校验，包括混合素材和拼接结果。HTML 可检查，但检查不延后交付；只有符合 [quality 单轮溢出例外](quality.md#内容溢出允许增长长度的有限例外)的 HTML 可自主增长长度，同一任务最多一轮。该例外优先于本文件中只记录、不自主改高或重排的一般限制；除此之外，必须用户明确说改才改。不得因效果不好自主重生、修图、替换或重排。继续完成原定未完成产物和首次预览，不擅自增加优化轮次。

**HTML 规则**：仅在用户明确要求或同意可自由编辑时，才生成或修改 HTML 及相关产物，已有明确意愿直接沿用。预览必须调用 `creative_design_preview`，仅使用该工具返回的设计预览／编辑入口真实短链，通过 RichMediaCard 交付。HTML 只作为内部实现文件，禁止交付 HTML 文件、源码附件、打包源文件或下载链接。字体使用 head 内声明的豆包 CDN 远端首选字体及对应字重、样式，系统字体仅作备用，禁止检查字体可用性、字形覆盖或加载命中。 HTML 复刻以用户选中的图片为准，尽量保持风格、排版、布局和字体，题材默认样式不覆盖原图；艺术字按[混合制作](produce-hybrid.md#独立艺术标题的使用条件)复用或参考生成透明素材后排版。
目标：将角色使命、性格与用途转化为可识别、可表演、可复现的形象，形成美观且适用的角色产物。
适用范围：题材的内容、布局与阅读要求用于生成前规划、提示词及首次实现；后续调整只执行用户明确要求的范围。HTML、原生层、字体资源与模板条款仅用于已获准的可编辑设计；产物检查仅限 HTML，不检查图片及其他非 HTML 产物。

适用产物：普通IP、角色Logo、影视角色，以及所需设定、传播、衍生和制作参考；单项需求不自动扩为系统。
核心流程：确定用途与边界（第1节）→推导角色造型（第2节）→组织画面与叙事（第3节）→继承身份并衍生（第4节）→按需设计角色Logo（第5节）→适配应用与制作（第6节）→按规格制作并随结果交付（第7节）。

## 1. 确定用途与授权边界
- 事实与需求记录按[共用规范](common.md)执行；单张纯图直接编写提示词，成套角色与衍生方案维护同一 Brief。先确定角色服务谁、承担何种使命、出现于何种载体，以及本次数量、尺寸、文字和授权范围。制作方式与交付遵循[主入口](../SKILL.md)，不以题材方法替代入口规则。
- 区分普通IP、角色Logo与影视角色。普通IP重视持续识别、行为和应用；角色Logo重视符号压缩与名称关系；影视角色重视剧情弧光、表演和可信结构。不得将Logo块面、计色限制覆盖普通IP。
- 新建角色时，从行为和用途推导形象。已有角色时，先辨认物种、年龄段、头身关系、轮廓、五官位置、标志服装、道具、主色和材质；只在授权内调整。局部编辑不得借优化重做全身或更换身份。
- 将参考分别转为比例、形态、材质、配色、构图或情绪方法，不照搬名称、角色及专属组合。用户提供资产不等于已核实授权；不主动引入未提供的受保护IP、公众人物或艺术家名称。
- 品牌、角色用途、风格等信息足以制作时直接做；只有缺少不可替代输入、关键规格无合理默认值或要求冲突时，按主入口澄清。要求从零创作时不因缺少母版阻断。

## 2. 从使命推导角色造型
### 行为、能力与身体
步骤 1：将使命或性格改写为可观察的行为。说明角色面对什么对象、想完成什么事、遇到压力如何反应。用伸手、停步、护住、观察、搬运、回望等动作替代单独罗列性格词。

步骤 2：由行为选择身体能力。判断角色需要抓握、负重、跳跃、潜行还是精细操作，再决定肢体长度、关节活动、手足形态及尾部功能。物种可提供结构起点，不以物种标签代替性格设计。

步骤 3：用重心和惯常姿态表达行为倾向。前探的视线可与后收的重心形成犹豫；低重心、稳定支撑可表达持续守护；高重心和长动作弧线可表达敏捷。根据角色目标选择，不将圆形等同善良、尖角等同反派。

步骤 4：从姿态提炼主剪影，再确定头身关系、五官疏密和识别部位。先看去掉颜色与细节后是否仍可辨认，再补内部结构。保留能支撑动作的颈肩、躯干和关节关系，不让装饰遮住身体能力。

| 条件 | 具体做法 |
|---|---|
| 以小尺寸陪伴、贴纸传播为主 | 可增大面部可读面积，合并细碎肢端；在提示词中明确眯眼、张嘴、转头所需保留的识别特征，不统一规定两头身或粗线 |
| 以运动、任务或道具操作为主 | 给手足、关节和躯干转折留出活动空间；让头身比例服从动作幅度，避免大头遮住操作接触点 |
| 需要安静、克制的情绪 | 减少持续夸张表情，利用视线偏移、肩部松紧和小幅重心变化；不要用无表情替代内在状态 |
| 需要鲜明识别部位 | 从耳、角、尾、发型、衣领或身体缺口中选与能力有关的重点；生成前明确正侧背的结构关系，不把所有部位同时做奇形 |

### 五官、道具与细节
- 先确定眼线、鼻口位置和面部留白，再调整眼形、眉向与嘴角。让五官与头部转面同步，不将正面五官平贴到侧面。用眼睑、脸颊、口部开合和头部倾斜共同表演。
- 为识别部位保留负空间。分开耳与背景枝叶、手与身体、道具与躯干的相似轮廓。缩小后若特征粘连，优先改间距与姿态，不只加描边。
- 让核心道具承担具体功能。说明拿法、收纳位置、使用方向及与身体的尺度关系。需要双手操作时，不同时安排无法完成的手势；偶发场景道具不得自动变成身份锚点。
- 使服装结构符合角色生活环境和动作。先确定穿脱、开合、层次和固定点，再加纹样、徽记与配件。减少无功能且遮挡表情的装饰。

### 配色与材质
步骤 1：划分身体大面、识别部位、服装道具、文字与背景的颜色职责。优先形成一组受控主色关系，不按行业直接指定颜色，也不把多个参考色系混成一套。

步骤 2：先用明度与面积建立主次，再调色相与饱和度。大面负责稳定识别，小面积对比色指向面部或功能部位；背景可随主题变化，但不任意交换角色主辅色职责。

步骤 3：按触感、环境和用途选择材质。柔软表面用宽缓明暗表现体积；硬质装备保留清楚转折；织物沿受力处形成褶皱；磨损集中在真实摩擦、暴露和接触区域。材质不替代结构。

| 条件 | 具体做法 |
|---|---|
| 品牌平面应用需要起始面积关系 | 可试用60–80%主导色、15–35%表面色、5–15%墨色或强调色，再按实际画面调节；不用此比例强制分配角色身体 |
| 深色或夜间场景 | 降低背景局部对比，在面部、手与关键道具附近建立明度分离；控制反光，避免亮斑切碎五官 |
| 两色已能稳定识别 | 不增加无职责新色；确需第三色时，指定其固定对象或状态功能 |
| 毛发、颗粒或高光遮住轮廓 | 减少边缘纹理密度和高光面积，在识别部位保留完整形状；不靠滤镜制造角色特点 |

屏幕色值仅作设计定义。精确继承颜色时，依据用户原图取色；印刷、专色和材料色使用已有真实资料或生产方提供的打样结论，不由屏幕值虚构生产结论。

## 3. 按阅读目标组织角色与画面
### 主视觉、设定卡与三视图
先区分传播与复现任务。主视觉让观者先感知角色气质和主题；设定卡让观者理解身份与能力；三视图让观者比较同一身体的不同方向。

| 条件 | 具体做法 |
|---|---|
| 主视觉依靠核心姿态建立认知 | 先按姿态确定角色占位。可用中心大角色建立直接识别，或用斜向动势引向目标；将标题置于轮廓外或可控遮挡区，避开面部和动作接触点 |
| 主视觉依靠场景建立情绪 | 用建筑、道路、桌面或重复物的透视线引向角色；前景裁切、中景互动、背景环境分层，不以平均细节填满画面 |
| 需要标题与角色并重 | 可用3:7或4:6分区，或偏轴角色配负空间。标题建立第二锚点，不机械居中，也不为留白缩小到失去识别 |
| 设定信息较多 | 按姓名→全身形象→性格/能力→道具与色材组织阅读。用角色区与模块区分栏，将局部放大、标签和色卡接入网格，不把所有内容等权装卡 |
| 设定信息较少 | 放大全身与关键局部，保留浅底和呼吸空间；标签靠近所指部位，用短引线连接，避免穿过五官 |
| 制作三视图 | 将正、侧、背按统一比例和脚底基线横排，对齐头顶、眼线、肩、腰及关节位置；统一观察尺度与站姿，避免透视和动态造成假差异 |

- 三视图表达同一角色，不做三个近似角色。将色卡、标题、视图标签和底部说明移出身体观察区。辅助线降低对比；背景网格、展示框仅在帮助比较时使用。
- 主视觉与设定卡至少在版式、背景色、信息密度、镜头距离、文字层级、配色策略中变化三项。让差异来自用途，不用换底色替代设计。
- 字体按任务分工。标题可呼应角色的曲率、端点和节奏；姓名与正文保证阅读；标签使用稳定字重、字号和对齐。避免标题、说明、编号同等强调。图内文字宜短，长设定移至指南，但不得删减锁定原文。
- HTML 角色展示的图文编排查构图“品牌视觉”，可取 `品牌视觉 吉祥物`、`品牌视觉 双角色`、`品牌视觉 角色出框` 等名称片段，再按[模板选型](templates.md)完整读取候选。仅借用角色与标题、说明的布局，不把展示模板当作角色造型或三视图模板；纯图不因此查询 HTML，不改变制作路线。

### 海报、场景与世界观
步骤 1：选择一个正在经历、发现、选择、对抗、抵达或离开的瞬间。明确角色目标、阻碍和情绪转折，不只写角色站在某背景前。

步骤 2：由目标决定动作。安排视线落点、手足接触、身体倾向与道具互动；让环境压力影响姿态，而不是先摆动作再堆场景。

步骤 3：按叙事信息选择景别。看清心理变化用特写；呈现手部操作和动作细节用近景；交代障碍、路径或目的地用中远景；表现世界观尺度用大全景。

步骤 4：用空间与光色指向同一互动。以路径、前景遮挡、明暗或色温差引导视线。低角度可强化体量，广角近景可强化迫近感，斜构图可强化失衡；仅在叙事需要时选用。速度线、尘土、水花等须有动作原因。

步骤 5：安放标题与必要信息。借天空、墙面或低细节区承载文字，必要时局部调节对比，不给整幅画面套沉重蒙版。概念海报允许背影、边缘、小比例和半遮挡角色，但须保留明确焦点。

同套画面避免连续中景站姿。除正式核心图外，每张至少变化2–3项：场景色、动作、景别、方向、互动、光影、信息密度或用途；服装变化须获授权。用平面放射图形组织视线时，不将其自动解释为光束或舞台追光。

## 4. 保持身份并设计衍生
步骤 1：新建角色时，以本次范围内第一张正式核心图建立身份并立即交付，不额外增加候选；继续按已明确的任务制作衍生。已有指定母版直接沿用，只有身份或版本无法确定、用户要求先选稿时才澄清。

步骤 2：提取身份锚点，分离可变画面。保留物种、年龄段、头身比、脸部结构、识别部位及锁定的服装、道具、主色和材质；不无故继承源图背景、裁切、文字、光照或偶发道具。

步骤 3：使用本次明确采用的母版作为真实输入，按入口既有能力制作衍生，不以文字重建近似角色。未取得有效母版时停止依赖性衍生，不假装具有未部署能力。

| 条件 | 具体做法 |
|---|---|
| 常规衍生 | 仅改变获授权的姿势、表情、视角、场景、光照、排版和应用；让新构图服务当前用途 |
| 主题更换 | 可改主题场景、局部配件、场景道具和传播语；保留物种、年龄段与主服装身份 |
| 授权换装 | 可改服装款式、局部配饰、编号、色卡和辅助色；保留脸、体型、核心材质、性格及识别点 |
| 局部编辑或修复 | 限定改动区域，保留其余部分；不得借修复重设角色或扩展授权 |

不增加 KV 或封面批准。保留母版来源、版本与衍生关系；产物返回即交付，混合素材同样不校验，按原定用途直接接入。

## 5. 按需压缩为角色Logo
仅在角色Logo、IP＋字标及其母版变体任务中采用本节，不自动增做Logo。

步骤 1：把品牌性格与体验提炼为一句话概念，选择角色关系、人格动作或图文巧思。产品可作为功能道具或结构线索，不必成为主剪影，不机械添加动物和装饰配件。

步骤 2：先构成独立剪影，再加入一个身份部位、一个人格动作和必要表情。头像或半身保留一个身份部位、一个表情动作、至多一个道具。选择粗线块面语言时，以2–5个主要块面组织；黑白块面通常用1–3个主黑块，不强迫所有标志使用粗线。

步骤 3：使用准确完整名称建立标准主标，再派生任务内的独立头像。让角色、字标与身份容器至少共享线重、曲率、端点、倾斜、粗糙度、黑白节奏中的两项。应用插画不得反改母版五官、主剪影和名称关系。

- 采用线条标志时，明确线重、端点、曲率、闭合与开口、黑白节奏、表面完整度。保持外轮廓完整，内部线不压剪影；手绘变化须受控，颗粒不得成为唯一识别点。
- 主标默认使用1–3个印刷颜色角色，常规最多4个；第四色对应固定小面积对象。主色1、墨色0–1、浅表面色0–1、强调色0–1，角色与字标共享色板。黑、白、灰、奶油色、描边、影边、印刷白边及身份容器均计色；透明和未印刷材料本色不计。
- 默认不用渐变。仅已有多色母版、不可替代的颜色语义或明确保留多色身份时例外；明确理由、色序、对象、背景及降级方式，只按原定范围制作所需简化版或单色／反白，不做产物验证或额外增加变体。
- 先保证字标无描边可读。双轮廓不超过两层；描边、白边、影边总视觉重量不超过字面，已确认外轮廓属于结构时除外。在提示词中约束字腔、字距和准确拼写，不对返回结果做缩小或文字校验。
- 区分背景、身份容器和应用承托底。容器至少满足两项才作为身份保留：参与名称结构、承载独特业务对象、单色贡献识别、移除后损失已确认含义、跨横竖及小尺寸稳定继承。
- 原定去底任务在输入说明中保护本体白色、孔洞与身份容器。结果返回即交付，不检查透明度、黑白、缩略、模糊或实际尺度，不自主修补或阻止后续采用。

## 6. 按需适配衍生与制作载体
以下数量仅用于已选择的组合产物，用户指定优先，不自动全交或拆成独立文件。

| 条件 | 具体做法 |
|---|---|
| 表情页或贴纸 | 采用2×2、3×3、横条或分组卡；结合眉眼、嘴型、头部倾斜、肢体和动作符号区分情绪，不仅换嘴。给外轮廓和裁切留余量，避免气泡挤压识别部位 |
| 动作延展 | 默认6–9个姿态一页，等距留白并统一光源、材质；以不同任务和受力关系区分动作，只改姿势与道具互动 |
| 换装页 | 授权后默认3–5版横向阵列；保持身体尺度，展示衣服开合、层次与识别部位的关系，使用准确编号和色卡 |
| 社媒场景卡、UI | 场景卡分别设计镜头、场景、动作和界面文字。UI通常4–6个空、加载、成功、错误、客服等状态；用表情、动作和提示语区分反馈，不用大装饰妨碍操作信息 |
| 周边套组 | 除指定单品外至少3类产品。按主物环绕、2×3/3×3网格、俯视平铺、陈列台、生活场景或开箱组织；明确主次、前后位置、视角、材质、标签及图案落位，避免把同一平面图无差别贴满 |
| 结构、色材与道具页 | 结构页保留头身比、几何体、正侧关系与复现标注；色材页对应实际部位、纹理、光泽和面积；道具页给出结构、正侧视图、握持、收纳及身体尺度关系 |
| 包装应用 | 区分展示、展开表达和生产资料，不互相替代或自动增做。依据真实品类、物理尺寸、刀模、内衬与开合关系安排图案，生成前规划跨面纹样、折边和文字，不把氛围图当生产规范 |
| 影视角色及制作参考 | 从身份背景、时代和角色弧光安排服装轮廓、面料、磨损及装备位置；表演页通常4–6个状态，用眼神和肢体表达情绪强度。剧情瞬间呈现环境压力与情绪转折；制作参考面向美术、建模、服化、分镜说明结构、色材、姿态和禁用项，不强制品牌色或Logo |
| 提案或过程展示 | 长图自上而下组织世界观主视觉、完整标题、故事与探索、设定三视图、动作场景及应用；用连续轴线、留白和层级串联，不等高切卡。探索草图、灰模和材质样不得冒称真实制作过程 |

真实周边与包装须以使用尺度、材料和生产资料成立。制作前依据已有供应商资料安排成型、印刷、切割细部及纹样位置；缺少必要资料时说明未验证边界，不编造毫米值或工艺结论。

## 7. 确定规格并核对交付
### 数量与画幅
单角色、单资产、单点编辑默认1张，不自动扩系统。用户数量和资产清单优先；多视图组合画面计1张，多个独立资产不得拼图减量。

| 条件 | 具体做法 |
|---|---|
| 已明确系统任务但未定规模 | 快速3张：主视觉1＋三视图/设定1＋场景/主题1；标准4–5张：基础2＋传播1–2＋扩展1；完整6–7张：基础2–3＋传播2＋扩展1–2，可选过程板在总量内统筹 |
| 系统范围尚未完整说明 | 按内容分工确定完成任务所需的最小完整组合，上述规模仅作参考；不因描述详细程度或模糊度自动扩为更多图片 |
| 作品集、辅助IP、提案 | 作品集8–10张，基础最多3、传播最多3、扩展最多2，周边/Logo1及整合长图1均计入总量。完整VI非主要IP默认3–4张；Logo、包装或活动辅助默认1–2张。提案按预算3–6张关键图，或明确选择1张纵向长图 |
| 已选择姿态扩展 | 默认1张，完整方案最多2张，只选1–2类；穿搭选换装，互动选动作，社交选表情，商业选周边。无偏好选动作，完整方案可在授权内加换装；不默认增做长图 |
| 未指定画幅 | 主视觉、设定卡、主题/概念/社媒、过程、周边、包装、UI及影视概念用16:9，可按竖向内容用4:5；角色圣经、动作、剧情瞬间用16:9 |
| 多视图与其他专页 | 三视图、表情页、结构、色材、道具、换装、影视拆解/表演/制作参考及IP＋Logo用16:9，紧凑信息页可用4:3；场景海报/KV用4:5或16:9；独立贴纸用1:1或4:5；提案长图用9:16或4:5 |

尺寸依次遵循用户指定、确需连续性的参考比例、默认画幅。各尺寸独立构图，不拉伸母版；包装展示画幅不等于物理生产尺寸。

### 结果交付与用户修改

角色、视图、表情、动作、字标、透明素材及应用图全部返回即交付，不做身份、比例、材质、文字、透明度或跨图一致性校验。不能因主观效果判断自行修复、重生、替换或重新去底。

只有用户明确指出要修改时，才基于真实母版处理指定部位、动作、文字或应用范围；修改结果同样立即交付，不追加优化轮次。仅 HTML 展示可按[质量规范](quality.md)记录布局问题，不扩展为图片检查。

数量、澄清与交付遵循[主入口](../SKILL.md)。标明用途、版本及未完成事项，不将设计图称为已部署或已通过生产验证。
