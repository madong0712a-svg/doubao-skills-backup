# pure-coding 与 image-coding 共享 HTML 实现规范

**读取方式**：按主入口的任务与阶段指引直接读取本文件；已有内容沿用，仅补读当前任务需要的关联规范。纯图阶段不执行 HTML 专属条款，模板资产仅在实际选中后读取完整正文及必要依赖。

**结果处理（所有场景）**：所有产物返回即按[主入口](../SKILL.md#交付规范)用 RichMediaCard + 真实短链交付；HTML 仅交付 `creative_design_preview` 的设计预览／编辑入口短链，不交付源文件。非 HTML 产物一律不做产物校验，包括混合素材和拼接结果。HTML 可检查，但检查不延后交付；只有符合 [quality 单轮溢出例外](quality.md#内容溢出允许增长长度的有限例外)的 HTML 可自主增长长度，同一任务最多一轮。该例外优先于本文件中只记录、不自主改高或重排的一般限制；除此之外，必须用户明确说改才改。不得因效果不好自主重生、修图、替换或重排。继续完成原定未完成产物和首次预览，不擅自增加优化轮次。

**HTML 规则**：仅在用户明确要求或同意可自由编辑时，才生成或修改 HTML 及相关产物，已有明确意愿直接沿用。预览必须调用 `creative_design_preview`，仅使用该工具返回的设计预览／编辑入口真实短链，通过 RichMediaCard 交付。HTML 只作为内部实现文件，禁止交付 HTML 文件、源码附件、打包源文件或下载链接。字体使用 head 内声明的豆包 CDN 远端首选字体及对应字重、样式，系统字体仅作备用，禁止检查字体可用性、字形覆盖或加载命中。 HTML 复刻以用户选中的图片为准，尽量保持风格、排版、布局和字体，题材默认样式不覆盖原图；艺术字按[混合制作](produce-hybrid.md#独立艺术标题的使用条件)复用或参考生成透明素材后排版。

读取条件：用户已明确要求或同意制作可自由编辑的版本；新建、重建及已有 HTML 修改均沿用这一条件。首次静态图片制作不读取或执行本文件，不因文字、表格、节点或多页内容而自动转代码。

## 1. 概述

- **统一实现，不裁决路线。** 本文件负责 pure-coding 与 image-coding 的 HTML 实现、固定画布、原生层、资产消费、测量及完整源。制作方式与交付由 [SKILL.md](../SKILL.md) 决定；素材现成或代码方便不构成改道理由。
- **共用规则归唯一责任方。** 事实、扩写、唯一 Brief、创意与身份母版见 [common.md](common.md)；结果交付见 [SKILL.md](../SKILL.md)，仅 HTML 检查见 [quality.md](quality.md)，素材不校验。

## 2. 使用场景

- **纯代码直接实现。** 使用有真实来源的现有资产、准确文字、HTML/CSS 与内嵌 SVG；本阶段不调用生图，不影响此前已完成的 pure-image 阶段，不强制新增素材清单、字体计划或几何副本。
- **混合素材就绪后组装。** 按 [produce-hybrid.md](produce-hybrid.md) 准备所需素材，图像生产按 [produce-image.md](produce-image.md)。组装检查不阻塞已返回产物的交付。
- **编辑保护完整基线。** 已有源按 [edit.md](edit.md) 获取完整文档，只检查、修改授权范围及必要联动区域；新建与整体重做执行下述完整实现规范，局改不为迁移旧结构改动未受影响内容。实际渲染或宿主接入受阻时按编辑规范处理具体冲突，不跳过失败或宣称通过。
- **选型交由专项文件。** 含文字 HTML 按 [fonts.md](fonts.md) 声明远端首选字体；已选图片复刻沿用原布局，模板只辅助实现。用户要求新布局或局改受影响项时，再按 [templates.md](templates.md) 读取对应资源。细选规则不在此重复。

## 3. 核心流程

### 设计方案与 HTML 实现

- 沿用唯一 Brief 的真实内容、锁定尺寸、阅读顺序、原生文字职责及身份依据。结构、主构图、视觉系统或素材职责变化时，先更新同一 Brief，只对超出用户要求或无法确定的关键变化进行澄清，不静默降级。
- Brief 冻结后将坐标、字号、色值、层级、裁切和 CSS/SVG 参数直接写入完整源，不另填几何投影。
- 按本题材已确定的页面／展开面／屏组织分别保存完整 HTML5 文档，包含 `<!DOCTYPE html>`、`html`、`head`、UTF-8 声明及 `body`；片段、补丁、截图均不能替代。分页 VI 同样逐页保存，不合并为一个长画布。
- 章节、重复组按语义组织；可定位编辑节点使用稳定 `id`／`data-layer-id`，真实区域可用 `data-region`，不得冒充宿主对象 ID。
- 沿用采用记录，保留 Brief 版本、确切资源 ID、发布资源提供的源 SHA-256、采用范围、内容映射和调整理由。整页、章节、局部、原子分别表述；借色板、保留 class 或注释不等于采用整页。

### 固定画布尺寸设置

- `html` 必须含 `data-canvas-width`、`data-canvas-height`，值为不带单位、小数或百分号的十进制正整数字符串。
- **作品总容器必须明确。** 每个独立 HTML 在 `body` 内用唯一 `data-canvas-root` 标记该页／面／屏的外层容器；尺寸仅对应该文件，不包裹整套页面。缺失、重复或标在 `html`／`body` 上均报错，不自动猜测容器。
- `html`、`body`、唯一作品容器的行内 `width`、`height` 均须为与属性完全一致的固定 px 值。清除默认外边距，采用 `box-sizing:border-box`，核对实际边框盒。
- **仅宽高强制行内。** 其他样式可用样式块、class、id 或可加载外部样式表；普通样式不得覆盖固定尺寸。
- 根节点不得以 `max-width`、`min-height`、`height:auto` 替代固定宽高，不用 `overflow:hidden` 藏正文、模块或页尾。局部装饰可按职责裁切；内容须容纳在所属区域，不全局解除裁切使其侵入下一章。
- 禁止 JavaScript、视口单位或媒体查询计算、改变作品尺寸；禁止根文档或整件作品随窗口 `scale`／`zoom`。内部百分比相对固定画布计算，排版不随视口改变。
- `data-canvas-protocol`、`data-canvas-version`、`id="canvas-root"` 非必填；已有则保留，仅接入规范明确要求时新增，不能替代尺寸属性与 CSS。

以下为 750×1500 的尺寸骨架示例，实际宽高按任务确定；本例为独立页面，包含正常流底部安全区；连续非末屏按下文接缝规则处理。

```html
<!DOCTYPE html>
<html lang="zh-CN" data-canvas-width="750" data-canvas-height="1500"
      style="width:750px;height:1500px;">
<head>
  <meta charset="UTF-8">
  <style>
    * { box-sizing: border-box; }
    html, body { margin: 0; padding: 0; }
  </style>
</head>
<body style="width:750px;height:1500px;">
  <main data-canvas-root style="width:750px;height:1500px;">
    <!-- 正式内容、页码及收尾信息放在安全区之前 -->
    <div data-canvas-bottom-safe-area="24" style="height:24px;"></div>
  </main>
</body>
</html>
```

- **按任务确定排版依据。** 复刻使用选中原图的画幅、页／屏边界、主要内容组位置、图文占比、字号与断行，按 editable 的细分策略实现；不以内容自然增高、模板默认值或通用排版优化改变原布局。只有新创作或用户明确允许重排时，才按完整文案规划栏宽、字号与高度。新增文案超出原空间时记录具体容量冲突，不自行缩图、删项或加长画布。混合生产使用实际返回素材组装，不进行素材准出检查。获准改变尺寸时，同步两项画布属性与三个根节点行内尺寸，再调用 `creative_design_preview`；预览返回后只记录问题，不自主改高或重排。


- **新建简历与菜单的首次容量安排。** 仅在新创作或用户允许重排时：简历先确定适合成品阅读尺寸的正文字号、行高与栏宽，再按真实内容安排模块，避免先套高容器再缩字或拉大间距；资料少时保留合理留白。菜单先分配栏目区域及完整行数，预留菜名换行和价格单位的宽度，图片与文字共同计入栏目高度。选定尺寸确实无法容纳可读内容时说明具体容量冲突，不擅自删项或增页。已选图片复刻则按 [editable 的场景排版重点](editable-upgrade.md#简历菜单与详情页的排版重点) 保留参考尺度与结构，不套用新建排版。此处用于首次规划，不授权预览后自主返工。

内容溢出且允许增长长度时，按 [quality 的单轮例外](quality.md#内容溢出允许增长长度的有限例外)处理；该例外优先于本文件不自主改高、重排或重复预览的一般限制，不能改变锁定尺寸或分屏归属。

预览统一调用 `creative_design_preview`，参数按实际工具协议填写。工具报告布局或图片资源问题时如实说明，不自动修复、替换素材或重复预览；用户明确提出修改后才处理对应项；不运行字体可用性、覆盖或加载检查，也不使用截图脚本替代该工具。

### 分页、分面与分屏

- 按题材已确定的页面／展开面／屏作为内部实现单位生产；每个文件包含独立可渲染的完整 HTML、固定尺寸和稳定编号，各自调用 `creative_design_preview` 生成同尺寸预览，并立即用其返回短链 + RichMediaCard 交付。
- 画册、套图及分页 VI 标明页序，结果返回即交付；三折页交内侧、外侧两个完整展开面，不把三个折区分别交付。
- **详情页区分新建与复刻。** 新建时按 ecommerce-detail 规划整体内容及分屏，再分别制作文件；各屏等宽，高度区分锁定值与起排参考，不继承同一模板高度。复刻时直接沿用确认版各屏的尺寸、边界与顺序，从参考读取和局部定位开始逐屏制作，不重新规划整页或用一条长页面内容流再切屏。字体、颜色等共用样式可以复用，尺寸与布局分别落实。确有跨屏连续背景时，仅背景沿用共享坐标或参数并换算到各屏；不能借背景连续合并内容流，也不能在每屏顶部重启同一渐变或场景。
- 仅当用户明确需要完整详情长图预览时，才按阅读顺序将同版本、等宽的各屏组织为长图 HTML 并调用 `creative_design_preview`；总高度为采用各屏高度之和，不改变各屏内部布局，不用负间距、裁切或拉伸掩盖接缝。保留各屏源；额外长图预览不替代已确认的分屏交付，除非用户明确改变交付形式。不自行拼接截图替代该工具预览，也不主动增加长图版本。

### 物理尺寸与采样分开计算

- 优先采用用户明确值、已确认印厂或版位规格；编辑继承原尺寸。冲突先解决，无尺寸才按题材推荐，并在 Brief 记录用途、单位及假设来源，示例不作默认规格。
- 数字作品用 px，默认 1 倍导出与画布同像素。物理成品用 mm 记录裁切、出血、折线及安全区；折叠品同时记录展开与闭合尺寸。
- HTML 按 `1 in = 96 CSS px`、`px = mm × 96 / 25.4`、`1 pt = 4/3 px` 换算。根宽高向上取整；元素、折线先保留精度，整数边界按累计转换后求差，避免逐段舍入漂移。屏幕 CSS 毫米不保证实物尺测毫米。
- 印刷位图另算 `export_px = ceil(mm / 25.4 × PPI)`。PPI 未确认时，300 仅可作为明示的设计测试假设，不冒充印厂要求；96 CSS px/in 不是印刷分辨率。
- 每边已确认出血为 b mm 时，出血版为 `(裁切宽 + 2b) × (裁切高 + 2b)`；内容、折线相对裁切区定位后整体偏移。未知出血不猜填，先做裁切区并记待补。
- 净稿不显示辅助线；生产校样可显示折线、裁切线及说明，须明确区分。尺寸齐全不等于具备印刷交付能力。
- 仅当原任务要求相应分辨率或用户明确要求修改时，从同一源按目标分辨率渲染，不放大小截图或仅改 PPI 元数据。导出像素按未取整物理尺寸计算，CSS 取整余量在边缘处理，不非等比拉伸，也不因采样倍率重写版式。

## 4. 不同产物/策略展开

### 原生文字与数据保持可编辑

- 普通标题、正文、数字、单位、条件、标签、CTA、图注及来源用真实 DOM 文本复刻并保持可定位。字体、字号、位置、断行和层级以选中图片为准；过于艺术化的文字按 [produce-hybrid](produce-hybrid.md#独立艺术标题的使用条件) 复用或参考生成透明底字图，作为独立图层排版。
- 数据仅消费有依据的输入与可复算转换。比例、合计、排序、坐标映射及单位换算可追溯口径和方法；零值、未知、不适用不得混用。模板姓名、学历、年月、章节及数值不是任务事实；无依据的非锁定示例槽位移除或暂停并记待补，不擅删确认事实。
- 透明艺术字图只承载原图中需保留的艺术文字，普通文字与布局仍保持原生；不重复 DOM 覆字，不声称字图内部文字可编辑，不用整张图片替代完整 HTML。
- 字体按选型在 head 内声明豆包 CDN HTTPS `@font-face`，使用对应 family、字重和样式；系统字体仅作备用。资源直接取现有字体清单，具体见 fonts.md。不做字体可用性、字符覆盖、加载命中或替换测试。
- 文字效果优先使用适合节点的发布 CSS：描边用 `-webkit-text-stroke` 且保留可读字色；阴影、发光用受控 `text-shadow`；渐变同时落实背景、标准及 WebKit `background-clip:text` 和透明字色；逐字差异用真实嵌套 `span`、变换及阴影。
- 装饰可用伪元素，独立装饰节点设 `aria-hidden="true"`。原图中过于艺术化的文字直接按透明字图流程复刻，不为原生实现方便而明显简化或改变原效果。

### 素材链接与使用位置

- 生成或编辑图片直接使用工具实际返回、已记录的 HTTPS 地址；已有结果复用原链，不为插入 HTML 下载重传或复制换链。素材清单只记录版本、来源与消费者，不做就绪／准出校验。
- 将完整 HTTPS 图片地址填入 `img src`、`srcset` 的每个候选、CSS 背景／蒙版或 SVG `image` 的 `href`／`xlink:href`；不使用本地、相对、file、data 或 blob 地址。缺少合规地址时通过可用上传工具取得真实地址或说明缺口；不因 302 跳转自行换成签名直链，不增加图片质量、尺寸或透明度检查。
- **背景按原效果实现。** 纯色、规则渐变和重复线纹可用 CSS；按 [editable 的背景方法](editable-upgrade.md#背景与连续场景) 从输入参考取代表色并还原渐变与线纹参数，准确值写入 HTML。复刻中的复杂纸纹、笔触及背景装饰沿用原图，需去除内容时按 editable 的背景局部编辑路径处理，不为减少资源引用改成简化 CSS 背景。
- **SVG 使用边界。** 确定性几何、基础箭头和规则图形可用 SVG；已有 SVG 优先复用。有特定造型、笔触或材质的插画与装饰继续使用图片素材，不因对象是星星、叶片或图标就用代码重画。
- **按用途确定接入方式。** 规则图形或需要节点可编辑的 SVG 直接内嵌 `<svg>…</svg>`；仅作图片引用时使用真实 HTTPS 资源地址。这条预览路径不使用 SVG data URI，也不调用编码脚本生成图片引用；已有静态 SVG 可直接内嵌或上传后引用，不重绘图像主体。
- **内嵌 SVG 写法。** 保留命名空间与 `viewBox`，按原比例显示；用 `fill`、`stroke` 控制颜色与线条，用 CSS 控制尺寸和位置，按所在布局选择定位方式。重复形状可复用，确为镜像的图形可用变换实现；不统一拉伸或转曲原生文字。保留必要定义及 `url(#id)`、`href="#id"` 内部引用，保持目标对应且同页 ID 唯一，不按外链一律删除；纯装饰节点加 `aria-hidden="true"`。
- **SVG 报错按原始返回处理。** 图片或字体引用报错未指明 SVG 时，不自行认定为 SVG 编码或内部引用问题。沿用本文件的预览失败处理规则，不自行轮换 data URI、内嵌 DOM 或图片链接，不删纹理、滤镜来试错。
- 同一素材可在多个 HTML 节点引用；用户明确要求替换时，只修改指定消费者及必要关联引用。HTML 检查只查看节点绑定与排布，不借此重新校验图片。

### 透明素材与混合模式

- 背景与透明输出在制作前按 [produce-image.md](produce-image.md) 安排；结果返回即交付并按原用途接入，不检测 Alpha、边缘或最终底色上的图像效果。
- HTML 复刻艺术字的透明素材来源按 [produce-hybrid](produce-hybrid.md#独立艺术标题的使用条件)，按原位置、比例与层级排版；不使用白底／黑底配 `multiply`／`screen` 代替透明背景。
- 普通 Logo HTML 展示可在均匀白底图的图片节点使用 `multiply`，均匀黑底图的图片节点使用 `screen`，制作前依据已知背景与品牌色选择该显示方式，不声称具有 Alpha；VI 的独立 Logo 层仍须真实透明。去底保留品牌本体底板，不重画身份；例外不扩至人物、商品及其他多色素材。
- 图文关系由真实承载层、定位、层级与裁切实现；跨层或复用对象使用独立资产或原生节点。已烘焙文字、面板、装饰及光影不重复叠加，不以 DOM 覆字或卡片修补 Hero 图内错误。
- 效果须实际可见，令牌、配方名或 CSS 属性存在不算兑现。祖先透明度、蒙版、模糊与混合不得损伤信息和身份；子节点 `z-index` 不能抵消祖先蒙版。

### HTML 中的图片布局

- 首次实现使用已知规格或工具返回的尺寸安排图片框、比例和取景；等比缩放，不拉伸主体。`contain` 用于完整显示，`cover` 用于已约定的取景，依据选中图片保留布局与保护范围。
- 不单独检查源图、处理图或生成素材的像素、分辨率、EXIF、透明度、比例误差、文字、身份与质量，不设置像素倍数或清晰度准出门槛。
- HTML 预览返回后，可按 [quality](quality.md) 记录图片节点的绑定、定位、缩放、层级、裁切和遮挡问题；不因此修改图片、重新取景、替换素材或重排。必须用户明确要求修改后才处理对应实现。

## 5. 输出形式

### 完整源与预览对应同一版本

- 每页／面／屏在内部保留完整 HTML，按实际尺寸调用 `creative_design_preview` 生成预览。用户明确要求修改，或执行获准的单轮溢出增长并完成页面更新后，将当前完整版本重新传入该工具，旧版本短链不能代表新版本。
- **直接交付工具短链。** 将完整 HTML 提交给 `creative_design_preview`，仅将其返回的设计预览／编辑入口短链原样填入 RichMediaCard 的 `refs`；多项结果逐项交付，不等待整套完成或额外检查。
- **交付设计入口，禁止交付 HTML 文件。** HTML 仅作内部实现与修改依据；只把 `creative_design_preview` 返回的设计预览／编辑入口真实短链填入 RichMediaCard，不发送 HTML 附件、完整源码、源码压缩包或下载链接，工具返回的源文件地址也不交付。
- 工具不可用、预览失败或未返回设计入口短链时，在内部保留源文件并说明交付未完成；禁止以 HTML 附件、源码或文件下载链接补交。其余已返回的有效设计入口继续交付。

### 首次组装的预览协议

完整源须为 UTF-8，显式包含 `<!DOCTYPE html>`、`html`、`head`、`body` 及 head 内的 UTF-8 声明；html 上的 `data-canvas-width`、`data-canvas-height` 为不带单位的十进制正整数。模板只供布局参考，其占位图片及字体声明也须在首次组装时按上述协议落实。图片引用形式合规不代表加载成功，预览成功也不代表视觉复刻达标。错误状态与交付按 canvas-delivery.md 执行。
