# 混合生产：准备素材并组装可编辑作品

**读取方式**：按主入口的任务与阶段指引直接读取本文件；已有内容沿用，仅补读当前任务需要的关联规范。纯图阶段不执行 HTML 专属条款，模板资产仅在实际选中后读取完整正文及必要依赖。

**结果处理（所有场景）**：所有产物返回即按[主入口](../SKILL.md#交付规范)用 RichMediaCard + 真实短链交付；HTML 仅交付 `creative_design_preview` 的设计预览／编辑入口短链，不交付源文件。非 HTML 产物一律不做产物校验，包括混合素材和拼接结果。HTML 可检查，但检查不延后交付；只有符合 [quality 单轮溢出例外](quality.md#内容溢出允许增长长度的有限例外)的 HTML 可自主增长长度，同一任务最多一轮。该例外优先于本文件中只记录、不自主改高或重排的一般限制；除此之外，必须用户明确说改才改。不得因效果不好自主重生、修图、替换或重排。继续完成原定未完成产物和首次预览，不擅自增加优化轮次。

**HTML 规则**：仅在用户明确要求或同意可自由编辑时，才生成或修改 HTML 及相关产物，已有明确意愿直接沿用。预览必须调用 `creative_design_preview`，仅使用该工具返回的设计预览／编辑入口真实短链，通过 RichMediaCard 交付。HTML 只作为内部实现文件，禁止交付 HTML 文件、源码附件、打包源文件或下载链接。字体使用 head 内声明的豆包 CDN 远端首选字体及对应字重、样式，系统字体仅作备用，禁止检查字体可用性、字形覆盖或加载命中。 HTML 复刻以用户选中的图片为准，尽量保持风格、排版、布局和字体，题材默认样式不覆盖原图；艺术字按[混合制作](produce-hybrid.md#独立艺术标题的使用条件)复用或参考生成透明素材后排版。

## 1. 概述

- 本文件仅在用户明确要求或同意可自由编辑后执行 image-coding；已有明确意愿直接沿用，不因题材、代码格式或已有源而自动进入。负责素材登记、采用与组装、图文分工及独立艺术标题。
- 图像承担摄影、场景、插画、复杂材质及获准图内文字；准确文字、数据、规则图形与指定可编辑区域由原生层承担。完整固定画布 HTML5 为可编辑实现源，不以整页压平替代指定编辑范围，也不将局部编辑要求扩大为全图。
- 唯一 Brief、事实、扩写、身份母版与创意依据归 [common](common.md)；HTML 检查归 [quality](quality.md)，结果交付与用户修改授权归 [主入口](../SKILL.md#交付规范)。参考传入、Prompt、背景与抠图执行归 [produce-image](produce-image.md)；全部 HTML 及通用图像适配计算归 [produce-code](produce-code.md)。

## 2. 使用场景

- 用于用户已明确同意自由编辑的混合新建、整体重做及已有 HTML 编辑；既有源保护与授权见 [edit](edit.md)，不因导出图片而改路线。
- 按实际视觉职责复用或补充素材。将已交付图片重建为可编辑版时，按 [editable-upgrade](editable-upgrade.md) 优先复用符合编辑范围的现有素材，只补确实缺少的图层；局部改字或间距不生成无关图片。
- 仅在用户明确要求方向样图或 KV 时制作对应产物；已选图片转为可编辑版时直接沿用其方向。
- 社媒套图按完整页链制作，沿用已选封面与系列机制，不默认增加封面批准。

## 3. 核心流程

### 素材尺寸与规格

- 按 [common](common.md) 更新同一 Brief，由页／段职责、准确文案及图文关系确定素材组合：共同解释整组的画面可合成完整场景，需分别邻接说明的对象按对应关系安排，需独立移动或跨层的主体保留可分离边界。完整背景、透明主体或复用由用途决定，不默认一章一张横图，也不逐条强配图。事实、身份与编辑范围沿用原记录，规划说明不进入成品。
- 生成前用真实文案、选定字体及拟用构图规划容量与图文对应，再确定素材数量、比例、取景和文字安全区；不因素材先定成矩形场景而把文字全部挤到图前或图后。可进行不加载未就绪素材的非交付文字容量／比例测量，不提前组装正式作品，不另建几何文件；套图按整套内容分别规划各页容量，不检查返回的图片。
- 字体选型、直接填写及阅读尺度见 [fonts](fonts.md)。复刻已选图片时沿用原风格和布局，模板仅辅助局部实现；确需新的布局且用户已要求时，再按 [templates](templates.md) 比较模板；只消费自包含发布 manifest、所选正文及必要依赖，不凭摘要、类名或缺失维护源实现。

### 用户要求的 KV

- 仅在用户明确要求时制作；数量按主入口，单项默认 1 张。已有选定图片直接作为方向依据，不为流程另增 KV。
- 明确主题、真实主体、焦点、视角、光材、配色与参考保护项。标题按用户文案或有依据的创意表达参与构图，无字要求优先；不以无字底图或散图拼装代替用户要求的完整 KV。
- 用户规格优先；未指定时可用 1920×1080、16:9 横版。工具能力不足时如实说明，不拉伸结果或虚报尺寸。
- 参考实际传入 `image_edit`；纯文字新建用 `image_gen`。结果返回立即按主入口交付。用户要求先选方向时再等待选择，否则按已明确的方向继续。
- 后续页面继承字体气质、配色与材质，按正式画幅、文案和编辑范围重新安排图文；KV 图内文字不冒称可逐字编辑。

### 封面与内页制作

- 在同一 Brief 规划完整页链、文案、编辑范围与共享视觉。已有套图转可编辑版时，直接依据已选各页重建；新建套图可先制作封面以建立系列依据，无结果依赖的内页可继续制作。
- 按各页职责、容量和画幅调整构图，不机械复制封面坐标、对象数或容器。各页产物返回后立即交付；仅用户明确要求先看封面再继续时等待其决定。

### 素材登记与组装

- 正式组装素材调用前建立轻量 `asset-manifest.json`；独立方向图未用于组装时无需登记。只登记本次制作范围，关联页／段与用途，记录生产方法、真实参考及顺序、身份母版与保护项、完整 Prompt、目标比例／尺寸、安全区、消费者、原计划处理及缺失的输入。
- 同一结果重复摆放共用一条，列出全部 `consumers`；每项一个 `output`，不同采用结果分项。维护 `asset_id`、`reference_inputs`、`postprocess`；DOM ID、坐标、字号、色值及 CSS 留在 HTML。
- 调用前基于已可见参考确定保留项，禁止重复调用读图工具；当前看不到图片时才读取。身份与变体依赖按 [common](common.md)；真实参考传入、输入顺序及 Prompt 编译按 [produce-image](produce-image.md)。未传入的图片不称工具参考，不预填未来句柄；必要输入无法满足时暂停依赖。
- 产物返回后立即交付，并在原条目回填真实 URI／句柄、实际尺寸、版本及状态；处理结果追加父子关系、范围、参数与采用版本；尺寸和透明属性仅记录工具返回值，不另行检测，不覆盖原图或凭旧 Prompt、记忆、预览地址猜采用版本。来源分类与身份继承按 [common](common.md)。
- 按生成前确定的用途和工具真实返回引用接入素材，不检查产物质量、身份、图内文字、透明度、方向、比例或有效像素，不设置采用门槛。背景保留、透明输出和原定去底在调用前安排，不因结果观感追加处理。
- 当前页面的必需素材已返回并记录后即可组装完整 HTML，不等待其他页面。直接绑定工具实际返回或用户提供的素材地址，不另做素材可用性或质量验收；同图各位置独立定位，不因 URL 相同擅自全部换源。
- **复刻分工沿用统一决定。** 按 [editable-upgrade](editable-upgrade.md#依据选中图片进行-html-复刻) 执行已有 Brief、素材路径及拆层边界：结构说明类主体插画缺少可用独立层时，按该规则用 5.5 参考生成透明素材，不用 SVG 重绘；完整场景及无需独立操作的背景装饰整体保留，确需独立操作或跨层的主体才拆出并采用透明素材，需编辑的文字和容器原生实现；不以带底 crop 或代码图标替代图片。处理按计划进行，已烘焙内容不重复叠加，不能整图铺底覆字冒充可编辑。

## 4. 不同产物/策略展开

### 首屏文字的制作方式

- 电商正式 Hero 默认商品／环境主图与原生标题、文案分离；明确选择且符合编辑边界的一体化方案，只允许主标题与必要短辅助文字入图，价格、日期、条件、参数和正文仍原生实现。
- 社媒、简历、三折页及其他题材复刻时，普通文字保留原生层；原图中过于艺术化的文字按下节复用或参考生成透明底字图。图中字标、包装文字与实物标签按 [common](common.md) 保护；不伪造证书、评论、账号或真实案例。

### 系列视觉一致性

- 创作型混合作品至少 **70%** 画面保持同一视觉家族，最多一种次级母题；单个 Prompt 一种主风格，色板通常 **2–4 色**，明确主辅职责，不覆盖锁定品牌色。
- 背景、容器与标题至少共享色板、轮廓、材质、网格中的 **三项**；分层独立主体与背景通过光向、透视、接触、遮挡、路径或材质至少 **两项** 建立空间关系，不以同色冒充融合。规则信息区可用稳定网格，不为变化改造事实。
- 背景分工、光效授权、连续来源及相邻素材试排执行 [produce-image](produce-image.md)；文字净空见 [common](common.md)。组装须兑现已定背景与图文职责，不以小卡片、纯色或弱化效果偷换，不用融合遮盖结构断口。

### 独立艺术标题的使用条件

1. **按原 PE 与看图判定。** 采用选中版本实际生图 PE／Prompt 的字体描述和画面字形；PE 说明意图，图像确定实际效果，准确文案沿用确认原文。无 PE 时看图判断，不编造历史。圆润字体配圆体、黑体配黑体、宋体配宋体，用 DOM 保留字重、宽窄、字号和断行；其他标题优先按艺术字候选判断，名称未知不等于艺术字。基础字体已变形为特殊笔画或复杂材质时按实际效果处理，判定简记在同一 Brief。
2. **优先复用，缺少才生成。** 对应透明字图直接复用；必须重制时按 [model-adapters](model-adapters.md#html-复刻补充素材的模型选择) 使用 5.5，实际传入原标题参考并输出透明底。参考生成通常用 image_edit；实际部署的 image_gen 若支持参考输入及透明输出也可使用，不写死工具名称。不能传参考或不能输出透明底时说明受阻项，不以纯文字调用冒充参考生成。
3. **PE 只描述原标题。** 写清准确文字、字形笔画、粗细、宽高比例、颜色、材质、装饰和断行，保留必要留白与细笔画；明确“透明背景生成”，不附带场景或底板，不强制方图、粗字、立体效果或新增换行。生成画幅按原字图区域规划，不用白／黑底混合模式冒充透明，不以整张成品替代字图。
4. **按原关系排版。** 结果返回即交付，再按原位置、可见字形尺度、层级及邻近关系接入 HTML。适用于各题材，不限制艺术字固定张数，不把普通文字批量栅格化；参考现有效果不被通用标题配方简化。字图可移动、缩放、替换，内部文字不能逐字编辑；仅改位置或尺寸复用已有字图。

字体声明并使用豆包 CDN 远端首选字体，系统字体仅备用，不做安装、可用性或字形覆盖检查；生成结果不另测透明度或质量。工具报错如实说明，已有返回产物仍须交付，不声明未验证的能力。

## 5. 输出形式

- 保留同一 Brief、轻量素材清单、真实素材及完整固定画布 HTML；整体决定不重复写，几何实现不另建副本。不另建生产合同。
- HTML 结构、原生层、字体、容量、页尾及高度校准执行 [produce-code](produce-code.md)。首次实现按指定尺寸组织内容；仅自适应高度长页在首次预览前按内容定高。预览返回后不因溢出或效果判断自行重排、改高或重做，必须用户明确提出修改。
- 仅 HTML 布局可按 [quality](quality.md) 检查并记录问题，素材不校验；生成图片按主入口立即交付，HTML 则必须调用 `creative_design_preview`，直接用其返回短链 + RichMediaCard 交付，不等待整套完成或检查通过。
- 套图各页预览统一由 `creative_design_preview` 生成，标明页序、尺寸与版本，使用对应工具短链 + RichMediaCard 立即交付。
