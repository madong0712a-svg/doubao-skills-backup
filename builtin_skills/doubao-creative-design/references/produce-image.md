# 图像生产：完整位图、素材与编辑

**读取方式**：按主入口的任务与阶段指引直接读取本文件；已有内容沿用，仅补读当前任务需要的关联规范。纯图阶段不执行 HTML 专属条款，模板资产仅在实际选中后读取完整正文及必要依赖。

**结果处理（所有场景）**：所有产物返回即按[主入口](../SKILL.md#交付规范)用 RichMediaCard + 真实短链交付；HTML 仅交付 `creative_design_preview` 的设计预览／编辑入口短链，不交付源文件。非 HTML 产物一律不做产物校验，包括混合素材和拼接结果。HTML 可检查，但检查不延后交付；只有符合 [quality 单轮溢出例外](quality.md#内容溢出允许增长长度的有限例外)的 HTML 可自主增长长度，同一任务最多一轮。该例外优先于本文件中只记录、不自主改高或重排的一般限制；除此之外，必须用户明确说改才改。不得因效果不好自主重生、修图、替换或重排。继续完成原定未完成产物和首次预览，不擅自增加优化轮次。

**HTML 规则**：仅在用户明确要求或同意可自由编辑时，才生成或修改 HTML 及相关产物，已有明确意愿直接沿用。预览必须调用 `creative_design_preview`，仅使用该工具返回的设计预览／编辑入口真实短链，通过 RichMediaCard 交付。HTML 只作为内部实现文件，禁止交付 HTML 文件、源码附件、打包源文件或下载链接。字体使用 head 内声明的豆包 CDN 远端首选字体及对应字重、样式，系统字体仅作备用，禁止检查字体可用性、字形覆盖或加载命中。 HTML 复刻以用户选中的图片为准，尽量保持风格、排版、布局和字体，题材默认样式不覆盖原图；艺术字按[混合制作](produce-hybrid.md#独立艺术标题的使用条件)复用或参考生成透明素材后排版。

## 1. 概述

- **执行主入口的需求路由。** [SKILL](../SKILL.md) 决定需求场景、制作方式、澄清与交付。本文件负责图像输入、Prompt、背景、去底、连续空间、纯图套图与长页拼接，不因字数、价格、Logo、字体、PNG/JPG 或工具限制改道。
- **区分终图与素材。** 完整位图承载获准文案及完整画面，不强制拆层或进入 HTML 覆字，不承诺图层编辑、原生矢量、设计系统、刀模或交互。image-coding 素材仅承担已分配的主体、环境、背景、复杂壳体、一体化 Hero 等职责；准确可编辑文字及常规规则图形留给原生层。
- 图像工具、grounding 与逐张交付遵循[主入口](../SKILL.md)。所有生成的图片返回后即交付。全部图像产物均不做成品检查、筛选、自评、修复或自主重生，混合素材、去底图与拼接图同样适用；不设置素材准出或拼接后复核。

## 2. 使用场景

- **完整图片直接生产。** 按对应题材规范制作单图、套图、长图、详情页、简历、折页、画册与品牌系统图片。简单纯图直接编写提示词；复杂任务沿用题材 Brief，不另建生产 Brief，不因 Brief 增加冻结步骤；身份母版与实际平台要求的确认按 common 执行。纯图不继承混合艺术标题约束，不增加 KV 或套图封面批准。
- **混合素材按职责生产。** 组装前置、KV 及艺术标题细则归 [produce-hybrid](produce-hybrid.md)，所有 HTML 实现归 [produce-code](produce-code.md)；本文件保留可供混合路线引用的背景与抠图策略。
- **未指定换路线的已有源编辑。** 独立图片按图片编辑；已有 HTML 的修改须有明确自由编辑意愿；已授权任务保留完整源，预览及交付按 [canvas-delivery](canvas-delivery.md)。纯图长页不因高度回退代码。位图能力与功能、编辑要求冲突时交入口处理；缺输入或能力仅暂停依赖部分。
- **建议不等于生产。** 仅提供方案、Prompt 或审查时不自行调用。题材、平台与模型按入口配套；模型适配见 [model-adapters](model-adapters.md)，不改变权限。

## 3. 核心流程

### 先落实产物规范

- 将对应题材的必要内容、准确文案、尺寸比例、阅读顺序、安全区及页面／物理面映射写入本次生成计划与提示词。采用 pure-image 不减免这些要求。
- 生成可直接查看的完整图片：文字、配图、图形和版式共同成稿，不只生成底图等待 HTML 补字。画册按页、卡片按已定正反面、折页按完整内外展开面分别生成；连续长页按下述规则分段拼接。
- 图片制作将内容、视觉和阅读规范落实到提示词；HTML 模板、Web 字体、原生图层与内部源保存条款只用于对应的代码制作；HTML 文件不得交付。
- 按题材的交付章节完成本次产物及后续沟通，保留真实引用、准确文案和版本。

### 参考图输入与编号

- **合并可一次完成的编辑。** 已有可用素材直接使用，能一次完成的编辑合并执行。
- 基于已可见参考区分编辑目标、身份、内容、风格与构图，禁止重复调用读图工具。仅保留商品、人物或角色身份时，将保留项与获准改动直接写入提示词；仅复刻版式或风格时，按需读取 [reference](reference.md) 明确构图、比例、层级及可替换项。风格参考不授权复制身份、商标、签名、水印或专属细节。
- Prompt 以“图1、图2”等稳定序号指代；附件或可用地址按同序实传。URL、路径、内部 ID、工具参数不混入画面描述；只看未传的图不算工具输入，资产 ID 不冒充图片。
- 身份敏感调用实际传入已确认母版并使用支持的编辑能力，不凭文字近似重绘。身份建立与继承按 common 执行；错误首图、裁片及衍生图不自动升格母版。
- 编辑合成成品时，当前成品是目标，独立母版是身份参考，二者不得互相替代。工具不能接收全部必要输入时报告阻塞，不省略身份降级生成。裁片记录父图、方向、坐标；扩图、去底和编辑均产生可回退新版本。
- **独立变体共用明确母版。** 按已确定数量分别编写 Prompt，固定同一组真实输入、版本、顺序和职责；按工具能力批量或分次生成，不将独立输出串作后续输入。连续扩图按真实依赖串行；复用同图不授权全局替换消费者。

### 生图提示词编写

- **指定图内数量必须 grounding。** 格式与完整示例见主入口。`<point>` 是必要空间描述，不属于下文禁止的 DOM／CSS／内部字段，模型改写不得删减或合并。
- **区分完整 KV 与无字底图。** 用户要求的 KV 按 [produce-hybrid](produce-hybrid.md#用户要求的-kv) 同时生成主视觉、准确标题和字体风格，Prompt 写清字形、层级及图文位置；不套正式背景素材的无字要求，不仅留白等候 HTML 补字。正式素材是否带字仍按题材与已确认的编辑边界执行。
- 生成围绕整图目的、主体、分区扫描、空间关系、媒介光材及保护要求；编辑围绕当前目标、保留项、授权改动、新旧融合和完整性。使用连贯自然语言，不增加固定段数或参数合同。
- 写清数量、尺度、朝向、视角、焦点、留白、接触、遮挡及上下文。摄影／3D 给出可信机位、光向和清晰范围；平面图形不强加景深，环境层次不以“丰富背景”代替。
- 一种主媒介，至多一种辅助母题或工艺；完整位图至少 **70%** 画面遵循同一视觉家族。系列保持配色职责、材质尺度和边缘语言，按页任务改变景别与密度。
- 画幅、比例、目标像素按工具协议传入；复杂任务同时保留题材 Brief 中的目标尺寸；Prompt 描述方向和构图，不塞 DOM 坐标、CSS 或模板名。调用前确认工具支持的规格，返回后只记录工具提供的尺寸信息；模型适配不得增删页数、身份、事实、原文或授权范围。

### 图内文字与准确文案

- 完整成品及获准图内文字逐条用中文双引号 `“”` 界定，英文、数字、标签同样处理；字体、颜色、排版和断行说明放引号外。界定符不画入图，也不写回源文案；原文自带引号保留。
- 完整成品要求仅呈现指定文字，不新增文字、乱码、伪 Logo 或水印；不把该句扩散为普通配图模板。
- 普通配图不写上屏标题、正文、价格、日期或 HTML 排版，不堆“无文字／no text”及伪字排除词；以空间位置和低纹理状态表达留白。已有包装文字、标签、Logo 属于身份，不得擦除。
- 混合制作的一体化 Hero 与 Logo 按实际任务处理；HTML 复刻的艺术字按 [produce-hybrid](produce-hybrid.md#独立艺术标题的使用条件) 复用或参考生成透明字图，开启透明输出并注明“透明背景生成”。不因 H1 层级将普通文字图片化；字体描述约束视觉气质，不承诺精确 family、face 或 weight。
- 调用前核对尺寸、首焦点、参考实传、文字源、保护边界及机位光材冲突。二维码等功能内容须有真实输入。

## 4. 不同产物/策略展开

### 背景制作

- 按实际露出区域、连续内容组生产，不机械按屏生图。全局底面、组级背景和局部覆盖不重复担责；完全被遮挡且无用途的图不生成。CSS 可稳定实现的规则渐变或表面效果不额外生图，也不以色块替换已确认摄影、材质或场景。
- 整页或连续背景组不得以无变化纯色规避主题所需纹理、肌理、渐变或空间关系。稳定纯色用于有信息职责的局部区域，说明纹理为何削弱主体或版式；VI 中承担明确品牌识别作用的主色场也可使用纯色，包括完整首屏背景。不为这些区域强加纹理或渐变，不拆容器套例外。该背景选择不改变已选构图，也不允许用纯色替换已确认的摄影、场景或材质；Logo 标准稿及用户要求的黑白版本使用干净底色，不强加纹理或渐变；Logo 系统展示按品牌气质与版式选择背景，不将标准稿底色扩展为所有展示页的规则。明确纯白底的单张商品主图等仍按题材执行。
- 描述主材质／色场、颜色、延展方向、纹理尺度与疏密、合理明暗、低干扰阅读区及连续线索。平铺表面明暗稳定，摄影保留可信受光和接触。
- 通知、公告、喜报、捷报、成果战报、邀请函、节庆贺图默认无明显光效。顶部聚光、太阳芒、舞台追光、体积光、闪电光纹、镜头光晕，仅在用户逐项明确要求或明确保留参考对应效果时采用；放射构图、庆典、红金、金色、丝绸均不构成光效授权。上述公告类视觉默认不用平面放射，用户明确要求时才采用；非公告视觉不扩大此专项门槛。

### 抠图与背景保留

- **先判断背景需求。** 每图记录：需要透明底、已有有效透明、保留完整背景。用途明确时不追加逐图批准；用途不明或改变锁定内容才澄清。有效透明位图或确认无背景填充的完整 SVG 直接复用，不重复生成或抠图。
- **透明新图。** 纯文字创作用 `image_gen` 开启透明输出，提示词注明“透明背景生成”。依赖原图时使用支持真实参考输入与透明输出的工具，通常为 `image_edit`；HTML 复刻的模型选择按 [model-adapters](model-adapters.md#html-复刻补充素材的模型选择)。

- **抠图优先使用 MediaKit。** 已有图片只需去底时，使用专用抠图工具；优先读取并使用 `byted-mediakit-image` 的 `remove-image-background`，实际入口为 `mediakit-cli image remove-image-background`。按当前工具契约提供可访问的图片 URL，选择对应场景并输出透明 PNG；不默认增加描边或裁掉透明留边。工具未部署时按主入口报告能力缺口，不伪造处理结果。
- **透明结果直接交付。** 按任务在调用前指定透明输出；直接生成和抠图返回的结果均立即交付，不检测 Alpha、残底、边缘、孔洞或误删，不据此重做，也不设置组装前的透明校验门槛。
- **保留有职责的背景。** 独立 Logo 优先透明源，移除外部展示背景，保留规范或用户确认属于标志本体的底板。完整照片、场景、平稿及一体化 Hero 可保留背景。
- **去底不改身份。** 在原定去底任务中保留主体和身份，不借去底重建。结果返回后不检查边缘或自动修补；用户提出修改后才处理指定问题。不得用混合模式冒充透明；HTML 复刻艺术字直接生成透明底。

### 跨屏背景与图片衔接

- 优先联合构图或基于实际母版扩展；独立图窗保留边界，换章可明确硬切。分开生产时记录前图版本、交接区、透视、主体和纹理尺度、光向及景深；同色 Prompt 不等于同源连续。
- 依赖真实边缘的扩图串行，先以最终素材和文字试排相邻区域。仅向指定方向延续，不拉伸原图；结构断口不靠黑幕、白雾或渐变遮盖，仅局部色阶差异可适当融合。
- 仅安全空场用于 Alpha 衔接，文字、Logo、主体及接触面不得受侵；接缝净空和保护范围按 common，仅 HTML 排布可按 quality 记录衔接问题，不检查或修复图片接缝。

### 多图规划、并行生成与合成

适用于套图、多页图片、长图分段及多图＋拼接任务。共享本节的执行方式，各题材的内容、页序和交付职责保持不变。

- **先规划全部输出。** 沿用当前任务记录或同一 Brief，确定数量、固定页／段号、阅读顺序、逐图完整文案、尺寸、构图和共享视觉参考；每个调用准备独立完整的提示词。生成前明确最终交付独立图片，还是独立图片加拼接成品，不按工具批次改变产物数量。
- **独立任务默认并行。** 输入齐备后并行调用生图工具，封面、内页和尾页不默认互相等待。超过实际并发上限时分批并行，不新增批次确认。各调用实传共同身份参考，并沿用已确定的配色、字体气质与背景关系，不将尚未返回的封面或前段设为普通多图的必需输入。
- **真实依赖局部串行。** 必须先建立身份母版、用户要求先确认封面，或需以前图真实边缘扩图时，先完成相应前置；依赖解除后并行生成已就绪的输出，其余独立任务不等待。仅因内容连续、需要同风格，不建立逐图串行依赖。
- **随返回随交付。** 每张结果返回即按固定页／段号交付，记录其真实引用与版本；返回先后不改变阅读顺序，不为凑齐整批扣留结果，也不自行重生已返回图片。
- **按交付职责合成。** 独立套图逐张交付，用户未要求时不自动拼成长图；长图及已要求拼接的任务，全部必要图片返回后按规划顺序、同一版本执行合成。长图尺寸与接缝按下节处理，其他拼图按已定布局合成，不拉伸或裁掉必要内容。拼接成品取得独立引用并立即交付，不能替代各张图片。缺图时保留并交付成功项，说明缺项，不用残缺拼图冒称完整成品。

### 长图分段与拼接

- 所有入口允许的纯图长页，以目标正整数宽 W、高 H 判断：**`H/W > 16/9`，即 `H × 9 > W × 16`，必须分段生成并拼接。** 恰好宽高 9:16 不强拆；低于或等于阈值但能力不足时仍可分段。未知高度先按内容和宽度估算记录，不缩短锁定尺寸规避拼接。
- 按章节和低信息接缝划段，逐段明确目标宽高；单段原则上不高于同宽 9:16，并符合工具比例及分辨率能力。不切开标题、商品识别面、表格行、证据或完整信息组；卡片的标题、正文、配图及边框须完整落在同一段内，不在上下缘截断或依赖相邻段补齐。
- 各段等宽；无重叠时段高总和等于整图高度，重叠仅设在纯背景冗余区，拼前只裁除此类区域，最终高度扣除真实重叠。不得为凑高度裁切、覆盖或羽化内容及其完整边界；未事先确定裁切范围时保留完整段图并直接拼接，不通过成品检查追加裁切。
- 每段 Prompt 包含本段完整文案、信息组完整容纳要求、全图视觉约束及上下缘背景接续，不把接续写成跨段延续半张卡片。按上节并行生成、逐段交付并保留合成输入映射；全部所需段就绪后，按规划顺序读取合成所需尺寸并执行原定拼接。此读取仅用于计算，不评价产物或触发重做。
- 使用已部署合成工具或平铺于 `scripts` 的确定性脚本。原等宽纵向拼接器遇宽度不一致即失败，不自动修接缝；重叠按上述范围先裁切，拼接结果返回即交付，不核对成品顺序、尺寸、接缝、内容丢失或遮盖，不自主回退或重拼。Pillow 等依赖缺失时使用实际可用替代工具或报告阻塞，不伪造结果。
- 拼接不是 HTML 排版，不拆字、覆字或拉伸补错。完整长图是新产物，取得独立真实引用；**段图与最终长图分别在生成后立即交付**，不能互相替代。
- 既有长页优先复用原分段及未改像素，仅改授权段和必要接缝；只有扁平图时保存基线并按能力定位拆段，不要求不存在的参数文件，不因高度重生整图。

## 5. 输出形式

- **记录沿用现有载体。** 简单纯图沿用对话与实际调用记录；复杂任务只更新题材已有 Brief，不另建生产 Brief 或参数合同。混合组装素材沿用唯一 `asset-manifest.json`，按“页面／章节＋图片名称”对应；纯图成品及套图不强加代码素材清单。
- **调用与版本可追溯。** 保存真实参考及顺序、完整 Prompt、请求参数、实际尺寸、用途、原始结果和处理版本。返回即回写真实引用、调用标识及稳定结果序号；所有返回图及未采用图均交付并保留，衍生版本回指输入、操作和回退版本。缺地址标待补，不造 URL 或记录，不倒改已确认设计。工具执行失败不伪造结果或原样重复请求。
- **混合素材记录采用关系。** 每素材项一个 `output`；同结果多处复用，不同采用结果分项。沿用 `asset_id`、`consumers`、`reference_inputs`、`postprocess` 定位实际消费者。纯图成品按上一条保留调用与版本记录，不要求这些组装字段。入口允许且符合用途的已有图片直接复用，不为流程重生。
- **交付统一走真实出口。** 纯图展示与交付按主入口；仅 HTML 检查读取 quality，混合素材与其他图片不校验。已有可用引用不为展示重复下载重传，授权合成读取像素除外；本地产物须取得真实可用引用。Brief、Prompt、日志不混入成品附件，除非用户索要。
