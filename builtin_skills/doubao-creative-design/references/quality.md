# HTML 检查与结果交付

**读取方式**：按主入口的任务与阶段指引直接读取本文件；已有内容沿用，仅补读当前任务需要的关联规范。纯图阶段不执行 HTML 专属条款，模板资产仅在实际选中后读取完整正文及必要依赖。

**结果处理（所有场景）**：所有产物返回即按[主入口](../SKILL.md#交付规范)用 RichMediaCard + 真实短链交付；HTML 仅交付 `creative_design_preview` 的设计预览／编辑入口短链，不交付源文件。非 HTML 产物一律不做产物校验，包括混合素材和拼接结果。HTML 可检查，但检查不延后交付；只有符合 [quality 单轮溢出例外](quality.md#内容溢出允许增长长度的有限例外)的 HTML 可自主增长长度，同一任务最多一轮。该例外优先于本文件中只记录、不自主改高或重排的一般限制；除此之外，必须用户明确说改才改。不得因效果不好自主重生、修图、替换或重排。继续完成原定未完成产物和首次预览，不擅自增加优化轮次。

**HTML 规则**：仅在用户明确要求或同意可自由编辑时，才生成或修改 HTML 及相关产物，已有明确意愿直接沿用。预览必须调用 `creative_design_preview`，仅使用该工具返回的设计预览／编辑入口真实短链，通过 RichMediaCard 交付。HTML 只作为内部实现文件，禁止交付 HTML 文件、源码附件、打包源文件或下载链接。字体使用 head 内声明的豆包 CDN 远端首选字体及对应字重、样式，系统字体仅作备用，禁止检查字体可用性、字形覆盖或加载命中。 HTML 复刻以用户选中的图片为准，尽量保持风格、排版、布局和字体，题材默认样式不覆盖原图；艺术字按[混合制作](produce-hybrid.md#独立艺术标题的使用条件)复用或参考生成透明素材后排版。

## 适用范围

本文件只检查已获准制作的 HTML。图片、视频、矢量、文档、混合素材、透明字图、去底结果、分段图、拼接图及切片等非 HTML 产物均不校验；不做 OCR、对象计数、像素与尺寸检查、Alpha 检查、接缝检查或质量筛选，也不运行素材清单的就绪／准出校验来阻止采用。

生成前的事实整理、参考身份确认、内容和规格规划照常执行。工具返回的引用、版本和元数据直接记录，不为记录启动产物测量或检测。HTML 所用图片按已确定用途和真实返回引用接入，不另设素材验收。

## HTML 成品

每份完整 HTML 就绪即调用 `creative_design_preview`，设计预览／编辑入口短链返回即通过 RichMediaCard 交付。检查在交付后进行，不作为交付门槛；除下文单轮溢出例外外，只记录并简述问题，不自动修改、重新生成或再次预览。已有源局改只查看用户要求范围及必要联动区域。

- **结构与尺寸。** 查看完整文档、画布属性、作品容器、页序、原生文字与实际图片绑定是否符合本次约定。不重新检查所引用图片的尺寸、像素、透明度、文字或质量。
- **复刻关系。** 对照选中输入图片，先看画幅、区域位置、并列／嵌套关系和内容对应，再看图文占比、疏密、素材节点的呈现方式及文字层级；不因模块齐全就视为布局一致。记录明显偏差，不据此改稿，不检查字体可用性、覆盖或加载命中。
- **布局与阅读。** 依据 `creative_design_preview` 的本次完整预览与 HTML 查看正文、数据、末行和页底内容是否完整可见，区分画布越界、父容器裁切、意外遮挡与参考原有的装饰叠压；同时记录断行及相邻页面排布问题。若只看到局部截图，说明完整性尚未确认，不直接判定内容丢失。只记录 HTML 呈现问题，不扩成对非 HTML 素材的计数、OCR、透明度或质量校验。工具预览成功不等于视觉合格；发现结构偏差或溢出时如实说明，不声称已验收通过，也不扣留有效短链；符合下文例外时仅执行一次长度增长，其余不自主追加修复、预览轮次。
- **实际功能。** 仅 HTML 中用户已要求的交互可检查真实行为，如实说明已执行和未执行的项目；不追加对其他导出格式的能力测试。

## 内容溢出允许增长长度的有限例外

本节是“只记录、不自主修改”的唯一主动优化例外，其他视觉差异仍只记录。HTML 以完整预览与源结构确认溢出；非 HTML 不新增自动验收，仅在用户明确指出内容溢出时按其反馈处理。

- **先判断增长能否解决。** 正文、数据或末行因可用长度不足而超出内容区，且增加长度能使其完整呈现时才触发。局部截图未展示、图片加载失败、横向越界或无关遮挡不自动归因于长度不足；不以单纯增加外层空白掩盖父容器裁切。
- **体裁与已确认约束优先。** 只增长允许变化的纵向长度，保持宽度、文字内容及可读字号；固定纸幅的简历、印刷菜单、票券等不能擅自加长。长页或分屏仅在高度未锁定且体裁允许时增长；保持产物数、屏序及每屏内容归属，不合屏、不增屏、不把内容移到其他屏。无法同时满足约束时说明冲突，等待用户决定。
- **只做必要联动。** 按完整内容所需高度增长实际受限容器与画布，联动其后的内容和页脚位置，并同步背景覆盖、导出尺寸及 HTML 画布声明。保留未受影响的布局、素材、图像比例与版本；不拉伸图片、不缩字、不删内容、不新增装饰。若必须重生成图片素材或大幅改构图才能增长，则停止并说明限制。
- **同一任务最多 1 轮。** 将本轮已确认、符合条件的溢出项集中处理；分屏只更新受影响屏，各调用一次必要的预览／导出。所有结果仍返回即交付，保留原版并说明长度变化。在已有 Brief 或任务记录中记明本任务已用优化轮次，跨轮对话沿用，不能按屏、按问题、改名或阶段切换重置。修正后若仍溢出、出现新问题或工具失败，如实说明，不启动第二轮自主修改或以重试变相追加；用户后续明确指定修改另按其授权处理。

## 用户明确要求修改后

用户提出修改后，只修改指定内容和必要关联实现，保留未授权内容及历史版本。若修改 HTML，将受影响页面的完整新版本传入 `creative_design_preview`；新设计预览／编辑入口短链返回即用 RichMediaCard 交付。检查发现的新问题仍只记录，不开启下一轮自主修复。用户要求修改图片时按对应图像工具执行，结果返回即交付，不做产物校验。

原任务中尚未完成的页面、原计划的拼接、已获准编辑版的首次实现和首次预览可继续执行；这不授权重做已返回结果。

## 交付

所有产物遵循[主入口](../SKILL.md#交付规范)。HTML 仅交付 `creative_design_preview` 返回的设计预览／编辑入口真实短链，禁止发送 HTML 文件、源码或下载地址，具体见 [canvas-delivery](canvas-delivery.md)。有返回结果就交付；无结果或无可用设计入口短链时，按 canvas-delivery 如实说明未完成项，不伪造、不以质量判断隐藏已有结果。
