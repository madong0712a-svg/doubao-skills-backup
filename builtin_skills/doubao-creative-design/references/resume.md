# 简历规范

**读取方式**：按主入口的任务与阶段指引直接读取本文件；已有内容沿用，仅补读当前任务需要的关联规范。纯图阶段不执行 HTML 专属条款，模板资产仅在实际选中后读取完整正文及必要依赖。

**结果处理（所有场景）**：所有产物返回即按[主入口](../SKILL.md#交付规范)用 RichMediaCard + 真实短链交付；HTML 仅交付 `creative_design_preview` 的设计预览／编辑入口短链，不交付源文件。非 HTML 产物一律不做产物校验，包括混合素材和拼接结果。HTML 可检查，但检查不延后交付；只有符合 [quality 单轮溢出例外](quality.md#内容溢出允许增长长度的有限例外)的 HTML 可自主增长长度，同一任务最多一轮。该例外优先于本文件中只记录、不自主改高或重排的一般限制；除此之外，必须用户明确说改才改。不得因效果不好自主重生、修图、替换或重排。继续完成原定未完成产物和首次预览，不擅自增加优化轮次。

**HTML 规则**：仅在用户明确要求或同意可自由编辑时，才生成或修改 HTML 及相关产物，已有明确意愿直接沿用。预览必须调用 `creative_design_preview`，仅使用该工具返回的设计预览／编辑入口真实短链，通过 RichMediaCard 交付。HTML 只作为内部实现文件，禁止交付 HTML 文件、源码附件、打包源文件或下载链接。字体使用 head 内声明的豆包 CDN 远端首选字体及对应字重、样式，系统字体仅作备用，禁止检查字体可用性、字形覆盖或加载命中。 HTML 复刻以用户选中的图片为准，尽量保持风格、排版、布局和字体，题材默认样式不覆盖原图；艺术字按[混合制作](produce-hybrid.md#独立艺术标题的使用条件)复用或参考生成透明素材后排版。

适用范围：题材的内容、布局与阅读要求用于生成前规划、提示词及首次实现；后续调整只执行用户明确要求的范围。HTML、原生层、字体资源与模板条款仅用于已获准的可编辑设计；产物检查仅限 HTML，不检查图片及其他非 HTML 产物。

目标：用真实履历和岗位相关证据说明个人能力，满足实际投递、人工阅读与检索要求。

适用产物：求职简历、学术简历及履历与精选作品结合的简历；不用于招聘广告、个人海报或独立作品集。

**核心流程**：明确岗位与规格 → 组织履历证据 → 确定视觉与布局 → 调整纸幅容量 → 制作简历，结果返回即交付。

沿用有效方案和完整源，局部修改保留未授权内容、页数、尺寸与风格。执行归属统一见 [SKILL.md](../SKILL.md)；需求与事实记录见 [common.md](common.md)，仅保留人像等身份按主入口图像工具指南处理，版式／风格复刻见 [reference.md](reference.md)，编辑边界见 [edit.md](edit.md)，生产及 HTML 检查分别见对应共用文件，不在本文件重复展开。

## 1. 明确岗位与规格

| 采用条件 | 具体动作 |
| --- | --- |
| 通用求职或人工阅读 | 让读者快速找到姓名、方向、联系方式、近期经历与最强证据；按岗位相关性分配篇幅 |
| 明确要求招聘系统读取 | 优先线性单列，使 DOM 与视觉顺序一致；按已知能力提供对应格式；仅 HTML 可检查读取行为，不测试其他产物，不承诺普遍兼容 |
| 作品结合型 | 保留清楚履历主线，用真实作品、本人角色、成果及真实链接证明能力 |
| 学术简历 | 保留研究问题、方法、发表、作者角色、准确作者、期刊、日期、DOI及研究条件，不为美化删改引文要素 |

- **纸幅默认 A4，210×297 mm。** 用户要求 A5，148×210 mm 时，重排内容与布局，生成前按目标阅读尺寸规划字号和安全区，不直接缩小 A4。
- **页数默认1页。** 用户明确要求多页并明确页数后采用多页，学术简历不自动增页。用户与投递要求优先；换纸幅不自动加页或删除非重复事实，不改成长图。

## 2. 履历事实与证据组织

### 2.1 写成可直接排版的完整文案

- 核对姓名、联系方式、学校、组织、职位、项目、日期、客户、技能、资质、奖项和数字。招聘要求只用于排序，不用于补造能力；搜索不用于制造个人履历。
- 区分本人动作、负责范围与团队成果。保留日期冲突、重叠、空窗及不明指标口径的待核实状态，不自行修正历史或推断原因。
- 基于事实优化定位、标题和表达，不增加未证实的身份、能力、结果或承诺。正式投递前完成必要核实，清除占位和写作指导，不静默删除缺口。
- 每条优先写“本人动作＋对象／方法＋真实产物或结果”。用职责说明持续贡献，用项目展开关键问题，不在两处重复同一事实。
- 无量化结果时，写真实产物、采用情况、交付范围、上线或审核状态、协作复杂度，不补百分比。技能名称附真实使用证据，不用星级、进度条或百分比自评冒充测量。

### 2.2 分配顺序与篇幅

按“身份与方向 → 最相关证据 → 经历细节 → 补充信息”组织第一页。应届生可先放相关项目、实习与教育；有经验者先放相关工作与成果，不要求每段等长。

按岗位相关性、证据独立性和职责覆盖分配篇幅，合并同义表达，不混写不同项目、角色或结果。近期相关经历可从 **3–5条**、较早或低相关经历可从 **1–2条**试排；条数仅作参考，不作为删事实指标。锁定原文不自行删除，任何非重复事实删减须用户决定。

| 采用条件 | 具体动作 |
| --- | --- |
| 职责笼统、内容不足 | 补清已知任务、本人动作、工具、产物和结果；未知内容待补 |
| 项目事实充分但说明不足 | 展开对象、范围、协作角色、难点、决策依据及交付物，不发明客户、规模或成果 |
| 技能与教育有来源且相关 | 补真实使用场景、课程、课题、作品或活动，不堆无关课程与技术名 |
| 已知事实已充分表达 | 用留白分组，不用无关内容和装饰填满；仍不足时指出最值得补充的岗位相关事实 |
| 用户已明确要求多页 | 首页独立说明身份、方向与最强证据；后页保留身份、页码及必要索引，不重复巨大页眉 |

多页经历尽量不截断，章节标题不孤立留在页尾；跨页写清续接。末页仅余零散几行时先重组文案，不加装饰填满，也不擅改页数。

## 3. 视觉调性、布局与模板选择

### 3.1 保留行业辨识度

优先采用用户指定风格与参考，在事实、锁定内容、渠道及打印要求内调整；行业只作选型依据。

| 采用条件 | 具体动作 |
| --- | --- |
| 艺术／设计／内容，需鲜明表达 | 用鲜明主色与对比色、个性标题配清晰正文；采用非对称、错位分栏或作品主视觉，保持履历顺序，展示作品、角色、判断依据、成果和链接 |
| 金融／投资，需理性稳重 | 以黑白灰为主，深蓝或墨绿点缀；数字对齐、规整分区，突出资质、责任、合规要求和可验证实践 |
| 法律／医疗／机构，需正式可信 | 用白底深墨、低饱和强调和中粗标题；统一机构、职位与日期轴线，写清资质及责任边界 |
| 技术／数据／工程，需结构清楚 | 用黑白灰、单一强调色、无衬线正文和少量等宽英数；对齐时间与证据，突出范围、方法、复杂度、产物及验证结果 |
| 产品／咨询／管理，需突出决策与交付 | 用浅底、企业深色、中粗标题和中性正文；主区呈现决策、协作、推进与交付，区分个人和团队贡献 |
| 市场／增长／运营，需鲜明节奏 | 用中性底、鲜明强调色、粗标题和清晰数字；逐项目对应渠道、周期、指标口径、本人动作与实际结果 |
| 教育／公益／服务，需亲和耐读 | 用暖白、自然色与深墨正文；按服务经历分组，突出对象、方法、范围及有依据的影响 |
| 学术／科研，需连续阅读 | 用黑白灰、少量定位色、长文正文字体与统一引文格式；沿单轴组织研究与发表信息 |

### 3.2 按内容选择模板与布局

模板选型见 [templates.md](templates.md)。用完整真实文案，尤其最长姓名、机构、职责及链接判断容量、阅读顺序和图文关系；不因换色、换字体或可替换图片直接否定结构。明确整页或局部采用，不为套模板改事实；少内容时调整栏宽、模块与图窗，不撑高空卡片。

1. **按内容初选。** 根据履历长度、元数据占比、证据关系、真实图片与投递要求，从布局表选择结构，再从风格表细化表达；行业只作选型依据。
2. **分组取词。** 构图查询“简历”及“通用”，容器、点缀、材质与特效查对应通用组。表中各词分别查询，真正同义词才用 `|` 合并；风格名称关键词不等同于工具的 `--style` 标签。已有有效方案只处理受影响部分。
3. **读后试排。** 按 [templates.md](templates.md) 的 `match → describe → read` 完整读取候选及必要依赖，明确整页或局部采用。用真实文案、最终字体和图片在锁定纸幅内试排，再记录采用范围与调整；通用长页只借局部关系，系统读取仍须实测。无适配候选时沿已选方法组织，不改履历事实、字号下限或页数凑模板。

| 采用条件 | 具体动作 | 检索词与借用范围 |
| --- | --- | --- |
| 通用投递、学术或系统读取 | 采用单轴线性履历，姓名、定位、优势、经历向下推进；右侧只放简短辅助信息 | 构图·通用：`单列正文疏朗留白`、`左侧成组标签与右侧项目说明的履历行`（借单列或条目关系） |
| 人工阅读且短元数据较多 | 采用经历主栏＋信息侧栏，可从70/30或75/25试排；窄栏不塞长句，联系与技能不和成果等权；系统读取另验顺序 | 构图·简历：`主次双栏与窄侧栏`、`主次双栏与竖标题`、`分节双栏与贯穿侧栏` |
| 长文、管理或学术内容 | 采用分章节出版页，以页眉、章节和段距组织；多页保持日期及章节连续 | 构图·简历：`竖排栏目导轨`（借栏目定位）；构图·通用：`章节眉线`、`同轴编辑式分隔线` |
| 项目、角色、方法与结果需对应 | 采用证据矩阵，统一单元但区分证据强弱，不做等权卡片墙 | 构图·简历：`横向分行与标签对齐`、`通栏双栏与网格对齐`；构图·通用：`证据信息网格对齐` |
| 人物或作品确为视觉重点 | 将人像／主作品置于一侧或上部，履历沿稳定事实轴排列，不挤压姓名、定位和经历 | 构图·简历：`上图下文与大字并排`、`非对称身份侧栏`、`曲线分区与人像穿插`（按事实轴适配） |
| 获准多页的作品结合型 | 采用编辑式跨页叙事，首页给方向与强证据，后页按案例接续，每页独立可识别 | 构图·通用：`章节纵向连续递进`（借案例接续关系，逐页重排） |

### 3.3 按表达目的细化风格

名称关键词用于寻找对应手法，不代表整行效果全部具备。通用构图借相关局部；专属模板仍按真实履历调整，样例照片、文字与技能表达不沿用。

| 采用条件 | 具体动作 | 检索词与借用范围 |
| --- | --- | --- |
| 克制编辑、出版感 | 用衬线姓名配无衬线事实、小型页缘标识和舒展段距；避免细衬线小字与散文式长自述 | 构图·通用：`人文出版`、`同轴编辑式分隔线`（借出版节奏与分隔） |
| 企业治理或项目比较 | 用中性字体、稳定网格和低干扰边界建立层级，不默认蓝侧栏，不将全部经历装入同款圆角卡 | 构图·简历：`极简理性`、`瑞士网格`（借网格秩序，字重按阅读要求调整） |
| 工程与数据证据密集 | 明确时间轴，对齐英数与结果，少量使用技术标签，不用伪代码背景，不让关键词压过成果 | 构图·简历：`简介双栏与时间轴`、`蓝色编辑选框与时间轴`；构图·通用：`日期机构说明行与时间线` |
| 多个代表案例可比较 | 可选1–3个代表案例，统一图窗比例，旁列角色、时间、职责与结果，不为凑数新增案例 | 构图·通用：`证据信息网格对齐`（借案例字段对齐） |
| 单项主案例足以说明优势 | 用主案例图、受控一级标题及线性事实区；姓名、岗位、联系和近期经历仍易定位 | 构图·简历：`上图下文与大字并排`（借主图与事实分区） |
| 产品／内容流程可证明贡献 | 将真实截图与准确说明共轴排列，保留核验上下文，不重画界面或虚构指标 | 构图·通用：`左侧成组标签与右侧项目说明的履历行`、`带引导线的图像标注`（借说明对应关系） |
| 需要人物识别 | 用3:4本人证件照和稳定身份区，保持自然肤色；附加半身照不挤掉价值摘要 | 构图·简历：`人物专题`、`非对称身份侧栏`（借身份区，照片仍按本人素材与3:4要求） |
| 有真实环境照或领导力表达依据 | 用真实负空间与姓名、定位共轴；领导力档案结合真实影响范围和治理型数据，不用豪华黑金、空泛名言或头衔替代业绩 | 构图·简历：`双色姓名粉带与情境照片`（借环境照与姓名关系） |
| 作品结合型、平面印刷表达有依据 | 用有限套色、粗标题、局部网点或套印配清晰事实栏，错版效果不盖正文，不做成活动海报 | 构图·简历：`字体潮流`、`波普拼贴`（借标题与色面关系）；特效·通用：`套色网印与错版颗粒` |
| 真实作品适合档案索引 | 用作品切片、索引、票签和扫描纹，逐项可追溯，不虚构票据或让胶带贴纸压过经历 | 构图·简历：`照片剪贴`；构图·通用：`票据档案`（借索引与纸面关系） |
| 插画或符号确能体现个人表达 | 统一线条、角色或符号，事实区仍按清晰顺序排列，不用通用头像代替本人，不用图标替代技能文字 | 构图·通用：`涂鸦手作`（仅借插画与分组关系） |
| 用户明确要求互动或游戏语言 | 局部采用像素、窗口或复古数字索引，窗口不遮挡；保留原生履历和静态阅读能力，系统读取须实测 | 容器·通用：`圆角顶栏卡片`；点缀·通用：`像素斜指针`（局部窗口与符号） |

### 3.4 选择局部容器与图片承托

优先用对齐、段距和分隔线组织履历。摘要、联系或重点项目确需独立分组时，用低圆角浅面或薄边；姓名、摘要、成果需分层时可用克制阶梯面板，避免证书感。纤维纸、档案页、口袋、撕纸仅用于有依据的创意媒介表达；照片衬纸和胶带只服务图片；胶囊与徽章只放少量短标签。规则容器与简单图形原生实现，叠层不遮人脸、日期、正文或链接。

| 局部用途 | 检索词与借用范围 |
| --- | --- |
| 浅面与薄边分组 | 容器·通用：`圆角矩形无描边`、`圆角矩形细描边` |
| 姓名、摘要、成果分层 | 容器·通用：`卡片与面板`（借阶梯轮廓，保持克制边框） |
| 纤维纸与档案页 | 容器·通用：`文件夹-纤维纸张`、`不规则档案纸与报纸面` |
| 口袋与撕纸 | 容器·通用：`绕线档案袋`、`不规则撕纸边` |
| 照片承托 | 点缀·通用：`照片衬纸与胶带` |
| 短标签 | 容器·通用：`胶囊与徽章` |

## 4. 字体、色彩与阅读要求

### 4.1 字体与文字能力

字体按 [fonts.md](fonts.md) 选型并直接填写，不检查可用性、加载或字形覆盖。用真实姓名、组织、职位、日期、项目、长链接和混合语种安排排版。

| 采用条件 | 具体动作 |
| --- | --- |
| 通用、商务或系统读取 | 用中性无衬线；姓名粗体、章节中粗、正文常规，数字可等宽，以字级和段距支持扫描 |
| 人文、文化、管理 | 用衬线姓名或章节配无衬线事实，小字与链接不用细衬线 |
| 创意、作品结合型 | 展示字只用于姓名和作品一级标题，公司、日期、链接及结果保持中性；粗印刷或手绘感用真实字体与CSS表达 |
| 技术、数据、产品 | 用几何标题与无衬线正文，英数及短技术标签可等宽，中文长段不用等宽字 |
| 研究、教育或多页学术内容 | 用清晰长文正文字体和稳定编号，保持引文与出版格式 |

**HTML 简历以选中图片复刻，保留字体气质、排版、布局与层级。** 姓名、标题和正文通常使用可编辑、可选择、可复制的原生文字；原图中过于艺术化的文字按 [produce-hybrid](produce-hybrid.md#独立艺术标题的使用条件) 复用或参考生成透明底字图后排版，并说明该图层可移动、缩放和替换，内部文字不可逐字编辑。已有位图局改不自动重建 HTML。

A4试排起点：**姓名24–42 pt、定位11–18 pt、章节10.5–14 pt、正文8.5–10.5 pt、日期8–9.5 pt**。A4正文不低于8.5 pt；这些数值用于生成前规划，不扩成其他载体的下限。按原始履历长度和目标阅读尺度安排，不在图片返回后测量字号或测试打印效果；HTML 发现问题只记录，用户明确要求后才调整。

区分母版、采样倍率与物理阅读尺寸：1 pt＝4/3 CSS px，毫米×96÷25.4＝CSS px；增加导出像素不等于提高物理字号。

### 4.2 配色与背景

| 采用条件 | 具体动作 |
| --- | --- |
| 通用、学术或灰阶打印 | 用黑色正文、灰色辅助和单一定位色，灰阶仍读清日期，不仅靠颜色编码事实 |
| 出版感、人文或自然人像 | 用暖白配深棕／墨蓝，不以低对比米色弱化事实 |
| 现代编辑、技术或作品 | 用黑白配高对比强调，重点落在姓名或关键结果，控制面积，不变成海报 |
| 教育、公益、服务或手作表达 | 用克制自然色配真实人像，正文保持足够墨色，不让柔色抹平层级 |
| 管理、咨询、金融或技术 | 用清晰浅底配企业深色区分章节，避免大面积深底影响打印 |
| 创意、作品或已有个人品牌 | 用有限套色或已有品牌色，明确主辅职责，跨页保持主色，不逐页换色 |

明确纸面、正文、次级文字、主色与强调色的职责。纹理、肌理或渐变按定位与实际露出区域选择，优先极弱纸纹、低对比肌理或克制渐变，不以装饰配额驱动版式。HTML/CSS适用的整页背景条件见 [produce-image.md](produce-image.md)“背景制作”；正文区保持低干扰，不损害字形、对比、灰阶打印或读取。无附加图不等于取消共用背景条件。

| 纹理用途 | 检索词与借用范围 |
| --- | --- |
| 极弱纸纹或纤维纸面 | 特效·通用：`轻纸纹`；材质·通用：`纤维纸张` |
| 低对比颗粒肌理 | 特效·通用：`空间调制的灰度颗粒`（降低阅读区对比） |
| 克制渐变 | 特效·通用：`细颗粒柔雾色场`（近似柔和色场，按需调整颗粒） |
| 已选印刷或档案表达 | 特效·通用：`套色网印与错版颗粒`、`正文后置薄扫描线`（只用于适合的局部表面） |

## 5. 固定纸幅容量

锁定宽高、页数、安全区和字号，在原页面内安排完整事实。以最长真实姓名、邮箱、机构、职责及链接判断容量，不以短占位文案代替。局部记录可因换行增高，但总高须留在锁定纸幅内；窄窗口不改变作品尺寸，自然高度只用于诊断。

采用原库三套 **800×1132 px** 简历母版时，沿用四边 **48 px，约12.6 mm** 的排版基准；此值不是通用印刷标准，其他分辨率按物理距离换算。姓名、联系、正文、日期和页脚均在安全区内；装饰可出血，人脸另设保护范围。首次实现按完整文案预留文字边界和页脚位置。

**步骤1：整理表达。** 合并重复职责与同义成果，收敛未锁定的空泛自评和修饰语。按相关性、独立证据和职责覆盖排序；同类短项目可分组，但名称、角色和不同结果不混写。删减非重复事实由用户决定。

**步骤2：实现真实换行。** 姓名换行后推开下文；邮箱和链接在自身容器断行，保留全文与目标；机构标签随内容增高。短年份区间尽量同行，日期整组放不下时移至下一行，不截断。

**步骤3：联动调整布局。** 同组统一调整栏宽、栏距与标签换行，保持职位—组织／日期—职责对应。标题撞照片时调整照片位置和标题区，不盖住脸。

**步骤4：收敛非信息空间。** 适度减少模块与记录间空隙、装饰和照片占比，拓宽正文列，保留字号、事实、日期、全部条目与安全区。不压缩字形或使用不可读行距，不用省略号、行数截断、滚动框、透明文字或隐藏溢出藏正文。

**步骤5：说明容量冲突。** 仍装不下时指出冲突字段和保持字号的重排结果，提出逐项精简建议；保留姓名、联系、目标、组织、职位和日期，不自动删项、加页或加长画布。

## 6. 本人照片与作品证据

从用户简历、附件或图片中选取当前候选人的真实人像，优先确定性裁切为 **3:4证件照**。缺照时可继续内容草稿并注明“证件照待补”，不按姓名或履历生成替身。用户明确无照，或渠道明确要求无照时可省略并记录依据；环境照、艺术照及半身照仅作已规划附加，不替代规定证件照。

保留五官、表情、年龄、肤色、发型、体型及服装身份。获准编辑只调整背景、曝光、构图或非身份干扰，保护头顶、下巴、肩部和面部；不新增虚构职业场景冒充任职，身份漂移时回用原图。

作品逐项绑定经历、本人角色、真实短链、归属和允许处理范围。截图不重画成更高级项目，裁切保留核验成果所需上下文，隐私处理须获授权。已有短链不省略，缺失标“短链待补”，不造URL或以本地路径冒充。

| 采用条件 | 具体动作 |
| --- | --- |
| 额外图片不能增加履历信息 | 不加附加图，用原生线条、形状和文字组织；照片仍按上述条件处理 |
| 有可追溯数据或技术资料 | 用准确原生图表、真实截图和必要图标，标签可检索 |
| 多项作品需快速浏览 | 统一缩略图比例、边缘、编号和后期，每图绑定项目事实 |
| 流程或界面可说明贡献 | 使用真实资料或明确示意，用原生文字准确说明 |
| 有真实环境人物来源 | 保持同一人物、真实环境与可用负空间，不暗示虚构经历 |
| 已选印刷、档案或插画表达 | 分别采用局部网点套色、可追溯作品切片或统一插画系统；不伪造证书、凭证、成果或本人身份 |

图片等比显示，生成前在提示词或首次 HTML 实现中保护人脸、肩部和作品证据。源图作为用户输入读取，返回的处理图和其他产物不做比例、缩放或有效像素校验；HTML 节点布局见 [produce-code.md](produce-code.md)。

## 7. 专项可用性与交付组织

生成前根据真实履历安排姓名、联系、组织、职位、日期、指标和作品归属，明确固定纸幅、页数、安全区及阅读顺序。普通文字在已获准 HTML 中保留原生层；艺术字图片层只能移动、缩放和替换，内部文字不能逐字编辑。

简历图片、PDF 及其他非 HTML 格式返回即交付，不做事实回查、阅读测试、像素检查、文字提取或招聘系统兼容测试。仅 HTML 可按 [quality.md](quality.md) 记录原生文字、布局与功能问题，不能自动修复；用户明确说改后才处理指定范围。

交付原定版本、页数和投递格式，不增加无照版、系统版、封面或长图。HTML 完整源内部保留，只交付 `creative_design_preview` 返回的设计预览／编辑入口短链 + RichMediaCard；其他格式真实生成后直接交付。图片不冒称可复制文件，未测试的兼容性与打印效果如实说明。

### 专项制作要求

- **人像输入约定：** 实际传入本人的原图或工具支持的可用引用，并在提示词中标为图 1；其他参考按用途依次编号。不能取得本人原图时请用户补充，不因输入尚无短链阻塞已有可用原图的编辑。
- **首次容量规划：** 使用真实姓名、邮箱、机构和职责安排空间，不注入虚构履历做压力测试，不因检查结果停止已有产物交付或自动重排。

### 图片交付后的编辑选项

在全部简历页面图片交付后，询问：“需要再生成可自由编辑的简历吗？你可以修改经历、联系方式和文字排版。”沿用真实履历与固定纸幅；用户明确要求可复制、可搜索或招聘系统读取时，按实际能力提供对应格式；仅 HTML 可检查功能，其他格式不校验，也不虚称已通过系统适配测试，不能以图片交付代替。

提问时机、已有意愿处理及同意后的制作见[追问与承接](editable-upgrade.md#追问与承接)，同一任务不重复追问。
