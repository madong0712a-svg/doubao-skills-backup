# audio-denoise 子能力指南

音频降噪：去除录音中的背景噪声、电流声、风噪、嗡嗡声，基于 ffmpeg 滤镜链（afftdn/highpass/lowpass）。 当用户说"降噪""去噪""去杂音""消除背景噪声""电流声""风噪""录音有杂音""音频降噪"时使用。 和 audio-editing 的区别：audio-editing 做剪辑/转码/音量等通用音频操作（内置 denoise 兜底），本 SKILL 专做降噪调参。
