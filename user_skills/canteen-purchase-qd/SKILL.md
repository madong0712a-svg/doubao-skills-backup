# 食堂采购清单处理

## 概述

处理每周五微信「黑池彤彤」发来的手写食材清单：先识别成待审核 Word 表交用户核对定稿，定稿后再录入微信小程序采购申请并提交核验。**顺序闸门：未获用户审核定稿前，不操作小程序、不提前下单。**

## 固定业务口径（默认沿用，无需再问）

| 项 | 值 / 规则 |
|---|---|
| 采购餐厅 | 合阳县新池镇中学（小程序自动带出） |
| 供应商 | 列表第一项：合阳县腾婷青菜干菜店 |
| 联系电话 | 系统自动带出，不手动填写、不修改 |
| 计量单位 | 斤；区域名称非必填，跳过 |
| 存疑处理 | 看不清的品名/数量/单价不臆造，标「待核对」一次性列给用户确认 |

## 流程

### 1. 取图、预处理、辨认
1. 微信对话中把清单原图另存到当天工作目录。
2. 跑预处理脚本分段放大增强：
   ```
   python scripts/preprocess_qd.py <原图路径> <输出目录> 2
   ```
3. 辨认顺序：先数量（查小数点、末尾 0、十位漏读；形近 5↔9、1↔7、0↔6 二次放大），再品名，后单价。
4. 三类最易混，拿不准一律挂「待核对」，不硬套菜名：
   - 叶菜：青菜 / 韭菜 / 蒜苗 / 青笋
   - 根茎：白萝卜 / 红萝卜 / 花白 / 白菜
   - 小果：圣女果 / 苹果 / 橘子 / 橙子
5. 整行涂黑/缺字标「待补充」，不臆造。

### 2. 填数据 JSON 并自检
1. 复制 `assets/qd_data.example.json` 为当天数据 JSON，填 `title`、`output_dir`、`restaurant`、`supplier`、`sheets`（每单 `{date, rows:[{name,qty,price,note}]}`）。
2. 跑自检（兼容旧单 `rows` 与多单 `sheets`）：
   ```
   python scripts/check_qd.py <数据.json>
   ```
   按提示复核词库未收录品名、单价越界、小数点、分单与总计合计。

### 3. 生成待审核 Word 表
```
python scripts/make_qd_word.py <数据.json>
```
产出《title（待审核）.docx》，每单一表、自动算金额合计，备注非空行汇总到文末「待核对事项」。交用户在本地/Canvas 内逐项核对；用户改完后**回读最新文档数据**作为录入依据，不凭记忆。单张旧表如需 xlsx 可用 `scripts/make_qd.py`（仅单 rows）。

### 4. 小程序新建申请并逐项加食材
1. 小程序历史采购单页 → 返回首页 → 点「采购申请」。
2. 收货时间选清单对应日期；供应商选第一项；电话自动带出不动。
3. 每一行：先查 `references/识别复盘记录.md` 第七节档案映射 → 搜索品名 → 点蓝色 **+** → 点数量框弹窗 → `Ctrl+A` 清空 → 输数量 → 确定。档案价与清单价一致的保留，不一致的留到下一步统一改。

### 5. 回明细表改单价
1. 全部加完回明细表，按「品名+数量+单价」逐行核对（明细顺序与清单序号不同，勿按行号对）。
2. 单价不符：点单价框 → `Ctrl+A` → 输清单单价 → 回车（明细单价直接编辑，不弹窗）。
3. 改完核对底部总斤数、总金额与定稿合计一致。

### 6. 提交并核验
1. 点「提交采购申请」→ 等「提交中…」结束。
2. 回历史列表核验新单：种类数、总金额、状态「待接单」、供应商、收货日期；确认无重复单据。
3. 把单号、种数、总金额回报用户。

## 验收红线

- 明细行数 = 定稿样数；总斤数、总金额与定稿合计一致。
- 每行品名、数量、单价与定稿一致；档案价不符的已改为清单价。
- 提交后历史列表为「待接单」，无重复单据；不填改电话，不擅自扩大范围。

## 资源导航

- `references/采购清单处理SOP.md`：完整操作手册、工具坑、提速清单、验收标准。
- `references/识别复盘记录.md`：历次初识别 vs 定稿差异、错误统计、易错品名对照、小程序档案映射；定稿后回填。
- `assets/ingredients_dict.json`：食材词库（标准名/别名/易混提示/单价区间）。
- `assets/qd_data.example.json`：多单 sheets 数据模板。
- `scripts/`：`preprocess_qd.py` 图片预处理、`check_qd.py` 自检勾稽、`make_qd_word.py` Word 多表生成、`make_qd.py` 单表 xlsx（旧版）。

## 环境与依赖

- Python 3.13；依赖：python-docx、openpyxl、Pillow（见模板目录 requirements.txt）。
- GUI 操作前先截图；CU 偶发中断等 2 秒重截图，坐标以新帧为准。
- 小程序登录态失效需用户介入登录；脚本与词库不存密码。
