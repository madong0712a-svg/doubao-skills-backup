# 中文起名

按“定喜用神 → 五行选字 → 音形义筛名 → 出报告”的顺序做，一次给 10–20 个候选并标明取舍，不空谈寓意。

## 边界

- 起名是文化参考，不承诺运势、健康、考试结果，不说“这个名字必定如何”。
- 五行喜忌优先用用户提供的排盘结论；用户没有八字时，只能做“偏五行”的用字建议，并说明这不是严谨喜用神。
- 不臆造笔画、康熙字典数据、重名统计。脚本未收录的字，直接标注“未收录”，请用户确认或换字。
- 涉及未成年人信息时，只问起名必需项，不在回复里复述出生时间、住址等隐私。

## 第一步：采集信息

必需：姓氏、用途（人名 / 店铺 / 品牌）、性别或气质倾向（男 / 女 / 中性）、期望寓意（品德、学识、志向、健康、才华、事业等）。

可选且能显著提升质量：出生年月日时与出生地（用于排盘定喜用神）、家族字辈、要避开的字（长辈名讳）、方言读音、单字名还是双字名、是否接受生僻字、已否定的名字。

缺必需项就问，一次问清，不要边做边补。

## 第二步：定喜用神

- 用户已给出“喜用神/忌神”：直接采用，按其顺序排优先级，第一喜用神权重最高。
- 用户给了完整出生时间：按 `references/bazi-yongshen.md` 的口径判断日主旺衰取喜用神；需要精密排盘时，先用命理类技能排出四柱，再来本技能选字。
- 什么都不给：按“姓氏五行 + 明显的五行缺口 + 气质偏好”给用字方向，并明确标注这是“偏五行建议”，不是严格喜用神。

## 第三步：选字与生成候选

```bash
python scripts/name_tool.py gen --surname 马 --yongshen 木,水 --gender male --theme 品德,学识 --count 20
python scripts/name_tool.py gen --surname 段 --yongshen 火 --gender female --len 1 --count 10 --out 取名报告.html
python scripts/name_tool.py score --surname 马 --name 马梓涵 --yongshen 木,水 --theme 学识
```

参数：`--surname` 姓氏；`--yongshen` / `--jishen` 喜用神、忌神五行，逗号分隔且按优先级排序；`--gender` male/female/neutral；`--theme` 期望寓意；`--len` 1 或 2（名字字数）；`--count` 输出条数；`--out` 生成 HTML 报告；`--surname-info` 给未收录姓氏补“拼音,声调,笔画,结构”。

脚本按 100 分制打分：五行契合 40、音韵 20、字形 15、寓意 15、重名与接受度 10。评分只做粗筛，最终必须人工复核。

姓氏不在内置表（约 100 个常见姓）时，脚本会提示音韵未完整校验。遇到复姓或生僻姓，先用 `--surname-info` 补数据，例如 `--surname-info ouyang,2,15,左右`。

## 第四步：人工复核（不可省）

对脚本给出的前 10–20 个名字逐条过一遍，剔除后再排序：

1. **谐音**：用普通话和用户方言各读三遍，连读是否出现不雅、晦气、嘲弄音。脚本只内置少量黑名单，不能代替人耳。
2. **字辈与避讳**：是否冲撞家族字辈、长辈名讳、同族已用字。
3. **生僻与录入**：是否常被读错、写错、打不出，是否影响学籍、证件、购票。
4. **性别气质**：是否过于阴柔或阳刚，是否与用户期望的气质一致。
5. **时代感**：是否带明显的上一代审美，或过度网红化。
6. **书写**：连写是否好看，笔画是否过繁，签名是否易被涂改。

音、形、义、字辈、五格口径的细则见 `references/naming-rules.md`；店铺名、品牌名另有注册与传播要求，同在该文件第七节。

## 第五步：交付

回复里给一张对比表，列：姓名、拼音、总分、五行、笔画、寓意、需要留意的一点。表格之后按“稳重 / 文雅 / 大气 / 少见”分组各推荐 1–2 个，说明取舍。不要把所有候选一次性堆给用户。

需要正式文件时，用 `--out` 生成 HTML 报告，交绝对路径并说明双击用浏览器打开；需要 Word 或飞书文档时，按对应技能排版。

名字释义只写关键的一句，不写“寓意深远、卓尔不凡”这类空话。

## 常见错误

- 只按“五行缺什么补什么”取名：缺的不一定是喜用，忌神补进去反而更差。
- 把热门字堆一起：梓、涵、轩、萱、沐同时出现，重名率极高。
- 为独特用生僻字：识读成本会跟孩子一辈子。
- 忽略姓氏连读：姓氏决定谐音风险，必须先连读全名再定字。
- 用康熙笔画套五格算吉凶：本技能按简体笔画只做字形均衡，不做五格吉凶，用户要五格需另说口径。

## 字库维护

字库在 `scripts/data/chars.json`，每条含 `c` 字、`p` 无声调拼音、`t` 声调、`s` 简体笔画、`w` 五行、`g` 性别倾向、`k` 寓意标签、`pop` 1–5 热门度（1 最热门）、`st` 结构。加字时保持字段完整，拼音不带声调符号，声调单独写数字。
