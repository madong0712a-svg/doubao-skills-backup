# 喜用神判定口径

用于“用户给了出生时间、需要五行方向”的场景。目标是给出可用的用字方向，不是出版级命理报告。结论要标“参考”，并说明依据。

## 一、先排四柱

1. 年柱以立春为界，不是元旦；月柱以节气为界，不是农历初一。
2. 日柱用万年历干支，时柱按日干起时（甲己日起甲子时等）。
3. 出生时间接近时辰交界（如 22:58、00:02）时，按两个时柱分别看一眼，选更贴合用户描述的那个，并注明不确定。
4. 出生地在西部时，真太阳时与北京时间可差 30–60 分钟，跨时辰会影响时柱，要提示。

## 二、判日主旺衰

看四项，不要只看一项：

- **得令**：日主在月支处于旺相（如木旺于寅卯月），还是休囚死。
- **得地**：地支有无本气根、中气根、余气根。
- **得生**：印星（生我者）是否透干有根。
- **得助**：比劫（同我者）是否有力。

综合判断身强、身弱、从强、从弱。从格不按常规扶抑，硬补反而破格，这类情况只给保守建议，不硬套。

## 三、取用神

按优先级依次考虑，命中即用：

1. **扶抑**：身弱取印比生扶，身旺取财官食伤克泄耗。
2. **调候**：冬生寒冻取火暖局，夏生燥烈取水润局，优先于扶抑。
3. **通关**：两行相战时取中间一行调和（如金木相战取水通关）。
4. **病药**：全局最重的那一处病，取能制它的五行。

喜用神通常 1–2 个，最多 3 个，按作用大小排顺序：第一喜用神 > 第二 > 调候辅助。

## 四、忌神与闲神

- 忌神：明显克破用神、加剧失衡的五行，起名要避开。
- 闲神：不影响格局的五行，可用但不必刻意补。

## 五、常见错误

- **缺什么补什么**：八字缺的五行如果是忌神，补进去更差。要先看喜忌，再看缺不缺。
- **只补一个字**：名字只有两字，补一个五行就够，两个字都塞同一五行常导致读音、字形失衡。
- **忽略姓氏**：姓氏五行不改，但会影响整体读感与谐音，选字要连姓一起读。
- **把日主当命主本人吉凶**：日主强弱只是取用依据，不能直接推出性格与命运结论。
- **用神与行业、方位混说**：起名只管用字五行，不要把职业建议、风水方位一起塞进来。

## 六、输出格式

给用户时写清三行：

- 日主：X 命，生于 X 月，身强 / 身弱 / 从格
- 喜用神：X、X（按优先级）；忌神：X
- 起名方向：优先用 X 行字，避开 X 行字

没有排盘依据时，不写“你八字如何”，只写“按你提供的信息判断”。
