# 音形义与命名规则

## 一、音

- 三字名（姓 + 双字）至少要有两种声调，最好一平一仄，读起来有起伏。
- 避免三字同声母、同韵母；姓与名首字同音时要换。
- 全名连读检查方言：西北官话注意 z/zh、c/ch、s/sh 不分导致的谐音；南方注意 n/l、f/h 与入声。
- 多音字慎用（行、长、重、乐、朝、都、区、仇、单、解、查、尉），名字被读错的成本很高。
- 叠字名（如“婷婷”）亲切但显幼，成人与职场场景要考虑。

## 二、形

- 双字名笔画合计 16–30 画较均衡，过简显单薄，过繁难书写。
- 三个字结构最好有变化（左右 / 上下 / 独体 / 半包围交替），同结构连排会板。
- 避免三个字都带同一偏旁（如“江海洋”“林松柏”），视觉重复。
- 不使用生僻字、异体字、自造字；姓名用字须在通用规范汉字表内，否则学籍、证件、购票、开户都可能出问题。

## 三、义

- 用字要有明确、正向、不歧义的本义，不靠网络新义撑场面。
- 两字之间最好有呼应（如“知远”“清和”），而不是两个吉利字硬拼。
- 避免与知名人物、影视角色、负面新闻人物同名同音。
- 避免直白的功利字堆叠（鑫、财、发、旺、富），易显俗。

## 四、字辈与避讳

- 有族谱字辈时，字辈字固定，只补另一字，且另一字不得与字辈字同偏旁、同音。
- 不与三代以内直系长辈同名、同字；同族同辈不重字。
- 部分地区讲究“男不带天、女不带仙”一类俗规，属于地方习惯，用户提及时尊重，不必主动搬出。

## 五、生肖与星座

生肖宜忌属民俗参考，各派说法互相矛盾（如“属虎忌猴字”一说不成立），只能作为用户主动要求时的补充，不能当硬约束，更不能因此否掉读音寓意都好的名字。

## 六、五格三才的口径

五格（天格、人格、地格、外格、总格）与三才配置必须用**康熙笔画**（含偏旁按原字计，如“氵”按“水”4 画），与简体笔画不同。本技能字库只存简体笔画，因此：

- 默认不做五格吉凶判定，只用简体笔画检查字形均衡。
- 用户明确要五格时，先说明口径，再逐字核康熙笔画；无法确认的字标注“待核”，不硬填数字。
- 五格本身是近代日本传入的姓名学体系，流派评分表不一致，结论只作参考。

## 七、店铺名、品牌名、公司名

与起人名不同，重点依次是：可注册（工商核名、商标近似查询）、易记易传播、行业联想、无歧义谐音、域名/账号可占用。

- 两个字最好，三字次之；避免生僻字与纯拼音缩写。
- 先查重名：企业名称在同一行政区同行业不能重名，商标要查 35 类及主营类别。
- 品牌名不做五行评分，`name_tool.py` 的五行分项对店铺名不适用，只用音形义部分。

## 八、班级、团队、活动命名

要求短、响亮、可喊、无歧义，字数 2–4 字，避免谐音梗和被起外号的空子；队名还要考虑口号押韵。
