# 居家风水 · 应用型百问百答

> 以《八宅明镜》《阳宅三要》《阳宅十书》为骨架，面向"用户传户型图/描述即出布局建议"的应用场景。
> 风水讲"藏风聚气、以人为本"，所有建议为环境与心理舒适度参考，不替代建筑安全与专业设计。

## 一、总纲
**Q1：什么是八宅风水？**
把住宅按坐向分为八种（乾坎艮震巽离坤兑），再依宅命配合分东四宅、西四宅；人亦分东四命、西四命，同宅命相配为吉。

**Q2：什么叫坐向？**
坐为住宅背面所靠之方，向为正面所朝之方（以大门或最大采光面论）。如"坐北朝南"即坎宅。

**Q3：东四宅、西四宅怎么分？**
东四宅：坎、震、巽、离；西四宅：乾、坤、艮、兑。东四命人宜居东四宅，西四命人宜居西四宅，气场相合。

**Q4：命卦怎么算？**
男：(100-出生年尾两位数)÷9 取余数对应卦；女：(出生年尾两位数-4)÷9 取余。余数 1坎、2坤、3震、4巽、5(男坤女艮)、6乾、7兑、8艮、9离。本 Skill 用 scripts 或查表速得。

**Q5：四吉星、四凶星是什么？**
八宅以生气、天医、延年、伏位为四吉；五鬼、六煞、祸害、绝命为四凶。依宅卦起伏位顺布八方。

## 二、门主灶三要
**Q6：为什么"门主灶"最重要？**
《阳宅三要》以大门、主卧、厨房为宅之三宝，三者方位生克决定宅气旺衰，是居家风水第一步。

**Q7：大门有何讲究？**
宜开阔明亮、不直冲电梯/楼梯/长走廊；门前整洁、不堆杂物；与宅命吉方呼应更佳。

**Q8：主卧放哪里好？**
主卧宜居宅之吉方（如延年、天医位），安静、方正、不压梁、不邻厨卫。

**Q9：厨房（灶）有何忌？**
灶忌正对大门、忌与卫生间相邻、忌横梁压顶；水火（水槽与灶）不宜紧贴直线对冲。

**Q10：厕所（卫生间）怎么看？**
宜在凶方（以污秽压凶），保持干燥通风；忌居中宫、忌正对大门与卧室门。

## 三、布局实务
**Q11：户型不方正怎么办？**
缺角以"补角"思路：在缺角处设灯、绿植或对应五行物；更根本是保持该区整洁明亮，不堆杂物。

**Q12：横梁压顶怎么化？**
床、沙发、书桌上方有梁，宜吊顶包平、移开家具或用布艺弱化视觉压感。

**Q13：穿堂煞（一通到底）怎么看？**
大门直对阳台窗形成气流直穿，传统谓"气不聚"；可用屏风、玄关、绿植缓冲。

**Q14：尖角冲射怎么处理？**
窗外有他建筑尖角正对，宜用厚帘、磨砂、植物或凸面镜柔化（镜勿正对邻户，免生纠纷）。

**Q15：镜子能随便挂吗？**
镜不宜正对床、正对大门、正对炉灶；卧室镜宜藏或侧墙，避免夜半惊神、气散。

**Q16：植物怎么选？**
客厅宜阔叶绿植（如琴叶榕、龟背竹）聚气；带刺植物（仙人掌）宜放外阳台挡煞，不宜入卧室。

**Q17：财位在哪、怎么布置？**
每宅有明财位（入门对角线）与宅命财位；宜整洁、有靠、放阔叶或聚宝盆类，忌空、忌压、忌水淹。

**Q18：书房（文昌）怎么布？**
书桌宜靠实墙、面向开阔，光线足；文昌位可放书桌或四支笔，重在心静。

**Q19：儿童房注意什么？**
宜采光好、色调柔和、床不靠窗下、不梁压；少用尖角家具，重安全与安稳感。

**Q20：老人房注意什么？**
宜近卫、地防滑、夜灯足、气流通；床位避梁、避镜对，求安稳。

## 四、形煞与气场
**Q21：什么是"煞"？**
煞指不利的环境形态或气流（路冲、天斩、反弓、孤峰等），现代理解多为噪音、视线、风压等不适来源。

**Q22：路冲是什么？**
住宅正对直路、直河、直巷，气流（车流）直冲，传统谓不聚气；可用绿化、矮墙、玄关缓冲。

**Q23：天斩煞是什么？**
两高楼间窄缝正对住宅，如被劈开；宜拉帘、设屏、移常用房间避正对。

**Q24：反弓煞是什么？**
道路或河流呈反弓形背向住宅，弯弓外缘受冲；宜在受冲面做绿化或遮挡。

**Q25：孤峰煞是什么？**
住宅独高四周低，风大无靠；宜加围合绿化、内层做屏障感。

**Q26：声光煞怎么处理？**
临街、霓虹、工地属声光煞；用隔音窗、厚帘、遮光，重睡眠安宁。

**Q27：电磁与管道怎么看？**
变电厂、高压线、下水主管邻近，传统归入形煞；现代以安全距离与屏蔽为先，咨询专业。

**Q28：何谓"藏风聚气"？**
背有靠、前有照、左右环抱，气流缓入缓出，人居安定；现代即"避强风、得柔光、有私密"。

**Q29：采光与通风为何是核心？**
无论何派，明亮通风、干燥洁净是一切"好风水"的底；阴暗潮湿先治本，再谈方位。

**Q30：户型图和照片看风水，Skill 第一步？**
先定坐向（门/主采光面）→ 判东四/西四宅 → 排四吉四凶方位 → 核对门主灶 → 给布局与化煞建议。

## 五、边界与误区
**Q31：风水能改运发财吗？**
不能。风水改善的是居住舒适度与心理安定，间接助状态；发财靠能力与机遇，勿迷信。

**Q32：能用风水骗人改运收费吗？**
不能。借风水恐吓、卖"法器"敛财属欺诈，本 Skill 明令禁止。

**Q33：租房也能看风水吗？**
能，且更重"可改动项"：整洁、灯光、床位、绿植、遮挡，比动结构实在。

**Q34：不同流派结论冲突听谁的？**
以"安全、采光、通风、整洁、舒适"为最大公约数；方位流派差异作参考，不绝对。

**Q35：楼房怎么定坐向？**
以整栋坐向为基，再结合自户大门与最大采光面；高层常以前后阳台定向，灵活处理。

**Q36：镜子、罗盘必须买吗？**
不必。基础布局靠常识与整洁即可；罗盘为精确测量工具，普通用户不必备。

**Q37：可否用风水选房？**
可作辅助：优先方正、采光好、无路冲反弓、邻里安净；但更取决预算、通勤、学区等现实。

**Q38：化煞物品必须开光吗？**
不必。绿植、帘、屏、灯皆实用；"开光"多为心理安慰，理性看待。

**Q39：风水与八字冲突？**
二者体系不同，风水管环境、八字管时空禀赋；居家布置可独立于命理操作。

**Q40：给用户建议的底线？**
只给可落地、不伤财、不恐吓的建议；涉及结构安全、电路、燃气须转专业；始终强调"舒适和睦为本"。
