# 户型判读与布局实操指南

> 供 Skill 分析用户上传户型图/照片或文字描述时使用。

## 一、信息收集清单（向用户提问）
1. 房屋坐向：大楼入户门朝哪？或您家户门朝哪？（以实际纳气大门为准）
2. 出生年：您和常住家人出生年（农历），算命卦匹配。
3. 户型：有无户型图/照片？各房间（门、主卧、厨房、卫生间、客厅、书房）在哪个方位？
4. 最关心：财运、健康、学业、夫妻/家庭和睦，还是整体？

## 二、从图/描述定位八方
以入户门或大楼坐向定"坐—向"，画九宫格（上南下北左东右西依实际朝向旋转）：
- 用指南针/手机指南针确定正南正北，标出东、东南、南、西南、西、西北、北、东北、中宫。
- 把门、主卧、厨房、卫生间落入对应宫位。

## 三、套八宅三步
1. 定宅卦（按坐向表中的八宅之一）。
2. 查该宅四吉四凶方位表（见 fengshui-classics.md 第二节）。
3. 看门/主/灶落在吉还是凶，门主灶五行生克。

## 四、典型问题速判
| 现象 | 八宅视角 | 建议 |
|---|---|---|
| 大门正对阳台/窗（穿堂） | 不聚气、气直出 | 加玄关/屏风/柜隔断 |
| 主卧在绝命/五鬼方 | 休息受凶星扰 | 移至延年/天医；不行则床位调吉位 |
| 厨房在五鬼方、灶压凶 | 火气助凶 | 灶移位向吉；加强通风洁净 |
| 卫生间居中宫 | 污压心 | 保持干燥通风、常关盖、放绿植净化 |
| 横梁压床/沙发 | 形煞主压抑 | 吊顶包梁或移家具 |
| 厕对门 | 污口对纳气 | 常关厕门、门挂帘 |

## 五、命卦与宅卦匹配
- 东四命住东四宅最佳；西四命住西四宅最佳。
- 若人宅不对（如西四命住东四宅）：优先让命主睡在本人命卦吉位（伏位/延年），用"人盘"补救，不强求换房。
- 多人同住冲突时，以户主（或最常在家者）命卦为主，兼顾老人健康（天医）、夫妻（延年）。

## 六、输出案例（虚构）
用户：户门朝南（离宅，东四），男主1985年（85→100-85=15÷9余6→乾，西四命，但实际2000前公式：100-85=15余6乾西四），女主1988年（88-4=84÷9余3震东四）。最关心财与健康。
分析：离宅四吉在震（生气）、巽（延年）、坎（天医）、离（伏位）。男主西四命、女主东四命，人宅略错配；建议主卧放坎（天医，利健康且女主东四合），书房/财位用震（生气），厨房避五鬼（乾方）放天医或延年；入户若有穿堂加玄关。
说明：传统参考，实用与安全优先。

## 七、话术
- 开场："我按八宅法给你盘一下，先把朝向和生年告诉我，纯属老传统参考哈。"
- 收尾："风水说到底是让人住得顺、心安。改动以实用安全为准，别为了'旺'硬改承重墙。"
