# 物料清单口径（v4.0）

> **用途**：交付时按房间输出物料清单，**只写材质、用量口径与损耗系数，不写单价与总价**。
> **红线**：本技能不做装修报价。清单中的价格一律留空，由业主自行询价。
> **配套**：`pitfall_guard.md`（选型避坑）、`templates/space_proposal.md`（一页纸提案摘要）

---

## 一、五大类口径

| 类别 | 用量口径 | 损耗系数 |
|---|---|---|
| **地面**（地砖/地板） | 房间净面积（门洞展开按当地口径） | 地砖 5–8% |
| **墙面**（涂料/壁纸） | 墙面展开面积（扣除门窗洞口） | 涂料 10%（两遍涂刷）/ 壁纸 15% |
| **天花** | 吊顶展开面积或投影面积（按方案） | 按造型复杂度 |
| **固定家具**（定制柜） | 投影面积 | 按展开系数 |
| **软装**（家具/灯具/布艺） | 按件计列 | — |

---

## 二、逐房间输出格式

```
## {房间名} 物料清单

| 类别 | 材质 | 用量口径 | 损耗 | 备注 |
|---|---|---|---|---|
| 地面 | 800×800 浅色亮光砖 | 约 {X} ㎡ | 8% | 同色美缝留 2mm |
| 墙面 | 浅色乳胶漆 | 约 {Y} ㎡ | 10%（两遍） | — |
| 天花 | — | 不做吊顶 | — | 双眼皮吊顶时另计 |
| 固定家具 | 电视柜 + 边柜 | 投影约 {Z} ㎡ | — | 落地式，非悬空 |
| 软装 | 直排沙发 + 单人椅 + 轻便茶几 | 按件 | — | 不做 L 型沙发 |
```

---

## 三、⚠️ 固定结尾（必须逐字包含，不得删改）

```
以上用量为效果图示意口径，非实测工程量。实际用量以现场实测、商家量房与正式报价为准。
```

## 四、与选型避坑的衔接

清单的材质一栏**必须与 `pitfall_guard.md` 的取值判定表一致**，不得出现已判定为避坑的选型：

| 空间 | 清单中不得出现 | 应写为 |
|---|---|---|
| 厨房台面 | 岩板、人造石、人造大理石 | 1.5cm 厚石英石 |
| 厨房柜门 | 肤感门板、PET 高光板 | 双饰面哑光板 + PUR 封边 |
| 厨房柜体 | 颗粒板、密度板 | 多层实木板 / 欧松板（ENF 级） |
| 厨房推拉门 | 吊轨 | 隐藏式 / 超薄极简地轨 |
| 卫生间门 | 木门 | 钛镁铝合金门 + 灰油砂玻璃 |
| 卫生间吊顶 | 石膏板、防水石膏板、蜂窝大板 | 300×600 铝扣板 |
| 卫生间地面 | 亮光砖、岩板、大理石 | 柔光防滑砖 |
| 客厅地面 | 柔光砖 | 800×800 浅色亮光砖 |
| 客厅背景墙 | 岩板、格栅、大理石 | 大白墙 / 浅色乳胶漆 |
| 卧室 | 榻榻米、碳晶门、生态门 | 成品排骨架床、实木复合烤漆门 |

## 五、损耗系数说明（写给业主看的一句话）

```
损耗是建材行业的通行做法：地砖要裁切、涂料要两遍、壁纸要接缝，
不预留损耗会出现"料不够"或"剩下太多"。具体系数随现场尺寸与铺贴方式浮动。
```

> ⚠️ 系数为行业常见区间。若庄主要按广联达或深圳地方口径取值，可在 `material_list.md` 内替换为项目自定值 —— **默认值不代表唯一正确答案**。
