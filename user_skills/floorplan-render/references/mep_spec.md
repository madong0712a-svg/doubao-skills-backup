# 水电施工图模块规范（mep_spec）

> **定位**：v4.7.0 新增（P1-2）。本技能从「效果图示意」升级为「可付费设计服务」的关键模块：
> 从**平面图 JSON 驱动**生成水电点位、工程量与施工说明，**不靠硬编码、不靠视觉估算**。
>
> **边界（写进每份交付）**：
> 本模块产出为**设计参考口径**，用于前期方案沟通、预算估算与施工交底辅助；
> 正式施工图须由持证设计单位出图，现场以实测与物业核定为准。
> 电表容量、入户主线规格以电业局核定为准；给水主管径以市政接入为准。

## 一、对齐的规范体系

| 领域 | 规范 | 用途 |
|---|---|---|
| 电气 | GB 50303《建筑电气工程施工质量验收规范》 | 布线、接线、验收口径 |
| 电气 | GB 50054《低压配电设计规范》 | 回路划分、保护整定 |
| 住宅电气 | JGJ 242《住宅建筑电气设计规范》 | 插座/开关数量与布置下限 |
| 给排水 | GB 50015《建筑给水排水设计标准》 | 管径、坡度、用水点 |
| 防水 | GB 55030《建筑与市政工程防水通用规范》 | 防水设防高度（强制性） |
| 施工 | GB 50327《住宅装饰装修工程施工规范》 | 水电施工工序与验收 |

> **地方细则优先**：深圳/广东地区另受地方规定与物业约束（如卫生间防水高度、洗衣机地漏），
> 本模块默认取**规范下限 + 常规做法**，遇地方更严要求按地方执行（核心原则 16：规范优先于经验）。

## 二、电路规则（mep_calc.py 的实现口径）

### 2.1 回路划分

| 回路 | 划分口径 | 线径（BV 铜芯） |
|---|---|---|
| 照明 | 全屋 1–2 路（>90㎡ 或房间 >6 间取 2 路） | 1.5 mm² |
| 普通插座 | 每回路 ≤ 10 个插座且 ≤ 3 个房间，按房间就近组团 | 2.5 mm² |
| 空调 | 每台 ≥1.5P 独立回路；同区域小功率可 2 台共用（不推荐） | 4 mm² |
| 厨房 | 独立回路（含台面插座 + 冰箱 + 油烟机） | 4 mm² |
| 卫生间 | 独立回路（含洗手台插座；有电热水器时同回路） | 4 mm² |
| 洗衣机/烘干机 | 独立回路（与厨房同墙时可并入厨房回路） | 2.5 mm² |
| 入户主线 | 按户载容量，本模块按 6–10 mm² 预留提示 | 6–10 mm² |

> 卫生间独立回路**无条件成立**：平面图未标电热水器时，本回路仍独立（仅供插座），
> 并在「待确认事项」提示业主确认热水器形式（电/燃气）——燃气改管由燃气公司实施。
> 断路器整定：照明 1P C16；普通插座 1P C20 + RCD 30mA；厨房/卫生间/空调 2P C25 + RCBO 30mA。

### 2.2 插座数量下限（JGJ 242 口径，本模块取值）

| 房型 | 插座数 | 位置 |
|---|---|---|
| 主卧/次卧 | ≥3 | 床头两侧各 1（其中 1 个带 USB）+ 书桌/梳妆区 1 |
| 客厅 | ≥5 | 电视墙 2（电视/机顶盒）+ 沙发两侧各 1 + 角落 1 + 备用 1 |
| 餐厅 | ≥2 | 餐桌旁 1（火锅/小家电）+ 餐边柜 1 |
| 厨房 | ≥4 | 台面 2 + 冰箱 1 + 油烟机 1（16A，距台面 1.8m） |
| 卫生间 | ≥1 | 洗手台侧防溅插座；电热水器回路另计 |
| 书房 | ≥3 | 书桌 2（台灯/电脑）+ 角落 1 |
| 阳台 | ≥1 | 防溅插座（洗衣机/吸尘器/晾衣机） |
| 玄关 | ≥1 | 鞋柜区（烘鞋/充电） |

**开关**：每间房入口 1 位；卧室与客厅走双控（入口 + 床头/沙发侧各 1 位）。
**安装高度**：开关 1300–1400mm；低位插座 300mm；床头/书桌高位 700–1000mm；
厨房台面 1100–1200mm；冰箱 500mm；洗衣机 1200mm；卫生间 1500mm（防溅）；
油烟机 2200mm；空调 1800–2200mm。

### 2.3 点位明细与家具触发增量（v4.7.0 明确）

各房型的**逐点位清单**（位置/个数/高度/用途）以 `scripts/mep_calc.py` 的
`SOCKET_POINTS` 常量为准（卧室 3 / 客厅 5 / 餐厅 2 / 厨房 4 / 卫生间 1 / 阳台 1 /
玄关 1 / 书房 3），本节不再重复列数，杜绝两处数字漂移。

**家具触发增量**（`EXTRA_SOCKET_TYPES`）：平面图里有该家具 → 房间按下表追加插座，
不依赖房型名——这是「从平面 JSON 驱动」与硬编码模板的本质区别：

| 家具 type | 增量 | 位置/高度 |
|---|---|---|
| desk / dressing_table | +1 | 1000–1100mm |
| treadmill / piano / aquarium / massage_chair | +1 | 300mm |
| dishwasher / dryer | +1 | 300 / 1200mm |

空调按家具 `type ∈ {air_conditioner, ac, split_ac, ac_indoor}` 识别，
每台独立回路；**清单里没有空调时必须报 ⚠️**，不得静默按 0 回路交付。

### 2.4 电线与线管工程量（估算口径）

- 每回路长度 `L = 1.4 × (配电箱→房间最远用电点距离 + 房间对角线 ÷ 2) + 50 mm 箱内余量`
- 「最远用电点」取成员房间净边界四角中离配电箱最远的角（保守口径）
- 线管（SC20/JDG20）米数 ≈ 同回路电线米数（同管穿设）
- **本口径为估算**，未含底盒预留（每盒约 100–150mm）与绕梁增量；
  正式算量按现场走线，差异在 ±20% 内属正常
- 配电箱/水表/排水立管房间缺省推定顺序：配电箱 玄关→入户→走廊→过道→最小房间；
  水表 厨房→餐厅→卫生间；立管 卫生间→厨房。推定值必须在「待确认事项」声明

## 三、水路规则

### 3.1 给排水点（由家具类型自动识别）

| 家具/设施 | 给水点 | 排水点 | 管径 |
|---|---|---|---|
| 厨房水槽/橱柜 | 冷 + 热 | 1 | 给水 De20，排水 De50 |
| 洗手台 | 冷 + 热 | 1 | 给水 De20，排水 De50 |
| 马桶 | 单冷 | 1 | 给水 De20，排水 De110 |
| 淋浴 | 冷 + 热 | 1（地漏） | 给水 De20，排水 De50 |
| 洗衣机 | 单冷（+热可选） | 1（专用地漏） | 给水 De20，排水 De50 |
| 阳台水龙头 | 单冷 | — | 给水 De20 |

入户给水主管 De25；热水器出水按设备规格（通常 De20）。
排水坡度：De50 ≥ 2.5%，De110 ≥ 1.2%（GB 50015 口径，管径越大坡度越小）。

### 3.2 防水面积（GB 55030 口径）

| 区域 | 墙面 | 地面 |
|---|---|---|
| 卫生间 | 墙面全高至 1.8m；**淋浴区至 2.0m 或到顶** | 全做，门口外延 300mm |
| 厨房 | 台面上返 300mm | 全做（有地漏时） |
| 阳台 | 300mm（有洗衣机/水龙头时） | 全做 |

防水面积 = 墙面（周长 × 高度）+ 地面面积；涂料按 2 遍（一底一面）计。

### 3.3 管长与用量估算（v4.7.0 明确）

- 给水支管 = 用水点→水表距离 × 1.2（绕行系数）；冷热点按 **2 根**计
- 入户给水主管 De25 = 水表→最远用水点 × 1.2
- 排水横管 = 排水点→立管距离 × 1.2；排水立管 1 根按**层高**计（默认 2.8m，
  `--floor-height` 可覆盖；原图未标层高时按默认并在待确认事项声明）
- 防水涂料 = 防水面积 × 2.2 kg/㎡（两遍），按 5kg/桶向上取整
- 周长按**墙中线**未扣洞口（估算偏安全）；卫生间墙面按淋浴间贴墙段 2.0m、
  其余 1.8m 分段计（非矩形房间按周长统一估算并注明）
- 厨房防水仅计**橱柜贴墙面**上返 0.3m；无橱柜数据时按全周长 × 0.3m 保守估算

## 四、交付物（mep_calc.py 输出）

1. **总览**：回路/插座/开关/给排水点/防水面积/电线合计
2. **回路划分表**：回路名 / 供电范围 / 线径 / 断路器 / 估算长度
3. **插座点位表**：房间 / 位置 / 数量 / 高度 / 用途
4. **开关点位表**：房间 / 开关位 / 双控关系 / 入口方位
5. **给排水点表**：房间 / 点位 / 冷热 / 管径 / 排水点径 / 支管估长
6. **防水面积表**：区域 / 墙面口径 / 墙面 / 地面 / 外延 / 合计 / 涂料
7. **材料清单**：电线（按回路）、线管、底盒、面板、断路器、给水管、排水管、
   防水涂料、角阀软管、地漏（不含价格）
8. **施工说明**：14 条标准条款（GB 50303/50054/50015/55030/50327 口径）
9. **待确认事项**：脚本生成的口径推定声明 + 家具缺失 ⚠️（空调/电热水器）+
   自动捞取 plan `meta.pending_confirm` 中与水电影相关的条目——**不静默跳过**

## 五、维护约定

- 规则变动只改本文件 + `scripts/mep_calc.py` 的常量区，两处必须同步
- 新家具类型进 `ABSENCE`/给排水识别时，先确认 schema 的 `type` 词表
- 工程量与**造价口径**（人工/主材价）不属本模块；要报价转造价流程
