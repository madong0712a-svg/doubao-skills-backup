# 居住画像（v4.0）

> **用途**：出图前收集居住人群信息，转为该房间的出图硬约束，写入提示词第 [3] 段。
> **核心认知**：装修不是装好看，是装人的生活习惯。效果图不考虑谁住，就是营销假象。
> **配套**：`buildability.md`（尺寸约束）、`SKILL.md` 第八节（调用位置）

---

## 一、《居住画像卡》

用户主动提供时按卡收集；**未提供时按"通用家庭，无特殊约束"处理并在交付时标注，不追问、不猜测。**


## 二、画像 → 出图硬约束映射表

**画像只改家具与软装，不改户型结构。** 不得以画像为由增删房间、移动墙体门窗。

| 画像信号 | 出图硬约束（写入提示词 [3] 段或房间约束列） |
|---|---|
| 有小孩（0–6 岁） | 儿童房家具圆角化、避免尖锐边角柜、地面材质偏软、不做通顶玻璃柜 |
| 老人同住 | 主通道 ≥900mm、卫生间画防滑地面 + 扶手位、不做地面高差、不做低照度角落 |
| 爱做饭 | 厨房按三角动线布柜（冰箱→水槽→灶台）；双排需净宽 ≥2400，否则改单排 |
| 爱收纳 | 柜体按藏八露二配置，提高柜体占比；禁止画无柜体样板间 |
| 常在家办公 | 书房/次卧画工作位（桌+椅+照明），加隔音提示 |
| 频繁待客 | 客厅保证会客区完整；餐厅餐桌按待客人数取保守大尺寸 |
| 独居 / 两口 | 可减少次卧的"使用感"，但**不得删除户型图中存在的房间** |

## 三、收纳配置（同源，并入每房间）

**原则：收纳优先于摆拍。** 业主收房后第一件事就是打柜子，画成"没有柜体的样板间"是误导。

| 原则 | 落地口径 |
|---|---|
| **藏八露二** | 柜体封闭占比约 80%，开放格/玻璃门约 20% |
| **就近收纳** | 物品就近其使用位置（清洁用品近洗衣区、餐具近餐厅） |
| **按频率分区** | 高频物品置于顺手高度，低频置于高处/深处 |
| **动线最短** | 柜体不得侵占主通道，开门幅度需留足 |

每个房间在《房间识别清单》的"收纳配置"列写出口径（如"玄关：鞋柜+挂衣区；客厅：电视柜+边柜；厨房：按动线布柜"）。

**紧凑空间（可施工性判定 ⚠️/❌）优先保证收纳完整，再谈风格表现。**

---

## 四、房间识别清单的画像列

在 `templates/room_inventory.md` 中，每房间除优先级与可施工性判定外，增加两列：

| 列 | 内容 |
|---|---|
| 居住画像约束 | 该房间因画像产生的硬约束（如"儿童房家具圆角化"） |
| 收纳配置 | 该房间柜体配置口径（如"藏八露二，玄关柜+餐边柜"） |

---

## 五、质检对应项

画像不满足时判定为**底层逻辑层**不通过（居住适配），处理方式：重新生成，插入画像硬约束。
