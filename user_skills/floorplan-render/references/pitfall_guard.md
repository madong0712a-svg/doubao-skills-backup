# 避坑知识模块 · 生图硬约束（v4.1）

> **用途**：出图时按当前房间取出对应排除项，与提示词第 [8] 段合并，**强制规避已知装修坑点**。
> **来源**：行业常见踩坑经验汇总，共 111 条要点。**已做去标识处理 —— 不含任何第三方创作者名称、账号或平台引用**，可直接用于对外发布。
> **取值规则**：现行国家规范 > 行业通行做法 > 通行经验判断。**规范优先于经验** —— 经验可以加严规范，不得低于规范。
> **配套**：`templates/pitfall_reminder.md`（交付时给用户的避坑提醒）、`buildability.md`（尺寸类约束）。

## 一、取值判定表（出图前先过这 4 条）

以下 4 项在行业内存在不同做法，本模块**已按规范与通行做法定稿**，不随输入变化：

| # | 争议项 | **本模块定稿取值** | 定稿依据 |
|---|---|---|---|
| 1 | 卫生间地砖 亮光 / 柔光 | **柔光防滑砖，禁止亮光砖** | 防滑优先，行业通行做法 |
| 2 | 厨房地面是否做防水 | **必须做。**四周墙面防水层高度 ≥0.3m，施工后闭水试验，完成后做保护层 | **现行规范要求（GB 50327），不得省略** |
| 3 | 厨房推拉门 吊轨 / 地轨 | **地轨，禁止吊轨**（隐藏式或超薄极简地轨） | 承重稳定，行业通行做法 |
| 4 | 厨房水槽 台中盆 / 台下盆 | **禁止台上盆。**台下盆（底部 ≥10 个卡扣）或台中盆 | 便于清洁，行业通行做法 |

### ⚠️ 关于"厨房防水"的取值说明

网上流传的"厨房防水是智商税、做了也白做"属于**低于现行规范要求**的说法，本模块**不予采纳**。

GB 50327《住宅装饰装修工程施工规范》对厨房地面防水施工有明确要求：厨房地面必须做防水层，四周墙面防水层高度 ≥0.3m，施工后做闭水试验，防水层完成后做水泥砂浆或细石混凝土保护层。

> ⚠️ 引用规范时的边界：本模块只写要求要点，**不写条款号**。GB 50327 的现行有效版本、具体条款与地方标准差异，须以标准原文及当地主管部门要求为准。

**生图处理**：防水层属隐蔽工程，在完成面效果图中不可见，因此**不设生图排除项**（避免无效文本占用模型注意力），改由 `templates/pitfall_reminder.md` 在交付时以施工提醒形式输出。

### ⚠️ 常驻易错规则：亮光 / 柔光按空间分

- **卫生间 → 柔光**防滑砖（防滑优先）
- **客厅 / 厨房 / 阳台 → 亮光**砖（800×800，易打理）

**不得全屋统一写一种。** 这是最容易画错的一处。

## 三、按房间追加排除项（出对应空间时必挂）

### 卫生间

```
禁止：悬空马桶（改落地式，含水箱、盖板、底座完整落地）——
禁止：台上盆与岩板一体盆（改陶瓷一体盆，四面挡水沿，盆深≥14-15cm，洞口比盆宽2cm）——
禁止：石膏板/蜂窝大板/防水石膏板吊顶（改300×600素色哑光铝扣板，可见拼缝网格）——
禁止：长条地漏（改10×10cm方形地漏+回字形倒角）——
禁止：灯暖浴霸（改风暖浴霸，陶瓷发热片，薄型≤13cm，出风口造型）——
禁止：木门（改钛镁铝合金门+灰油砂单层8mm钢化玻璃，透光不透人）——
禁止：长虹玻璃（改灰油砂磨砂玻璃，磨砂颗粒质感）——
禁止：黑色花洒/黑色边框（改枪灰或暖白色）——
禁止：百叶窗（改普通平窗+玻璃贴膜）——
禁止：浴缸（改淋浴花洒，含花洒座与手持）——
禁止：智能裸镜与墙面开放格置物（改智能镜柜，柜门闭合）——
禁止：半墙网红壁龛（壁龛移至马桶里侧，或不做）——
禁止：亮光地砖与岩板大理石地面（改柔光防滑砖+同色美缝）——
禁止：地漏装在非最低处（地漏须为全卫最低点，周边做回字形倒角找坡）
```

**约束等级**：强制

### 厨房

```
禁止：岩板台面与人造石台面（改1.5cm厚石英石台面，可见底部衬板）——
禁止：台上盆（改台下盆并见底部≥10个卡扣加固，或台中盆）——
禁止：吊轨推拉门（改隐藏式或超薄极简地轨，地轨延伸压住垭口套）——
禁止：集成灶（改分体灶，顶吸或侧吸）——
禁止：蜂窝大板与防水石膏板吊顶（改300×600素色哑光铝扣板）——
禁止：肤感门板与PET高光柜门（改双饰面哑光柜门+PUR封边，无油污手印反光）——
禁止：颗粒板与密度板柜体（改多层实木板或欧松板，ENF级）——
禁止：外凸金属拉手（改免拉手，吊柜门板下挂，地柜U型槽或45度斜切）——
禁止：塑料踢脚板（改瓷砖踢脚板）——
禁止：小规格仿古砖（改800×800亮光砖，墙砖也用800规格，三块到顶）——
禁止：台面前做挡水条（改墙砖贴规方，台面前怼打细防霉玻璃胶，内侧弧形一体挡水沿）——
禁止：内开厨房窗（改外悬或外倒窗，配上下抽拉纱窗）——
禁止：直角开孔灶具孔（改四角圆角，开孔前宽后窄）——
禁止：橱柜多隔板少抽屉（改少隔板多抽屉，见碗拉篮与调味拉篮）——
禁止：吊柜深度做成35cm（改40cm深，侧吸烟机嵌入齐平）——
禁止：全屋统一80cm台面（改高低台：炒菜区78-80cm，洗切区88-90cm）
```

**约束等级**：强制

> **厨房防水**：按现行规范执行，必须施工（要求见第一节）。隐蔽工程完成面不可见，**不写入生图排除项**，改由交付提醒输出。

### 客厅

```
禁止：岩板格栅大理石电视背景墙（改大白墙或浅色乳胶漆）——
禁止：投影幕布（改大屏显示电视）——
禁止：悬空电视柜（改落地电视柜，稳重不坠落）——
禁止：无主灯整层吊顶（层高≤2.9m；改双眼皮吊顶，深度30cm，错层4cm，无中央空调做26/22cm高）——
禁止：柔光砖（改800×800浅色亮光砖，纹路细、颜色浅暖，同色美缝留2mm，一砖通铺客餐厅阳台）——
禁止：L型与肥大型沙发（改直排沙发+单人椅）——
禁止：笨重长方形大茶几（改几何形轻便茶几或去茶几化边几）——
禁止：复杂水晶吊灯（改吸顶灯，不压层高）——
禁止：客厅与南阳台同时装窗帘（改只南阳台装，客厅不留窗帘盒）
```

**约束等级**：强制

### 卧室

```
禁止：榻榻米（改成品排骨架床，通风环保好打理）——
禁止：碳晶木门、碳晶门、生态门、铝木门（改实木复合烤漆门或无漆门）——
禁止：罗马杆窗帘（改窗帘盒，盒宽15cm，双层轨道22cm）——
禁止：飘窗贴瓷砖与飘窗包窗套（改整块大理石台面，不做小耳朵不外凸，不包窗套，用耐水腻子+防霉漆饰面）——
禁止：一门通顶超高门（改门高2.2m、宽88cm、板厚4.5cm）——
禁止：衣柜深度55/58cm（改62cm深）——
禁止：挂衣区上下等分（改上衣区80cm、裤子区≥95cm）——
禁止：叠衣区过多（改多挂衣区、少叠衣区，配分类抽屉）——
禁止：免拉手缝宽不当（改留2.5cm宽，宽了显大窄了夹手）——
禁止：儿童房柜体空格无背板（改空格背板必做）
```

**约束等级**：强制

### 玄关

```
禁止：鞋柜深度33-34cm（改35-40cm深，下方留18cm放当天穿的鞋，中间留40cm洞口随手放包）——
禁止：无感应灯电源（改预留电源装感应灯带，夜间自动亮）
```

**约束等级**：建议

### 阳台

```
禁止：笨重推拉门（改包垭口套+地暖通铺到阳台，敞亮通透）——
禁止：阳台吊顶藏梁藏晾衣架（改不做吊顶，梁与晾衣架外露）——
禁止：垭口刷乳胶漆或包木质套（改钛镁合金垭口，防水耐潮）——
禁止：洗衣机电源位置不当（改电源留在洗手盆正下方）
```

**约束等级**：建议

### 全屋定制与柜体（所有含柜子的房间必挂）

```
禁止：3/5mm薄背板（改靠墙背板≥9mm，背板后悬空处用18mm）——
禁止：只看柜门封边（改柜体柜门均用PUR或EVA封边，尤其踢脚板位）——
禁止：满玻璃门餐边柜与酒柜（改点缀一扇或不做，省下的钱多做抽屉）——
禁止：迷信大品牌定制（改本地工厂+ENF级多层实木板+指定好五金）——
禁止：塑料踢脚板（改瓷砖踢脚板或红砖地台外贴瓷砖）
```

**约束等级**：强制

## 四、正向强化词（与排除项配套，提高命中）

**排除项只写"不要"压不住** —— 模型对"看起来高级"的错配置有强惯性。**必须同时给正向描述。**

| 空间 | 正向描述 |
|---|---|
| 卫生间 | `落地式马桶完整呈现水箱、盖板与底座` / `陶瓷一体盆带四面挡水沿，盆深≥15cm` / `300×600哑光铝扣板吊顶可见均匀拼缝网格` / `10×10方形地漏配回字形倒角，地漏为地面最低点` / `风暖浴霸薄型出风口造型，非灯泡发光` / `钛镁合金门配灰油砂磨砂玻璃，透光不透人` / `柔光防滑地砖配同色美缝` / `枪灰色恒温花洒` / `智能镜柜柜门闭合` |
| 厨房 | `1.5cm厚石英石台面，底部可见衬板` / `台下盆并见底部多个不锈钢卡扣加固` / `隐藏式极简地轨，无凸出明轨` / `分体侧吸灶具` / `300×600素色哑光铝扣板吊顶` / `双饰面哑光柜门无反光` / `多层实木柜体暖木纹哑光质感` / `免拉手无外凸金属件` / `高低台面：洗切区较高、炒菜区较低` / `少隔板多抽屉，抽屉带碗拉篮与调味拉篮` |
| 客厅 | `浅色乳胶漆平整电视墙，无岩板无格栅无大理石` / `大尺寸液晶电视悬于墙面` / `落地式电视柜接地无悬空` / `双眼皮跌级吊顶，层次分明` / `800×800浅色亮光地砖通铺，砖面有反光，同色2mm美缝` / `直排沙发配单人椅` / `几何形轻便茶几` / `简约吸顶灯` |

| 阳台 | `垭口套包边，阳台与客厅一体通铺` / `阳台无吊顶，梁与晾衣架外露` / `钛镁合金垭口套` |

## 六、执行流程（出图时逐条打勾）

```
[-0.5] 避坑约束加载（本模块）
   ├─ 1 过取值判定表（4 条，已定稿不随输入变化）
   ├─ 2 挂常驻排除项（所有房间）
   ├─ 3 按房间挂追加排除项（对应小节）
   ├─ 4 挂正向强化词（对应小节）
   ├─ 5 查可施工性联动表（画得下吗）
   └─ 6 全部合并进提示词第 [9] 段
```

**合规校验新增 4 条**（加入原有 10 条，共 14 条）：

- [ ] 卫生间无壁挂 / 悬空马桶，画的是落地式
- [ ] 无岩板台面、无台上盆
- [ ] 无吊轨推拉门、无集成灶
- [ ] 卫生间为柔光防滑砖，客厅/厨房/阳台为 800×800 亮光砖（不得全屋同一种）
