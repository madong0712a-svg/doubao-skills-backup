# 单图质检清单

> 每张效果图必须逐项检查以下 17 项。任何一项不通过，都必须在质检结果中写明具体问题与建议动作。
> 批量直出模式下的附加规则见文末「批量质检规则」；3.0 新增第 16、17 项（出图后处理 + 可施工性）。
> **处理方法见 `references/postprocess.md`，脚本见 `scripts/postprocess.py`，尺寸判定见 `references/buildability.md`。**

---

## 〇、批量高发错误速查

批量生成全屋时，以下错误出现频率最高，质检时**优先核对**：

| 高发错误 | 典型表现 | 判定 |
|---|---|---|
| 无中生有的窗户 | 居中无外墙房间（餐厅/玄关/卫生间）画面出现大窗 | 门窗一致性不通过 → 重新生成 |
| 平窗变落地窗 | 次卧普通平窗被画成阳台式落地大窗 | 门窗一致性不通过 → 重新生成 |
| 飘窗消失/被拆 | 主卧/书房飘窗台被改造成落地窗或直接消失 | 空间关系不通过 → 重新生成 |
| 跨图风格漂移 | 后生成房间与客厅锚点图材质色温不一致 | 材质/配色一致性不通过 → 局部修改 |
| 房间比例失真 | 紧凑房间被画成大开间 | 空间关系不通过 → 重新生成 |
| **布局不可施工** | 净宽 1.9m 的厨房被画成双排橱柜；净宽 3.0m 卧室画 1.8m 大床 | **可施工性不通过 → 重新生成（按 `buildability.md` 强化约束）** |
| **平台水印未清** | 右下角残留「AI生成 / WORKBUDDY」 | **后处理不通过 → 必须处理后才可交付** |

## 一、17 项检查清单

| # | 检查项 | 判定要点 | 归属维度 |
|---|---|---|---|
| 1 | 墙体一致性 | 墙体位置、走向、数量与解析结果一致，无重叠、无移位 | 空间关系 |
| 2 | 门洞一致性 | 门洞位置、数量一致，无新增、无消失、无错位，未被家具遮挡 | 门窗一致性 |
| 3 | 窗户一致性 | 窗户位置、数量、开向一致 | 门窗一致性 |
| 4 | 阳台一致性 | 阳台/露台位置与边界与户型图一致，未被并入室内或删除 | 空间关系 |
| 5 | 房间功能对应 | 房间数量与功能与户型图对应，未虚构不存在的房间 | 空间关系 |
| 6 | 承重结构 | 未新增或删除承重结构，擅自改造外墙/承重柱 | 空间关系 |
| 7 | 动线合理性 | 主通道畅通（≥900mm），家具未堵塞入户到各空间的动线 | 动线 |
| 8 | 家具稳定性 | 家具无悬浮、无穿模、稳定落地 | 透视 |
| 9 | 透视成立 | 地面、墙面、天花透视合理，垂直线条稳定，无穿模 | 透视 |
| 10 | 天花结构 | 天花有合理支撑，未出现无支撑悬空结构 | 透视 |
| 11 | 材质一致性 | 材质与风格迁移卡一致，跨图统一，无异常反射 | 材质 |
| 12 | 配色一致性 | 配色仍属于目标风格，主辅点缀比例未跑偏 | 配色 |
| 13 | 文字规范 | 画面中无错字、乱码、无法辨认的文字、虚假广告 | 文字 |
| 14 | 隐私安全 | 无房号、姓名、电话、门牌号等个人信息 | 隐私 |
| 15 | 商业可用 | 无虚假房源实拍表述，适合直接展示给客户 | 商业 |
| 16 | **平台水印** | 右下角无「AI生成 / WORKBUDDY」等平台标识；已按底色类型处置，或经检测三件套判定确认不可见 | **后处理** |
| 17 | **可施工性** | 家具布局符合该房间净尺寸的最小可装尺寸（见 `references/buildability.md`）；不可施工的空间已采用保守布局 | **可施工性** |

## 三、维度合并规则

11 个输出维度与 17 项检查的对应关系：

| 输出维度 | 对应检查项 |
|---|---|
| 空间关系 | 1、4、5、6 |
| 门窗一致性 | 2、3 |
| 动线 | 7 |
| 材质 | 11 |
| 配色 | 12 |
| 透视 | 8、9、10 |
| 文字 | 13 |
| 隐私 | 14 |
| 商业 | 15 |
| 后处理 | 16 |
| 可施工性 | 17 |

任一子项不通过 → 该维度判为「不通过」。

## 四、结论判定规则

| 结论 | 判定条件 | 后续动作 |
|---|---|---|
| **直接采用** | 全部 17 项通过 | 进入交付，可作为客户展示素材 |
| **局部修改** | 仅材质(11)/配色(12)/透视(8,9,10)/文字(13)/后处理(16) 类非结构问题不通过 | 针对性处理，**保留底图** |
| **重新生成** | 空间关系类(1,2,3,4,5,6)/可施工性(17) 任一不通过 | **回退稳定底图**，重新生成 |
| **不可用** | 隐私(14) 或 商业(15) 不通过 | 禁止交付，必须重生成 |

> 第 16 项（水印）属于**本地可修**，不需要重生成 —— 走 `scripts/postprocess.py` 处理即可。
> 第 17 项（可施工性）属于**结构类**，必须重生成，不能靠后期修图解决。

## 五、回退触发条件（硬性）

出现以下任一情况，**立即停止叠加修改，回退到上一版确认无误的底图**：

- 墙体重叠或移位
- 门洞错位、新增或消失
- 窗户位置/数量/开向改变
- 房间数量改变或虚构出新房间
- 空间方向改变
- 户型明显跑偏
- 家具布局超出该房间净尺寸的最小可装尺寸（不可施工）
- 连续多次生成后空间结构持续漂移

回退后向用户说明：

```
检测到空间结构错误（{具体问题}），已回退到上一版确认无误的底图。
不在错误结果上继续叠加修改，避免户型漂移。
```

## 六、多图一致性检查（套图额外检查）

当一次交付 2 张及以上效果图时，额外检查：

- [ ] 主色与辅色是否同一套
- [ ] 墙面和地面材质是否同一套
- [ ] 天花处理方式是否一致
- [ ] 家具语言是否统一
- [ ] 软装体系是否统一
- [ ] 主光源色温是否一致（按风格卡的标准色温，不得逐张漂移）
- [ ] 拍摄高度和空间尺度感是否一致
- [ ] **可施工性判定标准是否一致**（同一户型不得对同类房间采用宽严不同的尺度）

不一致时判为「局部修改」，统一风格后重新生成不一致的那几张。

## 七、常见缺陷对照表

| 缺陷 | 表现 | 建议动作 |
|---|---|---|
| 户型跑偏 | 房间关系与户型图不符 | 回退底图，重写户型结构描述 |
| 门窗漂移 | 门/窗位置与解析卡不符 | 回退底图 |
| 家具悬浮 | 家具有阴影但底部不落地 | 局部修改，强化「家具稳定落地」 |
| 透视穿模 | 家具与墙体、地面相交错 | 局部修改 |
| 动线堵塞 | 沙发/柜体挡住通往阳台或房门的路 | 局部修改，强调主通道畅通 |
| 天花悬空 | 吊顶无支撑结构 | 局部修改 |
| 材质反射异常 | 地面镜面反射过强、金属面变形 | 局部修改 |
| 文字乱码 | 画面出现无法辨认的字符 | 走 `fix_garbled_text()` 做色块化，或重新生成 |
| 隐私泄露 | 出现房号、门牌、电话 | 重新生成，禁止交付 |
| 风格跑偏 | 配色明显不属于目标风格 | 局部修改，强化配色比例 + 检查风格库排除项 |
| 跨图不统一 | 同一套图两张材质/色温不同 | 统一风格描述后重生成 |
| **厨房画出双排橱柜** | 净宽不足 2400 却出现对向高柜 | 重新生成，按 `buildability.md` §5.1 写可施工性硬约束 |
| **卧室画 1.8m 大床** | 净宽不足 3300 却两侧留通道 | 重新生成，按 `buildability.md` §5.3 改写 |
| **卫生间三件套挤不下** | 净宽 1.7m 却出现台盆+马桶+淋浴房完整形态 | 重新生成，按 `buildability.md` §5.2 改写 |
| **平台水印残留** | 右下角可见半透明白字 | 走 `postprocess.py --crop`（多结构底）或 `--fix`（渐变/平涂底） |
| **裁切后有色带/白边** | 数值达标但目视有浅色横带 | 换用 `--crop`，不要在修复路径上继续调参 |

## 八、质检记录要求

每张图的质检结果必须独立输出，不得合并成一句「检查通过」。

质检结果需包含：
1. 11 个维度的通过/不通过判定
2. 主要问题（具体到是什么问题，不能只写「不通过」）
3. 建议动作（四选一）

质检完成后，交付报告中需汇总所有图片的质检结论。

---

## 九、批量质检规则

1. **全检不抽检**：批量出图时每张图都要出独立质检结论，不得合并为一句「全部通过」
2. **即时重生成**：质检不过的图当场重新生成（上限 1 次），修改提示词强化对应约束后再生成；不带入下一张
3. **缺口如实报告**：重生成仍失败的房间标记为缺口，交付时说明原因与补齐方式，不阻塞其他房间
4. **先质检后归档**：每张生成后先读图质检、再走 `postprocess.py` 后处理、再重命名归档、再生成下一张；**禁止「先全部生成完再看」**
5. **套图一致性统一核对**：全部房间生成完后，一次性核对跨图配色/材质/色温/家具语言/拍摄高度
6. **对照房间识别清单**：窗户类型逐房间核对（平窗/飘窗/落地窗/无窗），清单标注「无窗」的房间画面出现任何窗户即判不通过
7. **对照可施工性判定**：逐房间核对清单的「可施工性判定」列，判定为 ⚠️/❌ 的房间必须采用保守布局
8. **后处理留痕**：交付报告中注明每张图的水印处置方式（未检出 / 裁切 / 修复），便于回溯
