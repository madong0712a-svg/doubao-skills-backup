# 计费契约表（per_call 按次付费）

> **用途**：本技能商业化交付的**唯一收费口径**。上架前由发布者核对单价；
> 对外承诺（FAQ 表、SKILL.md、交付话术）一律引用本表，不得与之冲突。
>
> **来源**：4.6.1 新增，对标竞品 plan-to-render（企业认证，¥1/次）的计费契约结构，
> 按本技能「平面图先行 / 效果图与平面图同批 / 平面图阶段修改零成本」的特点改造。
>
> **版本**：4.6.1

## 一、计费契约

| 项 | 内容 |
|---|---|
| 计费方式 | `per_call` —— 安装免费，每次调用扣费 |
| 单价 | **¥1.00 / 次**（对齐竞品 plan-to-render 实测市场价；调价必须同步修改本表 + `templates/faq_table.md`，两表不一致按本表执行） |
| 单次包含 | 户型结构化解析 1 份 + 平面俯视图 1 套（默认空间高效型；用户要对比出 2 套，不另计）+ 效果图 1 批（客厅 2 张 + P0–P3 其余房间各 1 张） |
| 免费微调 | 同一风格内微调（光线 / 材质 / 机位）**1 次** |
| 换风格 | 属新一次调用：先播报预算再出，不先斩后奏 |
| 加房间 | 优先级内直接补；单批 >10 间房只出核心空间，其余列清单问后补 |
| 平面图阶段修改 | **未出效果图前的平面图修改不另计**——平面图是预览门，改它不付出图成本 |
| 重出规则 | 因我方质量原因（结构错误 / 朝向画反 / 平台水印 / 自检 FAIL）重出**不另计**；用户偏好性重出（无质量问题的换风格 / 换机位 / 换布局方案）按新一次调用计 |
| 不包含 | 施工图、水电定位图、精确尺寸复尺、装修报价、材料采购推荐 |
| 交付形式 | 平面俯视图 + 效果图（可下载文件）+ 逐图质检报告（17 项）+ 十一项自检报告 + 布局数据 JSON + 同源对照表 + 物料清单 + 一页纸提案 + 避坑提醒 + 房源文案 + 风险提示 |
| 交付时限 | 平面俯视图约 2 秒；效果图逐张生成，全屋一批通常数分钟内 |
| 退款规则 | 未出图全额退；已生成图片属虚拟定制内容，不支持无理由退款；出图失败（模型故障 / 图片无法解析）全额退或补出一次 |

**交付时必须说明的边界**：

> 效果图为设计参考，不构成施工依据。实际尺寸、承重墙、管线走向须以现场勘测与专业设计图纸为准。

## 二、出图成本（默认零成本）

默认走**硅基流动免费档** `FLUX.1-schnell` —— 出图不计费，单次 ¥1 的毛利接近 100%。
要更高质量再切付费档（`FLUX.1-dev` 等，按服务商计费），**切档前必须说明单价与预计张数**。

| 服务商 | 免费档 | 付费档 |
|---|---|---|
| 硅基流动 siliconflow | `FLUX.1-schnell` **免费** | `FLUX.1-dev`（有试用/额度，以官方当时政策为准） |
| 智谱 zhipu | 新用户赠送额度，**非完全免费** | `cogview-4` 约 ¥0.01/张、`glm-image` 约 ¥0.016/张 |

> **别对用户说「智谱完全免费」** —— 它是低价 + 有限免费额度，超了要扣费。
> 免费承诺只对硅基流动 `schnell` 说。政策会变，价格以服务商官网为准。

## 三、预算播报闸（消耗前必须拦）

| 情况 | 处理 |
|---|---|
| 单批次预计消耗 > 60 积分 | **先播报预算并等确认**，不得静默消耗 |
| > 10 间房 | 只出核心空间（P0–P3 优先级），其余询问后补 |
| 切付费档模型 | 出图前说明单价与预计张数，得到确认再切 |
| 批量修改波及全屋 | 先报「N 房间 M 张 K 个保守布局」再逐张执行 |

## 四、与 FAQ 表的分工

- 用户追问**收费 / 免费 / 重出 / 加房间**口径 → 一律引用本表，`templates/faq_table.md` 只做引流不做承诺。
- 修改本表单价或包含项 → 同批检查 FAQ 表第四类与 SKILL.md 第二十一节（异常与降级）有无冲突表述。
- 平台侧实际结算方式（积分 / 按次）以上架平台规则为准；本表定义的是**对用户的交付承诺**，两者不一致时以对用户承诺为准，成本差额自行消化。
