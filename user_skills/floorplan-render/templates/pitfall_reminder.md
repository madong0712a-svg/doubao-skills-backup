## 二、逐空间提醒内容库（出图后按房间取用）

### 卫生间

**已规避：**
- 避开了壁挂式马桶 → 采用落地式，水箱、盖板、底座完整，维修时无需砸墙
- 避开了台上盆与岩板一体盆 → 采用陶瓷一体盆带四面挡水沿，盆深 ≥15cm，不留卫生死角
- 避开了石膏板 / 蜂窝大板吊顶 → 采用 300×600 铝扣板，未来检修可直接拆开
- 避开了长条地漏 → 采用 10×10cm 方形地漏配回字形倒角，排水快且不积毛发
- 避开了灯暖浴霸 → 采用风暖浴霸，不烤头皮、不伤眼
- 避开了木门与长虹玻璃 → 采用钛镁合金门配灰油砂玻璃，透光不透人、不变形发霉
- 避开了亮光地砖 → 采用柔光防滑砖，防滑优先
- 避开了黑色花洒五金 → 采用枪灰色恒温花洒，耐看易清洁
- 避开了百叶窗与浴缸 → 采用普通平窗配贴膜、淋浴花洒

**施工提醒：**
- 防水必须做：淋浴区刷到 **2m**、干区 1.2m、门口外翻 30cm，**闭水试验满 48 小时**，完成后做保护层
- 马桶安装前用水不漏 / 堵漏王把下水管与瓷砖缝隙封死，否则污水渗进沙灰层全屋返臭
- **法兰圈自购**（红油高胶 / ABS 加长，三四十元），不要用商家附带的黄油或黑色法兰，三四年就氧化渗水
- 地漏装前检查与下水管的**断层**，有断层必须换加长地漏芯
- 下水管用阻尼片 + 2cm 厚隔音棉双层包管，否则半夜被冲水声吵醒
- 浴霸排风管要接到止逆阀并通室外，直接扔在吊顶里等于没排风
- 马桶移位不超过 50cm，每 10cm 留 1cm 坡度；移位超 30cm 选直冲

**若本图涉及干湿分离：**
- 卫生间长度 ≥2.5m 建议做干湿分离或三分离，早高峰不排队、湿区水汽不乱跑

### 厨房

**已规避：**
- 避开了岩板与人造石台面 → 采用 1.5cm 厚石英石台面，底部加衬板，不磕碰、不半年发黄
- 避开了台上盆 → 采用台下盆（底部 ≥10 个卡扣加固）或台中盆，不留卫生死角
- 避开了吊轨推拉门 → 采用隐藏式 / 超薄极简地轨，不晃不脱落，扫地机器人能过
- 避开了集成灶 → 采用分体灶（顶吸 / 侧吸），内部油污可清理
- 避开了肤感 / PET 高光柜门 → 采用双饰面哑光柜门 + PUR 封边，不挂油污不留手印
- 避开了颗粒板 / 密度板柜体 → 采用多层实木板或欧松板（ENF 级）
- 避开了蜂窝大板 / 防水石膏板吊顶 → 采用铝扣板，检修方便
- 避开了外凸金属拉手与塑料踢脚板 → 采用免拉手设计 + 瓷砖踢脚板
- 避开了小规格仿古砖 → 采用 800×800 亮光砖，油污好打理
- 避开了统一 80cm 台面 → 采用高低台：炒菜区 78–80cm、洗切区 88–90cm，按身高不弯腰不架胳膊

**施工提醒：**
- ⚠️ **厨房地面必须做防水层**（按 GB 50327《住宅装饰装修工程施工规范》），不得以"无地漏""用不到"为由省略。四周墙面防水层高度 **≥0.3m**，施工后做**闭水试验**，完成后做水泥砂浆或细石混凝土保护层。选大品牌水管与全铜角阀，下水管根部用堵漏王加固。
  *说明：网上流传的"厨房防水是智商税"属低于现行规范要求的说法，不予采纳。现行版本、具体条款与地方标准差异，以标准原文及当地主管部门要求为准。*
- **烟道必须装密封止逆阀**（自购），瓦工贴砖前先开洞、贴到顶、紧贴瓷砖安装，否则油烟会从邻居家串进来
- **瓷砖进场先验收再结账**：生产日期是否同日（防色差）、是否优等品、有无 3C 认证、吸水率 ≤0.5%（GB/T 6952）、缝卡是否配齐
- **贴完砖晾干立即做美缝**，别拖：卫生间用水泥基 / 氢化环氧（不发霉），厨客阳台用纯聚脲（耐晒不变黄）
- **墙砖双面拉毛**再上墙，粘结牢固不掉砖
- 橱柜**少隔板多抽屉**，配碗拉篮 / 调味拉篮；隔板多取放费劲、碗盘积水发霉
- 改水电前**先定家具尺寸与位置**；水路从入户截断全换，至少打压两次；烟机灶具、马桶、花洒、洗碗机这些高频件买好的，别省
- 灶具孔**四角做圆角**、开孔前宽后窄，受力不裂、锅把不顶墙

### 客厅

**已规避：**
- 避开了岩板 / 格栅 / 大理石电视背景墙 → 采用大白墙或浅色乳胶漆，省下的钱投在电视和沙发上
- 避开了投影幕布 → 采用大屏显示电视，白天看也清楚
- 避开了悬空电视柜 → 采用落地电视柜，后期不开裂不坠落
- 避开了无主灯整层吊顶（层高 ≤2.9m）→ 采用双眼皮吊顶，层次分明且不压层高
- 避开了柔光砖 → 采用 800×800 浅色亮光砖，同色美缝留 2mm，一砖通铺客餐厅阳台，耐看好打理
- 避开了 L 型 / 肥大型沙发 → 采用直排沙发 + 单人椅，空间更宽敞
- 避开了笨重长方形大茶几 → 采用几何形轻便茶几（或去茶几化用边几）
- 避开了复杂水晶吊灯 → 采用吸顶灯，不压层高、好打理、亮度够

**施工提醒：**
- **全屋灯光色温统一 3500K**，同一空间灯具色温差不超过 500K，否则显廉价
- **不要全屋挂网**：只在新旧墙交接、水电开槽、石膏板拼接、明显裂缝处局部挂网，其余纯属多花钱
- **不要全屋冲筋找平**：只在有柜子、踢脚线、门窗的位置局部找直
- 客厅与南阳台**只需在南阳台装窗帘**，客厅不留窗帘盒，省钱省空间
- 电视插座做成抽拉抽屉隐藏网线 / 电源 / 路由器，并留散热通风口

### 卧室

**已规避：**
- 避开了榻榻米 → 采用成品排骨架床，通风环保、好打理
- 避开了碳晶门 / 生态门 / 铝木门这类"好听名字"的门 → 采用实木复合烤漆门，隔音环保、千元内搞定
- 避开了罗马杆 → 采用窗帘盒（盒宽 15cm、双层轨道 22cm），不漏光不挡采光
- 避开了飘窗贴瓷砖与包窗套 → 采用整块大理石台面（不做小耳朵、不外凸），飘窗不包套，用耐水腻子 + 防霉漆饰面
- 避开了衣柜深度 55/58cm → 采用 62cm 深，厚羽绒服大衣能挂能关
- 避开了挂衣区上下等分 → 采用上衣区 80cm、裤子区 ≥95cm，上衣不悬空、裤子不拖地
- 避开了叠衣区过多 → 采用多挂衣区、少叠衣区，配分类抽屉，拿取不翻乱
- 避开了一门通顶超高门 → 采用门高 2.2m、宽 88cm、板厚 4.5cm，商家不加钱且不易变形

**施工提醒：**
- 床头装**四孔插座**比五孔更实用
- 儿童房柜体上下空格的**背板一定要做**，否则脚踢脏墙
- 免拉手缝宽留 2.5cm：宽了显大，窄了夹手
- 定制柜装完**用手电筒验收**：螺丝孔有无装饰盖、有无贴纸掩盖划痕、封边是否到位、五金有无 LOGO、背板厚度够不够

---

### 玄关

**已规避：**
- 避开了 33–34cm 深的鞋柜 → 采用 35–40cm 深，大码鞋和鞋盒放得下
- 鞋柜下方留 18cm 放当天穿的鞋和拖鞋，中间留 40cm 洞口随手放包
- 预留了感应灯电源 → 采用感应灯带，夜里回家自动亮、人走自动灭

---

### 阳台

**已规避：**
- 避开了笨重推拉门 → 采用包垭口套 + 地暖通铺到阳台，敞亮通透
- 避开了阳台吊顶藏梁藏晾衣架 → 不做吊顶，梁和晾衣架露出来，简单实用不压层高
- 避开了垭口刷乳胶漆或包木质套 → 采用钛镁合金垭口，防水耐潮不暴晒发黄
- 洗衣机电源留在洗手盆正下方，安装维修都方便

---

### 全屋定制与柜体

**已规避：**
- 避开了 3/5mm 薄背板 → 采用靠墙背板 ≥9mm，背板后悬空处用 18mm，柜子不晃不响承重够
- 柜体与柜门**都用 PUR / EVA 封边**（尤其踢脚板位），不偷工受潮开裂
- 避开了满玻璃门餐边柜 / 酒柜 → 点缀一扇或不做，省下的钱多做抽屉
- 不迷信大品牌 → 本地工厂 + ENF 级多层实木板 + 指定好五金，防潮环保又省钱
- 五金选大品牌、抽屉带缓冲阻尼，别贪便宜

## 三、全屋通用的三条硬规矩（每次都提）

```
1. 隐蔽工程不省钱 —— 防水、水电、角阀、地漏后期不可换，换一次代价极大。
2. 三个不省 —— 环保材料（板材/乳胶漆/室内门/腻子/美缝剂/玻璃胶/防水涂料，胶类尤其不能省）、隐蔽工程、高频使用电器。
3. 小件提前网购 —— 一次性马桶、密码盒、阻尼片+2cm隔音棉、前置过滤器、地漏、烟道止逆阀、地砖保护膜、全铜陶瓷阀芯三角阀、防霉玻璃胶。师傅自带或小区五金店现买的，质量差价格高。
```
