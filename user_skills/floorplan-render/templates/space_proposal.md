# 空间提案卡 · 一页纸（v4.0）

> **用途**：把房间清单、风格说明、可施工性提示、收纳配置、物料清单摘要合成**一页**，供房产经纪人直接转发给客户。
> **定位**：这是"给客户看的那一版"。完整技术细节留在交付报告里，本页只放客户关心的内容 + 必要的免责边界。

---

## 一、使用规则

| 项 | 要求 |
|---|---|
| 长度 | **一页以内**，不超过 A4 一面 |
| 语言 | 客户能看懂的话，**不出现专业术语**（不写"净尺寸""可施工性判定""热桥"） |
| 必须含 | 风格一句话、空间亮点、已避开的坑、物料摘要、口径声明 |
| 禁止 | 报价、承诺采光时长、真实面积、升值保证、"绝对""百分百"等绝对化表述 |
| 配套 | 完整版见 `delivery_report.md`；避坑明细见 `pitfall_reminder.md` |

## 三、按受众调整

| 受众 | 强调什么 | 弱化什么 |
|---|---|---|
| **购房客户** | 空间亮点、已避开的坑、"住进去什么样" | 材料型号、施工工艺 |
| **房产经纪人（转发客户）** | 亮点 + 避坑 + 下一步建议 | 技术细节 |
| **设计师（内部对齐）** | 可施工性提示、收纳配置、物料清单摘要 | 营销文案 |
| **门店客户（成交前）** | 亮点 + 已规避的坑 + 现场确认事项 | 价格相关内容 —— **本技能不提供** |

---

## 四、与避坑提醒的关系

提案卡上的「已避开的常见问题」是 `pitfall_reminder.md` 的**浓缩版**，每空间只取 3 条最相关的：

- 卫生间 → 落地马桶（非壁挂）、陶瓷一体盆、铝扣板吊顶
- 厨房 → 石英石台面（非岩板）、台下盆（非台上盆）、地轨（非吊轨）
- 客厅 → 大白墙背景墙、落地电视柜、亮光砖
- 卧室 → 成品床（非榻榻米）、62cm 深衣柜、窗帘盒

**不重复完整清单** —— 完整版在避坑提醒里，提案卡只做门面。
