# 风格选型与户型图解读速查

供 floorplan-to-render 执行时查阅：先读懂户型图，再帮用户选对风格，最后才是出图。

## 1. 户型图解读清单（读图时逐项提取）

| 提取项 | 看什么 | 影响 |
|---|---|---|
| 格局 | 几室几厅几卫、有无玄关/储藏间 | 决定效果图房间清单（--rooms） |
| 朝向采光 | 指北针、窗的位置与大小 | 采光差的房间优先推荐浅色系风格（奶油/北欧） |
| 承重墙 | 粗黑实线/斜线填充墙 | 效果图不得表现出拆改承重墙的格局 |
| 动静分区 | 卧室区与客餐区是否分离 | 报告里点评动线合理性 |
| 厨卫关系 | 厨房是否靠入户/餐厅，卫生间是否干湿分区 | 厨房效果图布局（L 型/U 型/一字）依据 |
| 尺寸标注 | 开间进深、层高 | 开间 <3.3m 的客厅不做满墙柜；层高 <2.7m 劝退复杂吊顶 |
| 特殊结构 | 飘窗、阳台是否封闭、梁柱位置 | 效果图要保留这些结构特征才可信 |

读图后给用户输出一张「户型解读表」：格局 / 面积 / 朝向 / 优点 2 条 / 注意点 2 条。

## 2. 风格速选矩阵（用户纠结时用）

| 用户画像 | 推荐风格（--style） | 一句话理由 |
|---|---|---|
| 首次装修、预算紧、小户型 | modern 现代简约 / nordic 原木北欧 | 耐看不过时，主材便宜好买 |
| 年轻女性、采光一般 | cream 奶油风 | 浅色系提亮，柔光弥补采光 |
| 改善型住房、重质感 | lightlux 轻奢 | 石材金属提档次，但五金灯具预算要足 |
| 喜欢传统文化、大户型 | newchinese 新中式 | 大空间压得住深色木作 |
| 高挑层、工业审美 | industrial 工业风 | 层高 ≥2.8m 才出效果 |

预算提醒（占硬装比例的经验值）：现代/北欧最省；奶油风贵在弧形工艺；轻奢贵在石材五金；
新中式贵在实木；工业风贵在层高处理与管线美化。

## 3. 效果图 prompt 实务

- **户型图即 image1**：图生图让布局可信；prompt 只负责「风格 + 视角 + 空间内容」，不要在 prompt 里重复描述房间数量（以图为准）。
- **先出 aerial 全屋鸟瞰**：3D 轴测图和用户确认格局理解无误后，再逐房间出透视效果图，返工率最低。
- **一张不满意**：同 prompt 重生成 1-2 次再改 prompt；改 prompt 时每次只动一个变量（风格词 / 视角 / 光线）。
- **保留结构**：承重墙、飘窗、梁柱在 prompt 里点名保留（如 "keep the structural bay window"），防止 AI 自由发挥。
- **尺寸建议**：室内透视 1536x1024（横构图信息量大）；全屋鸟瞰 1024x1024。
- **quality 用 high**：效果图是交付物，不用 low/medium 凑数。

## 4. 效果图的边界（必须告知用户）

1. 效果图是**风格意向图**，不是施工图——没有精确尺寸、材料规格、节点做法。
2. AI 可能美化空间比例（层高显高、房间显大），落地以实测为准。
3. 图中的家具/建材不代表可买到的具体商品，选样按色卡与材质描述找近似款。
4. 涉及拆改的构想，必须核对承重墙与物业规定，效果图不构成拆改依据。
