# 面相照片判读实操指南（应用型）

> 本指南供 Skill 在分析用户上传影像时遵循，把经典"形—位—义"落到可操作的观察步骤。

## 一、请用户提供的标准素材
1. 正脸平视照：正面、双眼平视镜头、光线均匀、无刘海遮额、无浓妆、露双耳。用于看三停、十二宫、五官。
2. 侧脸45°照：看鼻梁走势（悬胆/露骨/歪斜）、地阁（方满/尖削）。
3. 半身照（可选）：看腰圆背厚、肩颈、手足（若露）。
4. 视频（可选）：静帧抽看即可，不做动态微表情断言。
若素材不达标，先引导补拍，切勿在模糊图上硬解。

## 二、逐部位观察清单
- **印堂（命宫）**：宽度（一指半~两指为佳）、有无竖纹/悬针纹/川字纹、气色明暗。
- **眉**：长短是否过目、疏密清浊、有无断缺、眉尾是否入天仓、两眉是否交锁。
- **眼**：大小黑白分明否、神藏或露、有无三白四白、眼形（凤/丹凤/三角等）、鱼尾纹。
- **鼻**：山根高低、鼻梁直否有横纹、准头丰隆否、鼻孔仰露否、兰台廷尉（鼻翼）饱满否。
- **口**：唇色红润否、上下唇齐丰否、口角上扬或下垂、人中深浅。
- **耳**：轮廓分明否、贴脑或招风、耳白过面否、耳垂厚否、有无长毫。
- **颧**：左右是否对称朝拱、过高（破权）或低陷、有痣。
- **地阁（下巴）**：方满丰颐否、尖削否、歪斜否。
- **气色**：整体润泽或枯暗；时令正色为何；有无局部异色。

## 四、案例示范（虚构，仅供格式参考）
用户传正脸照：印堂宽平、眉清长过目、眼黑白分明有神、鼻丰隆直、口方唇红、耳贴脑白润、地阁方满。
输出：
- 三停五岳：三停平等，中岳（鼻）高隆朝拱，整体贵相基础好。
- 五官：耳成（贴脑白润）、眉成（清长）、眼成（监察有神）、鼻成（审辨丰隆）、口成（出纳方红）→ 五官能成，主贵显福厚。
- 十二宫要点：命宫明润主心智通；财帛丰隆主财旺；妻妾光润主情稳；其余平。
- 气色：面色润白（金形正色），无碍。
- 综合：传统相法看，此人给人文静而有主张、可信赖的印象，中年后担当事业运佳。相逐心生，保持心田宽厚可固相。
- 说明：仅供娱乐与自我觉察。

## 五、常见误区分辨
- "印堂发黑"：多为疲劳/光线/肤色，提示休息，不臆断灾。
- "鼻有横纹"：相法主波折，现实中可能是表情纹，温和提示"注意财务规划节奏"。
- "夫妻宫有痣"：仅作"情感需多沟通"的轻提示，不判离婚。
- 不把单一特征放大为命运定论；始终回到"形—位—义—心神"整体观。

## 六、与用户的对话话术
- 开场："我按《麻衣神相》的十二宫、五官、三停体系来看，纯属传统文化参考，别太当真哈。"
- 收图后："这张光线不错，能看清十二宫。我按三停→五官→重点宫位→气色来说。"
- 收尾："相由心生，心田好相自变。这解读就当个自我觉察的小镜子。"
