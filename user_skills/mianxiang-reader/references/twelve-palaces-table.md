> 以《麻衣神相》十二宫为蓝本，附现代温和解读。相不独论，须整体观。

## 三、五官形态成败扩展判读
### 耳（采听官）
- 成相：轮廓分明、喜白过面、贴脑、耳厚垂珠、内有长毫 → 少年运顺、福厚。
- 欠相：轮飞廓反、鼠耳木耳、低小软弱、耳薄无垂 → 少年波折、-six亲助力弱。
### 眉（保寿官）
- 成相：清高疏秀弯长、高目一寸、尾拂天仓 → 聪明福寿。
- 欠相：粗浓黄淡、散乱低压、交锁、中断 → 刑伤破败、兄弟疏离。
### 眼（监察官）
- 成相：黑白分明、神藏不露、凤眼象眼等、波长射耳 → 贵显有威。
- 欠相：蛇蜂羊鼠四白等眼、赤白纱侵、神光太露 → 愚顽凶败。
### 鼻（审辨官）
- 成相：丰隆耸直有肉、悬胆截筒、端正不偏 → 富厚。
- 欠相：鹰嘴剑峰、露孔仰灶、扁弱露骨、孤峰 → 贫苦刑恶。
### 口（出纳官）
- 成相：唇红齿白、四字方口、仰月弯弓、人中深长 → 富贵。
- 欠相：覆船鱼口、唇短齿露、黑皱、上薄下反 → 困顿。

## 四、气色时令正色速查
- 春青、夏红、秋白、冬黑，季月黄，为天时正色。
- 木形青带黑忌白；火形红带青忌黑；金形白戴黄忌红；水形黑带白忌黄；土形黄带红忌青。
- 青如晴日初出润泽为正；干焦如伤痕为邪凶。红白黑黄同理。
