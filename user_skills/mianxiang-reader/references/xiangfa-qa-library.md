# 麻衣相法 · 应用型百问百答

> 以《麻衣神相》《柳庄神相》《水镜神相》体系为骨架，面向"用户传照片/视频即出解读"的应用场景。
> 相法讲"相不独论、相由心生"，所有解读为性格与趋势参考，不替代现实努力与专业判断。

## 一、总纲
**Q1：什么是十二宫？**
面部分为十二个功能区，各主人生一事：命宫（印堂）、财帛宫（鼻）、兄弟宫（眉）、夫妻宫（眼尾）、子女宫（卧蚕）、疾厄宫（山根）、迁移宫（额角）、奴仆宫（地阁）、官禄宫（额中）、福德宫（眉上）、父母宫（日角月角）、田宅宫（上眼睑）。看相先立十二宫框架。

**Q2：什么叫"三停"？**
上停（发际到眉）主早年与思想，中停（眉到鼻准）主中年与才干，下停（鼻下到地阁）主晚年与福禄。三停匀称为佳。

**Q3：什么叫"五岳"？**
额为衡山、鼻为嵩山、颔为恒山、左颧为泰山、右颧为华山；以鼻（中岳）为中坚，四岳朝拱为贵相之基，指面部中心与四方的均衡。

**Q4：什么叫"五官"？**
耳眉眼鼻口，分主采听、保寿、监察、审辨、出纳；五官端正清秀为基，再论气色与格局。

**Q5：最核心的一句话原则是什么？**
相不独论——单看一处易偏，须宫、形、色、神综合；且相由心生，心改相随转。

## 二、分宫详读
**Q6：命宫（印堂）怎么看？**
两眉之间为命宫，宜宽平明亮。窄陷多思虑，有纹侵主早年波折；明润主心宽运顺。

**Q7：财帛宫（鼻）主什么？**
鼻为财帛宫，鼻准（准头）主财库，鼻翼主守财。准头丰圆有肉、鼻翼不露孔为善理财；尖削露孔主财来财去。

**Q8：兄弟宫（眉）怎么看？**
眉为兄弟宫，也主性情与同辈缘。眉清疏长宽、尾不散主兄弟和睦、自身有恒；眉乱逆、交连印堂主兄弟参商、性急。

**Q9：夫妻宫（眼尾）怎么看？**
鱼尾（奸门）为夫妻宫。平满光泽主夫妻和顺；凹陷、纹多、有痣主情路波折，须结合整体不与独断。

**Q10：子女宫（卧蚕）怎么看？**
眼下卧蚕为子女宫。丰润明活主子女缘厚、晚年得济；枯陷或有恶痣主子女缘薄或多忧，仅作倾向参考。

**Q11：疾厄宫（山根）怎么看？**
山根（鼻梁根）为疾厄宫，连年寿（鼻梁）。高耸平润主少病；低陷断折、有横纹主体质偏弱，提醒注意作息就医。

**Q12：迁移宫（额角）怎么看？**
边地、驿马（额角两侧）为迁移宫。丰隆开阔主出行有利、外出得遇；低陷狭窄主远行多阻。

**Q13：官禄宫（额中）怎么看？**
天庭（额中）为官禄宫，主事业名望。饱满明润主事业顺、有官贵气；低窄凹陷主早年事业多磨。

**Q14：田宅宫（上眼睑）怎么看？**
上眼睑为田宅宫，主家宅、祖业。宽润主得祖荫、居家安稳；陷薄主居家多迁、少祖业。

**Q15：父母宫（日角月角）怎么看？**
左右额角为父母宫（日角父、月角母）。高耸明润主双亲康宁；低陷枯暗主早年父母缘浅或体弱，须温言。

## 三、形与神
**Q16：耳大耳小有何说？**
耳主福禄与早年运。耳轮分明、垂珠朝口为福厚；耳小廓反主幼年辛劳、自立早。麻衣有"耳白过面""耳高于眉"为贵之论，但须综合。

**Q17：鼻梁中断说明什么？**
鼻梁（年上寿上）中断或横纹，传统主中年波折、健康留意；但更应看作提醒而非定论。

**Q18：眉锁印堂（连眉）怎么看？**
两眉交连印堂，主性执、多忧；现代看多与长期皱眉习惯相关，放松即可改善——正是"相由心生"的例。

**Q19：眼形与性格？**
眼为监察官，最重神。目清有神、黑白分明主心正聪察；眼神游移、三白四白多主心术需省。形随神转，养神为先。

**Q20：唇齿与性格？**
口为出纳官。口方唇齐、齿密白主言语有信、晚年安；唇薄齿疏主善辩或言多，仅作倾向。

**Q21：气色怎么看？**
青主忧疑、赤主困恼口舌、黄明主平顺、白主哀耗、黑主危滞。气色日日变，故相随时移，最忌以一时色下定论。

**Q22：何为"南人北相、北人南相"？**
南方人面方阔、北方人面清秀为相格反差，古称"相夺"，主离乡发迹；今可理解为面相与出身地反差者多外闯。

**Q23：少年看耳、中年看眼、老年看口，对吗？**
是传统"流年"观的简化：耳主幼、目主中、口主老；但全期仍须综合，不可断章。

**Q24：骨相与肉相何者为重？**
麻衣重骨格为体、肉色为用；骨立而肉润、神清为上。骨露肉枯则需养。

**Q25：女相重点看哪里？**
古法重眉目清秀、鼻准有肉、唇红齿白、神态安和；今更重整体气质与神采，不以旧框限人。

**Q26：男相重点看哪里？**
古法重天庭、颧鼻、地阁的均衡与威仪；今同样以神清、形正、色润为要。

## 四、应用与边界
**Q27：用户传照片，Skill 第一步做什么？**
先定位十二宫与三停五岳，读五官端正与否、气色明暗，再结合用户年龄与所求（事业/感情/健康/整体）给侧重解读。

**Q28：流年部位怎么用？**
面部按年龄分布部位（如耳管幼、目管中、口管老，细分有"流年百部"），可提示某阶段宜留意之处，但须轻断。

**Q29：面相能改吗？**
形有定而神可变，气色、神态、习惯日日改；心境修养、作息规律都会反映在面上——相由心生，正此谓也。

**Q30：同人异时面相会变吗？**
会。气色、神态、胖瘦、纹路随岁月与心境变；故拍照看相宜说明近期状态。

**Q31：面相与八字冲突听谁的？**
二者体系不同，面相看先天禀赋与当下神色，八字看干支时空；可互参，不必强分高下。

**Q32：拍照看相要注意什么？**
光线均匀、正脸微侧各一张、不浓妆不表情夸张；角度畸变会误读宫位。

**Q33：侧脸能看什么？**
侧脸看鼻梁走势、额下巴的线条（三停侧面），利于判断中停与晚景。

**Q34：痣相怎么看？**
古法分部位论吉凶（如眉内痣主富、眼下痣主劳），今多作趣味参考，不因一痣下定论。

**Q35：麻衣、柳庄、水镜三家有何侧重？**
麻衣立十二宫与神形总则；柳庄重性别与实操歌诀；水镜补气色与流年。本 Skill 以麻衣为纲、旁参二家。

**Q36：能否凭面相决定录用谁？**
不能。面相可作自我觉察，绝不可用于招聘、信贷等涉及他人权益的判定，那是歧视且无效。

**Q37：用户问"我是不是克夫/克妻"怎么回？**
明确说明相法只讲倾向与相处提示，无"克"之实；引导关注沟通与关系经营，不落宿命恐吓。

**Q38：眼善心不善怎么办？**
以神为先——神清为正、神浊为邪，形好而神恶不足取；故看相终在"观人观其神"。

**Q39：何为"相由心生"的操作意义？**
把看相当作自我提醒：修正习气、宽心养神，面上自然转好；这是相法最实用的部分。

**Q40：给用户的解读应含哪些部分？**
十二宫要点、三停五岳均衡、五官与气色、结合所求的方向建议、以及"趋势参考、莫作定论"的说明。
