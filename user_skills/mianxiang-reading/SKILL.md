# 面相分析

## 工作流

1. **收图校验**：按“照片合格性校验”判断能否判读，不合格先要图，不要硬判。
2. **读知识库**：`Read references/mianxiang-encyclopedia.md`，再开始判读。
3. **判读**：按固定顺序（面型 → 三停 → 五岳 → 五官 → 十二宫 → 气色痣纹 → 神气）。
4. **输出**：读 `references/report-template.md`，套用其中的报告结构。
5. **免责**：报告结尾必须带免责声明，正文不要说教式重复。

## 照片合格性校验

必要条件：

- 正面或偏转不超过 15°，五官不被头发、帽子、手、口罩遮挡（额头、耳朵尽量露出）
- 无美颜 / 瘦脸 / 大眼滤镜，无明显磨皮
- 光线均匀，无强侧阴影、逆光、油光反光
- 单人一张，眉、眼、鼻翼、唇线、耳廓细节清晰可辨

不合格时：一条说清缺哪几项，再给 3–5 句拍摄指引（自然光朝窗、手机前置关美颜、镜头与眼平齐、头发拨开露额、素颜或淡妆、距离 50–80cm、正脸微收下巴）。某一部位实在看不清，就写明“此部位判读不清，不作论断”，绝不编造细节。

## 判读顺序（固定，不要跳步）

| 顺序 | 对象 | 作用 |
|---|---|---|
| 1 | 面型与五行形相（木火土金水） | 定整体格局与气质基调 |
| 2 | 三停比例（上/中/下） | 定人生三个阶段的重心与均衡度 |
| 3 | 五岳与四渎 | 定格局高低、是否“朝拱流通” |
| 4 | 五官（眉→眼→鼻→口→耳） | 逐项取象，落到具体能力与性格 |
| 5 | 十二宫重点宫位 | 只讲与本人明显相关的 3–5 宫，不必全讲 |
| 6 | 气色、痣、纹 | 定近期状态与细节标记 |
| 7 | 神气（眼神） | 总纲，最后压轴定评 |

取象权重：**神 > 骨 > 肉 > 皮**。眼神、气定与否，优先级高于任一五官的尺寸形状。局部有瑕疵但整体格局成立时，明确写“不害大局”。

## 论断口径（必须遵守）

- **先扬后议**：先讲优势与可用之处，再讲需留意之处；结尾给方向，不留在负面情绪里。
- **只讲倾向，不讲必然**：用“倾向 / 易 / 偏 / 宜 / 忌”，禁用“注定 / 一定 / 必死 / 必离 / 破财无疑”。
- **不做疾病诊断**：疾厄宫只谈“注意休养、易疲劳、留意作息”，有具体不适建议就医，不点病症名。
- **不做人身攻击与品行定性**：禁用“凶恶、克夫、贱相、小人相”等词；一律改写为中性行为描述，例：“眉压眼者性急，宜缓三分”。
- **不预测具体灾祸与时间点**，不提供“化解 / 开光 / 改运”式服务暗示；建议落在作息、行事风格、人际与修养（相由心生）。
- **未成年人只讲优点与成长建议**。
- 涉及他人的照片：只做性格与气质层面的中性描述，不评价美丑、不推断隐私、不做婚恋与用人建议。

## 输出

- 默认：按 `references/report-template.md` 的结构输出完整报告（口语化，不堆术语，术语首次出现配一句白话）。
- 速判请求（“就说一句 / 简单看看”）：150 字内，格局一句 + 优势一句 + 留意一句 + 一句建议。
- 报告长度随照片信息量走：合格高清正面照 600–1000 字；信息不足的照片 300 字以内并说明局限。

## 变体

- **双人对比（夫妻相 / 合作相）**：先各自 3 行速判，再讲互补点与摩擦点，最后一句相处建议。
- **单项深挖**（只看财运 / 事业 / 婚姻 / 健康气色）：只取相关宫位与五官，其余一句带过。
- **流年部位**：按当事人年龄定位到对应部位，讲这一段的着力点。
- 手相、姓名、八字、风水不属本技能范围，按用户意图另走其他技能。
