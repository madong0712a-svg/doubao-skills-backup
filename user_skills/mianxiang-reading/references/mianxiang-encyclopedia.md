## 1. 判读总纲

传统相法讲“相不独论”，取象有轻重：

**神 > 骨 > 肉 > 皮**

- **神**：眼神是否定、是否有光、表情是否松。神清者，纵五官平常亦有后劲；神浊者，五官再好也易散。
- **骨**：额、颧、鼻梁、下颌的骨相撑不撑得住，决定格局的“架”。
- **肉**：肉是否包得住骨（骨肉相称），过瘦为“枯”，过肥为“浮”，两者都主耗。
- **皮**：肤色气色、痣纹，属细节与近期状态，权重最低。

均衡为佳：**骨肉相称、气色明润、神态安稳**，比任何单项“贵相”都可靠。

## 2. 五行形相（面型）

| 形 | 特征 | 主性 | 宜 |
|---|---|---|---|
| 木形 | 面长、身直、清瘦，眉清目秀 | 仁、重情、善思 | 文教、研发、策划 |
| 火形 | 上尖下阔或面尖颧高，行动快 | 礼、性急、外显 | 销售、表演、开创 |
| 土形 | 面方、肉厚、背厚，行动稳 | 信、持重、耐压 | 行政、管理、实业 |
| 金形 | 面方、色白、骨坚 | 义、刚断、守规矩 | 政法、纪律、工程 |
| 水形 | 面圆、肉丰、下颌厚 | 智、圆融、善谋 | 商贸、谋划、外联 |

多为“主形 + 兼形”（如木兼火、土兼金）。取象时先定主形给基调，再用兼形补一层细节。忌语：木形忌“枯”，火形忌“赤气满面”，土形忌“肥而气滞”，金形忌“过刚无肉”，水形忌“面浮”。一律转写为“宜养”“宜缓”。

## 3. 三停

- **上停**：发际到眉毛（天庭）。主 15–30 岁，早年运、祖上根基、父母缘、心智与学业。
- **中停**：眉毛到鼻准。主 31–50 岁，自身奋斗、事业、财务、婚姻。
- **下停**：人中到地阁（下巴）。主 51 岁以后，晚运、子女、田宅、部属与基业。

断法：
- 三停均等 → “三停平等，一生衣禄无亏”，作**平顺、均衡**解。
- 上停长而明润 → 早年得长辈助力，思虑型，读书与规划上有优势。
- 中停充实 → 中年发力，实务能力强，靠做事立身。
- 下停厚实方圆 → 晚运稳，聚人聚财，越老越有底气。
- 上停短、发际低 → 早年多劳碌，须自立，早年靠勤补。
- 中停窄 → 中年多变动，宜专注一门。
- 下停尖削 → 晚年宜早做积累与安排，不宜全靠后人。

## 4. 五岳四渎

**五岳**（以鼻为中岳）：

- 南岳：额头（衡山）→ 名声、上级与长辈缘、早年势。
- 中岳：鼻子（嵩山）→ 全局主梁，主自我、中年运、财路。
- 北岳：地阁（恒山）→ 富与晚运、根基、聚合力。
- 东岳 / 西岳：左颧 / 右颧（泰山 / 华山）→ 权柄、执行力、同侪与竞争关系。

“五岳朝拱”：颧不高于鼻，额与颏饱满，四方向中岳聚势 → 格局稳、能担责、事业有台阶。
颧高过鼻而鼻弱 → 有冲劲但易逞强，宜借团队补位；鼻强颧弱 → 独立能扛但少助力，宜主动经营人脉。

**四渎**（耳、目、口、鼻），取“流通不滞”：耳孔不塞、目黑白分明、唇口闭合有力、鼻窍通畅、气色不阻。流通 → 思路与人际不堵；滞 → 易积压情绪与事务，宜疏通。

## 5. 五官

### 眉（保寿官）：兄弟、寿元、情绪与耐力

- 佳：眉长过目、眉尾有聚、眉清见底、走势顺势。
- 欠：眉短不及目、眉压眼、眉中断或稀薄、眉尾散乱。
- 取象：眉长者重情、耐力好、能长期扛事；眉浓者义气、讲义气但易执；眉稀者心思细、易多虑；眉压眼者性急、心事多压在心口，宜缓三分；眉尾散者理财宜记账、宜收口。

### 眼（监察官）：心性、智慧、精力

- 佳：黑白分明、眼神定而有光、眼形细长有收、卧蚕饱满。
- 欠：下三白（眼珠偏上露白多）、眼神浮游不定、眼窝深陷神疲、眼周赤脉。
- 取象：眼神定者判断准、耐得住；眼大有神者外向、善表达；眼细长者心思深、能守密；目光游移者多为睡不足或心事多，先调作息。**只谈神气与状态，不谈“凶相”**。

### 鼻（审辨官）：财、自我、中年运

- 佳：山根不断、鼻梁挺直不歪、准头丰隆有肉、鼻翼（兰台廷尉）有收、鼻孔不仰。
- 欠：山根低陷、鼻梁起节、准头尖薄、鼻孔外露、鼻翼单薄。
- 取象：准头丰者务实聚财；鼻翼收者理财有度；鼻孔微露者花钱爽快，宜设强制储蓄；鼻梁起节者个性硬、主见强，宜柔化沟通；山根弱者易疲，宜养身。

### 口（出纳官）：食禄、言语、人际与晚运

- 佳：唇线清、唇厚适中、口角微上扬、齿齐而白、闭合有力。
- 欠：口角下垂、唇薄口小、常开不合、齿乱不齐。
- 取象：口角上扬者人缘好、心态乐观；唇厚者厚道、重情义；唇薄者口才利、说话直，宜留三分；口小唇薄者不善主动表达，宜多开口；闭合有力者话有分量。

### 耳（采听官）：童年、根基、悟性与纳言

- 佳：耳高齐眉、轮廓分明、耳垂有肉、贴脑。
- 欠：耳薄无肉、招风、耳轮反、耳垂过薄。
- 取象：耳厚贴脑者根基稳、听得进劝；耳高者悟性早、早年得机；招风耳者外向、消息灵、易分心；耳薄者宜养肾养神、少熬夜。

## 6. 十二宫

| 宫 | 位置 | 主事 | 断法要点 |
|---|---|---|---|
| 命宫 | 印堂（两眉之间） | 一生运势根基、心胸 | 宽窄约一指半至两指、明润平满 → 开阔、近期顺；过窄或见竖纹、疤痕 → 思虑重、易纠结 |
| 财帛宫 | 鼻准 + 两鼻翼 | 财路、理财 | 丰隆有收 → 稳；尖薄露孔 → 来去快 |
| 兄弟宫 | 双眉 | 手足、同侪、合作 | 眉秀不散 → 缘厚；眉断眉稀 → 宜独立行事 |
| 田宅宫 | 上眼睑（眼窝） | 家业、置产、居所 | 宽厚明润 → 安定；凹陷单薄 → 居所多变动 |
| 男女宫 | 泪堂（眼下） | 子女缘、晚辈 | 平满有光 → 缘厚；青暗浮肿 → 操劳熬夜，调作息 |
| 奴仆宫 | 地阁两侧腮颐 | 部属、晚辈、助力 | 方圆有肉 → 得人帮；尖削 → 事必躬亲 |
| 妻妾宫（婚姻宫） | 眼尾（鱼尾） | 感情、婚姻 | 光润无杂纹 → 和顺；凹陷、乱纹 → 多起伏，宜沟通 |
| 疾厄宫 | 山根（鼻根） | 体力、健康状态 | 明润 → 恢复快；青暗 → 留意休养与体检（不作病症判断） |
| 迁移宫 | 额角天仓、驿马 | 出行、变动、异地 | 丰隆 → 变动得利；低陷 → 宜本地深耕 |
| 官禄宫 | 中正（额中） | 事业、职务 | 饱满光润 → 有台阶；凹陷乱纹 → 靠专业立身 |
| 福德宫 | 天仓（眉尾上）+ 地库（下巴两侧） | 福分、享受能力 | 丰 → 有福可享；薄 → 劳心，宜主动放松 |
| 父母宫 | 日月角（额两侧，父左母右） | 父母缘、长辈 | 饱满 → 长辈缘厚；低陷 → 早年独立 |

实操：**只讲 3–5 个明显成立的宫位**，其余一句“其余诸宫平顺”带过。不要十二宫逐一铺开。

## 7. 气色

论近期（1–3 个月），不作长期定论。

- 明润、润泽、透血色 → 状态好，事易顺。
- 暗滞、灰蒙、局部青黑 → 疲劳或阻滞，宜调作息与节奏。
- 印堂明润 → 近期心气顺；印堂暗 → 心事多，宜减法。
- 山根青暗 → 体力透支，提醒休息与体检。
- 准头赤 → 上火、焦躁，宜降火静心。
- 眼周暗、卧蚕浮 → 睡眠债，先把睡眠补回来。

## 8. 痣相

- **善痣**：黑亮、微隆起、有毫毛、形状圆整；生于额中、准头旁、地阁、耳垂 → 加分项。
- **忌位痣**：印堂正中、山根、眼尾、口角、人中 → 作“多一分留意、少一分执念”解读，不作凶断。

实操：只取最显眼的 1–2 颗讲，痣多不必细数。

## 9. 纹路

- **额三纹**（天纹、人纹、地纹）：早年操劳印记。纹路顺、不断 → 思路清、有历练；断裂交错 → 早年多操心，宜稳节奏。
- **川字纹（眉间竖纹）**：思虑重、责任心强、爱操心 → 建议把“想”落成“做”。
- **法令纹**：深浅适度主规矩与威权；过早过深 → 早年担责多、劳心。
- **鱼尾纹**：笑纹自然者为善；杂乱交错 → 情绪起伏多，宜修和。
- **眼下横纹**：操劳、熬夜痕迹，调作息即可。

## 10. 流年部位（简化）

| 年龄 | 部位 |
|---|---|
| 1–14 | 双耳（左 1–7，右 8–14） |
| 15–30 | 额头（15 火星、16 天中、19 天庭、22 司空、25 中正、28 印堂、29–30 山林/凌云） |
| 31–40 | 眉眼（31–34 眉、35–40 眼） |
| 41–50 | 鼻（41 山根、44 年上、45 寿上、48 准头、49–50 兰台廷尉） |
| 51–60 | 人中、口、唇（51 人中、57–60 口唇） |
| 61–75 | 下停（61–62 承浆、63–65 地阁、66–70 腮颐、71–75 奴仆） |

用法：只取当事人当前年龄段的 1–2 个部位讲“这一段的着力点”，不铺满整张流年图，也不算具体年份吉凶。

## 11. 常见吉格（转为倾向表述）

- 天庭饱满 + 地阁方圆 → 早年有助、晚运稳，中年最能出成绩。
- 三停平等 → 一生起伏不大，稳中求进型。
- 五岳朝拱、四渎流通 → 格局宽、能担事、扛得住压力。
- 面如满月、气色明润 → 心态稳、人缘好，做事有人捧场。
- 眉清目秀 + 准头有肉 → 才与财可兼得，宜专业立身。
- 骨肉相称 → 体力与执行力均衡，耐久战。
- 神气清定 → 越到中年越显，属于“后劲型”。

**提醒**：格局高不等于必富必贵。相不独论，一切断语只作倾向与自省之用。
