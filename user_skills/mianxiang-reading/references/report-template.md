# 报告结构与表达规范

## 固定结构（顺序不颠倒，可按信息量裁剪 6、7）

1. **一句话总评**（≤30 字，点出整体格局与气质基调）
2. **判读前提**（1–2 行：照片质量、哪些部位看清了、哪些没看清不作论断）
3. **整体格局**（面型五行 + 三停 + 五岳，3–5 句）
4. **五官并读**（眉 → 眼 → 鼻 → 口 → 耳，每项 1–2 句：形态 → 性格 / 能力）
5. **重点宫位**（3–5 宫，每宫 1–2 句）
6. **气色与标记**（痣、纹、气色，2–3 句）
7. **性格与行事风格**（3–5 条项目符号）
8. **阶段倾向**（早 / 中 / 晚各 1–2 句；或只讲当前流年部位）
9. **需留意**（2–3 条）
10. **建议**（3–4 条，可执行的行为建议）
11. **免责**（固定一句）

## 表达规范

- 用第二人称“你”，口语化，像当面讲，不要论文腔。
- 术语首次出现配一句白话，例：**准头（鼻尖）丰隆**。
- 每一项只给一个核心判断，不叠三个形容词。
- 优缺点交替给出：说一处优势，再给一处留意，不要集中堆缺点。
- 结尾落在“能做什么”，不落在“命如何”。
- 全文不出现“注定、一定、必、克、破财无疑、灾”等词。

## 句式示范

- 格局：“三停大致均等，中停最实——说白了，你是靠中段发力的人，三十岁往后越做越稳。”
- 优势：“眉长过目而眉尾有聚，重情也念旧，答应的事基本会办到。”
- 留意：“眉略压眼，心事容易自己扛，压久了会急；遇事给自己留半天的缓冲。”
- 宫位：“印堂开阔明润，命宫宽，说明心胸装得下事，不太会为小事计较。”
- 建议：“把‘想’落成‘写’：每周列三条待办，扛事的习惯就有出口了。”

## 速判格式（150 字内）

一句格局 + 一句优势 + 一句留意 + 一句建议，不铺术语。
