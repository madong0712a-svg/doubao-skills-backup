# 物理建模音色引擎技术说明

> 本文说明 `instrument_voices.py` 的原理、为什么需要它，以及它相比旧实现的改进。
> 阅读对象：想知道"为什么现在听起来像乐器了"的人。

---

## 一、问题：为什么旧版听起来像电子琴

旧版 `synth_note()` 的全部逻辑是：

```python
for harm, amp in HARMONICS[timbre]:        # 固定振幅的正弦谐波
    wave_out += amp * np.sin(2π * freq * harm * t)
wave_out *= envelope(t)                     # 单一指数包络
```

这叫**静态谐波叠加（Static Additive Synthesis）**。它的致命缺陷：

| 缺陷 | 后果 |
|---|---|
| 谐波的**相对强度从头到尾不变** | 真实乐器的高频会先消失，这里不会 → 音色"死" |
| **单一包络**控制所有谐波 | 所有谐波同时衰减，不符合物理 |
| 谐波是**精确整数倍** | 真实弦有轻微 inharmonicity（非整数），这里没有 |
| **无共鸣体** | 没有琴体/音板/管腔的箱体共振 → 没有"乐器腔体感" |
| 音符间**机械对齐** | 没有演奏微时序 → "MIDI 味" |

**实测证据**：旧版单音符 C4 的各次谐波保留率全部是 **0.02** —— 意味着 1 秒后高频只剩 2%，几乎完全消失。听感就是"闷、扁、单薄、假"。

## 二、方案：三种物理建模方法

### 2.1 模态合成（Modal Synthesis）—— 主方法

**核心思想**：任何发声体都可以分解为一组**共振模态**。每个模态是一个有自己频率、振幅、衰减速度的衰减正弦。

```
信号 = Σ  振幅ᵢ · exp(-t·衰减ᵢ) · sin(2π·f·频率比ᵢ·t)
        i
```

**决定性参数是"频率比"**，它直接对应材质：

| 频率比 | 物理含义 | 听感 |
|---|---|---|
| 1, 2, 3, 4, 5… （整数） | 理想弦 / 空气柱 | 钢琴、弦乐、管乐 |
| 1, 3.93, 9.54, 16.7 （非整数） | 自由-自由弹性杆（木条） | 木琴、马林巴 |
| 1, 2.76, 5.40, 8.93 （非整数） | 圆形板/钟形 | 钟、铃、金属 |

**另一个决定性参数是"衰减速度"**：真实乐器中，**频率越高的模态衰减越快**。
这就是为什么钢琴高音短促、低音绵长；也是为什么"看起来是同一组谐波"的不同音色会有完全不同的听感。

本引擎的每个音色都据此调参，例如钢琴：

```
(1.000, 1.00, 0.55)   ← 基频：最强、衰减最慢
(2.003, 0.58, 0.85)   ← 2次：稍弱、稍快
(3.008, 0.34, 1.20)
...
(9.074, 0.017, 4.30)  ← 9次：极弱、衰减极快（4.3/0.55 ≈ 8倍速）
```

**注意 2.003 / 3.008 这些非整数值** —— 这是真实钢琴弦的 **inharmonicity（非谐性）**：因为弦有刚度，高次谐波会比理想整数倍略高。这个细节让音色"结实"而非"塑料"。

### 2.2 Karplus-Strong 弦模型

**核心思想**：直接物理仿真一根弦。

```
1. 用噪声（拨弦激励）填充长度为 N = 采样率/频率 的延迟线
2. 循环：y[n] = (y[n-N] + y[n-N-1]) / 2 × 损耗系数
3. 相邻两点平均 = 低通滤波 → 高频自然先衰减
```

它的精妙在于：**"高频先衰减"不是我们硬编码的，而是滤波器的物理必然结果**。这就是为什么 KS 出来的声音天然像弦。

**本实现的两个改进**：

| 改进 | 原因 |
|---|---|
| **激励源先做低通** | 朴素实现用纯白噪声，频谱重心高达 7kHz，听起来像沙锤而非拨弦。真实拨弦能量集中在基频附近，故先低通。 |
| **拨弦位置 (pick_pos)** | 在延迟线上做 comb 滤波，模拟拨弦点对特定谐波的抵消。这是"这根弦是在这个位置被拨的"空间感来源。 |

### 2.3 FM 合成

**核心思想**：用一个振荡器（调制器）去调制另一个（载波）的频率。

```
y(t) = sin(2π·f·t + I(t)·sin(2π·f·r·t))
```

**关键在于调制指数 I(t) 随时间衰减**：

- 起音瞬间 I 很大 → 产生大量边频 → 声音"叮"地一下很亮、很复杂
- 迅速衰减后 I→0 → 只剩纯基频 → 声音变干净

这正是 DX7 电钢、钟琴的听感秘密。生产级 FM 音色的标准做法。

## 三、让"演奏"变真实的四项技术

光有好音色还不够，还要像"有人在弹"。

### 3.1 和弦滚奏（Strumming）

真实演奏中，和弦的各个音不可能**精确同时**发出。

```python
strum = ci * rng.uniform(0.008, 0.022)   # 每个和弦音依次延迟 8~22ms
```

### 3.2 微时序偏移（Micro-timing）

人手不可能完全踩在拍子上：

```python
jitter = rng.uniform(-0.011, 0.014)      # ±11~14ms 偏移
```

### 3.3 力度弧线（Dynamic Arc）

小节内的强弱起伏，模拟演奏的"呼吸"：

```python
arc = 0.55 + 0.45 * math.sin(math.pi * s / steps)   # 小节内先渐强后渐弱
bar_dyn = 0.82 + 0.18 * np.sin(bar_idx * 0.9)       # 跨小节的大起伏
```

### 3.4 音高微漂移

```python
micro_detune = 1.0 + rng.uniform(-0.0009, 0.0009)   # ±0.09% 音高漂移
```

## 六、与采样级大模型的边界（诚实说明）

本引擎是**参数化合成**，不是采样回放。它做到的是：

✅ 有真实乐器的**物理特征**（谐波衰减、共鸣、非谐性）
✅ 有真实演奏的**人文特征**（微时序、力度、滚奏）
✅ 100% 原创、可商用、零版权、零依赖、秒级出片

它做不到的是：

❌ 录音级的**音色保真度**（缺少真实乐器的复杂噪声成分、空间录音细节）
❌ 复杂配器的**声部交织**（目前是"和弦+琶音+低音"三声部）

**要跨越这条线，必须上 L2（ACE-Step）**——那是扩散模型从海量真实音频中学到的分布，
本机 GTX1660 6GB 可跑。部署见 `INSTALL_ACESTEP.md`。

**两者的关系**：不是替代，是分工。L1 负责"立刻可用、批量、零成本"，
L2 负责"关键片头/高要求场景的录音级质感"。
