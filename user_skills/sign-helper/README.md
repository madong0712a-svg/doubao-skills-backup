# 签到助手（sign-helper）

WorkBuddy「Buddy 加油站」每日签到提醒技能（纯提醒型 · 合规上架版）。

## 它做什么

- 每天 **09:00 主提醒**、**17:00 兜底检查**（今日未签到才再提醒一次）
- 本地记录连续打卡天数，追踪 7 / 14 / 28 天里程碑倒计时
- 断签保护：提醒补签
- 用户回「签了」或发截图即可完成打卡确认（仅本地记录）

## 合规边界（重要）

- **只做提醒、记录与断签保护**，不模拟点击、不读写登录态、不调用任何平台接口、不存储账号凭据。
- 所有签到操作一律由用户在客户端手动完成，本技能最后不替用户点任何一下。
- 不提供积分规则数值，规则与入口一律以客户端活动页为准。

## 触发方式

- 定时：WorkBuddy 定时任务每天 09:00 / 17:00 触发。
- 手动：说「签到 / 领积分 / buddy积分 / 签到助手 / 提醒我签到 / 打卡」等触发词。

## 配置参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| 主提醒 | 09:00 | 定时任务 rrule 控制 |
| 兜底检查 | 17:00 | 未签到才再提醒 |
| 打卡日志 | `~/.workbuddy/memory/checkin-log.md` | 追加式记录 |
