# 户型风水判定与七类"不建议居住"的硬伤

## 一、风水不佳的户型（避险清单）

| # | 户型问题 | 问题说明 |
|---|---|---|
| 1 | **卫生间位于中心** | 卫生间为家中污秽之源，位于房子中心不利于所有居住者运势；且脏气排不出去，只能在卧室或客厅徘徊，气味难闻 |
| 2 | **三角形户型** | 三角形的稳定性差，面积有效利用做不到，许多面积将浪费；风水上属大不吉 |
| 3 | **T 型户型** | 前面大、后面小，称为"退田比"，家运一天不如一天 |
| 4 | **多边形户型** | 久住者思维不清晰、没主见，东一下西一下 |
| 5 | **缺西北角/西南角** | 房子如人体，缺角如肢体不全。西北缺不利丈夫，西南缺不利妻子，北方缺不利长子，东南缺不利长女 |
| 6 | **刀把形户型** | 整体形状像刀把，存在严重缺陷且寓意不佳，建议避开 |
| 7 | **门窗比例不合适** | 门要大小合适，窗要不多不少。买房时可暂不考虑（可通过装修调整） |
| 8 | **外部有高架桥、烟囱或变压器** | 外部环境不利，建议不要选 |

## 二、风水好的户型标准（八条）

1. **吉位充分利用**——按居住需求各安本位，如主卧位于合星位利于夫妻感情，卫生间位于衰星位压制凶星
2. **卫生间位置至关重要**——避开屋子中心地带与西北角（最大不吉）；家有男孩者，厕所位于正东方也不吉
3. **室内不出现两门相对**——减少客厅中的门，减少无法利用的通道走廊；客厅应宽敞、明亮、通风，有较好朝向和视野。长走廊对入户门、入户门正对厨房门、开门即见厨房餐厅、厕所正对卫生间，均属犯"门冲"
4. **重视卧室采光效果**——起居室、厨房、卫生间采光依次类推；厨房宜直接对外采光通风；客厅卧室分离、厨房餐厅分离但相互挨着；户门不宜直接对着客厅
5. **户型形状不太怪异**——方正户型最符合，三角形、金字塔型等不理想
6. **阳台最好与客厅相连**——条件允许应大一些，有两个更好
7. **干湿分离**——卫生间干湿分离，与主卧位置近，不宜正对客厅餐厅，不宜与厨房紧连
8. **户型不缺角**——以方正为最佳；尤其**西北、东北、正东**三个位置不能缺

## 三、七类强烈建议不要居住的房子（无有效化解之法）

现实中的房子，只要没有太重大的缺陷，大多可借阳宅风水的制化方法化解。但以下情况**强烈建议不要住**，因为无法化解，强行住进去会慢慢对运气构成重大威胁：

| # | 类型 | 判定与说明 |
|---|---|---|
| 一 | **历史上的"不洁用途"房屋** | 曾是屠宰场、刑场等聚集阴气之地；购买老房前应先探听清楚此房之前的用途 |
| 二 | **发生过非正常事件的房屋** | 曾发生凶杀命案或有人自杀过的房子。看房时**第一直觉很重要**——若进屋后浑身不自在却找不出原因，建议另寻目标 |
| 三 | **曾有特殊用途的房子** | 曾被用于一般人忌讳的行业：殡葬业、停尸间、监狱、神坛、屠宰场、不洁场所、化粪池等，屋内可能残留不良气场。可能开始无所谓，怕的是时间长了出问题 |
| 四 | **盖在危险地势的房子** | 陡峭山壁旁、悬崖峭壁之上、太靠近水边海边、沼泽沙洲等。有些强调风景秀丽的高级住宅偏喜欢盖在这类地形上，**切勿贪图环境优雅而忽略自身安全** |
| 五 | **宅基有问题的房子** | 地底下曾是采矿隧道、取水口井水池、地铁、洼地（虽经填土但地气已受损）；地下有暗渠流过，或建时运来填平地基的土壤有太多杂物、树木残根 |
| 六 | **采光不良的地下室** | 地上属阳面、地下属阴面，地下室虽属阳宅建筑体但在阴面，易汇集阴极磁场。长时间待着对健康影响大，一般只作停车场或杂物间，**住人绝对不宜久住** |
| 七 | **地势过于低洼的房子** | 每逢下大雨就淹水，想发也发不起来；台风或雨势稍大即造成严重灾情（典型如汐止地区、沿海地区）。地势过于低沉或太靠近易淹水河岸的房子不宜居住 |
| 八 | **建筑体太过奇特** | 建筑师为突显独特性设计的奇特造型：三角形、有缺角、大小高低不平均等，虽印象深刻，却犯了阳宅学大忌（如央视着火的大楼即案例），不适合当住宅或办公室 |

> 以上八条在判定时统一按"**一票否决**"处理，不进入常规打分。

## 四、户型选择的通用建议

买房的户型选择非常重要。户型指住房的结构和形状（常见有平层、跃层、错层、复式；按面积分小户型和大户型），户型功能的配置需要匹配家庭结构。购房者应针对自身家庭情况，选购面积合适、功能齐全的户型。
