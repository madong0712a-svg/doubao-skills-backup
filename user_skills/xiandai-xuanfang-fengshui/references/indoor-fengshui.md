# 室内篇：阳宅三要与缺角

古书中厨房、大门、主卧共同组成住宅三要素，传统称为"阳宅三要"。以下为现代住宅的落地判定标准。

## 一、厨房布局

厨房是家中烹饪食物的重要场所，方位布局关系家人健康，也与整个家庭息息相关。

1. **方位**：适合放在**北方和东南方**。东南方是天然季风通道，与厨房火属性形成"木火通明"格局，厨房要能开窗、保持空气流通；北方与厨房形成"水火既济"格局，理论上较为理想。
2. **刀具**：使用后不要随意摆放在明面台面上，**刀尖不能对着人常活动的方向或卧室**，最好收纳于刀架——既是安全考虑，也避免无形的尖锐感。
3. **冰箱**（现代厨房的粮仓）：不宜正对灶台，不宜紧贴灶台摆放，冰箱门不宜正对厨房门（有"仓门大开"之象）。可放在厨房角落，或与灶台成斜角位置。
4. **炉灶**不要直对水龙头；若已对着，最直接的办法是调整水龙头朝向。
5. **厨卫不同宫**：厨房是烹饪场所，应讲究卫生、防止病从口入；厕所是污物与细菌集中处，二者临近有被污染风险，**尤其灶台不可与厕所相对**。现代住宅厨卫常相邻，要求不宜过苛——只要不是面对面，细菌传播风险可控即可。

## 二、大门与玄关

大门是纳气口、家宅的咽喉，决定财富与气场的进入。玄关是从大门进入客厅的缓冲区域，更是纳气的关键通道。

- **忌与正门成一条直线**：否则从外面把家里看得明明白白，隐私全无，还可能导致气流直冲。应在正面或侧面做隔断/屏风挡一挡，让气流回旋，实现"藏风聚气"。
- **隔断与屏风要满足"透"和"适中"**：
  - **透**：间隔一定要通透。磨砂玻璃优于厚重木板；若用木板，选色调明亮的，或用镂空木架，别做实心墙。
  - **适中**：不宜太高或太低。太高遮光挡气，太低起不到隐私保障作用。
- **忌过于阴暗**：昏暗环境影响出门与回家的心情，让人压抑。采用通透材质保障自然采光，配置暖光照明，顶部装筒灯或射灯也合适；**灯光避免布置成三角形，最好安排成方形和圆形**。
- **材质**：优先木质、石质等自然材质，不用塑料这类廉价感强的材料。

## 三、卧室布局

卧室是休养生息、恢复精力的私密空间，布局应保持**"静谧、安定、和谐"**。

- **睡眠区位置**：应设在最安静、最私密的位置。**床不能靠窗**——窗户是气流进出的地方，床头靠窗睡眠时头部易受风寒侵袭，窗外光线、声音变化也干扰睡眠，让人睡不踏实、精神紧张。现代紧凑型三居因空间限制不得不靠窗时，只要不影响休息睡觉，问题不大。
- **床忌正对镜子**：镜子有反射作用，半夜醒来意识模糊，容易被镜中自己惊吓，影响心神。
- **床忌在横梁下**："横梁压顶"，躺在床上无形中受压迫感，导致精神紧张、思绪混乱，长期易引起头痛、失眠及事业压力。若恰在横梁下方，可用暖光射灯或灯带照亮床区，减少视觉压抑。
- **衣柜**（卧室中体量较大的家具）：最适合摆在北、西南、东、东南方位，特别是可摆在**床的左侧**，形成"左青龙，右白虎"格局。
- **绿植**：避免带刺植物，不宜摆大型绿植（夜间吸收氧气、释放二氧化碳）。选小型、阔叶、常绿植物，如吊兰、绿萝，既能净化空气。
- **床下**：尽量不要堆放过多衣物或物品，保持能量流通。

## 四、缺角

**方位对应人**：西北方为男主人，西南方为女主人，东方为长子，东南方为长女。西北、西南最好不缺角；家里是儿子的，东方不要缺角；是女儿的，东南方不要缺角。

**测量方法**：
1. 在户型图上画两条对角线，交点即中心点
2. 以该点为中心，以最远的角为半径画圆
3. 缺的部分**超过半径的 1/2** → 缺角；**超过 2/3** → 严重缺角
4. 轻微缺角不会有太大影响，不必过度焦虑

## 五、补充：户型格局（阳宅三要之外）

- **吉位充分利用**：按居住的不同需求各安本位。如主卧室位于合星位利于夫妻感情，卫生间位于衰星位可压制凶星。
- **卫生间位置至关重要**：中心太极点受污是风水大忌。厕所为家庭污秽之源，处于屋子中心地带或西北角为最大不吉；家中如有男孩，厕所位于正东方也不吉。中心五行属土、土生万物，卫生间产生的秽气会令太极受污，影响家人健康与运势。
- **避免两门相对**："门冲"之说，不利藏风聚气、财运、健康，且两门相对谓之"骂"，多主口舌。长走廊对着入户门、入户门正对厨房门、开门即见厨房餐厅/厕所、正对卫生间，均属犯"门冲"。
- **重视采光**：起居室、厨房、卫生间的采光依次类推；厨房宜直接对外采光通风；客厅卧室分离、厨房餐厅分离但要相互挨着；户门不宜直接对着客厅。
- **户型方正**：自古"天圆地方"，方正的户型符合风水理论；三角形、金字塔型等不理想，可能形成煞气。户型以方正为最佳，**西北、东北、正东这三个位置不能缺**。
- **阳台**：最好与客厅相连；条件允许应大一些，能有两个更好。
- **干湿分离**：卫生间干湿分离，与主卧室位置要近，不宜正对客厅和餐厅，不宜与厨房紧连。
